# 草案を出す

**本文は書かない。** 草案を出して、著者の訂正を受け、要素を固めるところまで。本文は [episode-write](../episode-write/SKILL.md)、設定を畳むのは [episode-close](../episode-close/SKILL.md)。

## 読むもの

**PROJECT_RULES.md は全部読んでいる前提。** そのうえで次を読む。量が多いので、節を選んで読んでよいものは選ぶ。

1. **[掲載表.md](../../../C_執筆管理/掲載表.md)**で、その話の前後の並び（種別と案）を引く。由来・目印・人は、前後の話の話別設定で確かめる（続けて同じものを使わないため）。**[進行記録.md](../../../C_執筆管理/進行記録.md)の節も、その話に掛かるものは読む**（例：「安藤の時計を刻む」「I069を六十一に挿した」）。話数で grep すると拾える。
2. **その話の案**（`C_執筆管理/話アイデア/I0NN_題.md`）を全部。
3. **[連載の組み方.md](../../../C_執筆管理/連載の組み方.md)を全部。** 伝えることを先に立てる、本筋回は濃くする、人の出し方、本家の型、安藤の影、依頼人の持ち札（既出の一覧）。
4. **[基礎設定.md](../../../B_設定/基礎設定.md)の「年表」「舞台」。**（回の組み方の原則は、三の連載の組み方.md の「連載の原則」に移した。） 舞台には店まわりの座標と配置がある（店・ひさし・信号・本家の路地）。**店の前の場面を組むときは必ずここで確かめる。**
5. **直前の話の本文と話別設定**（`B_設定/話別設定/0NN_*_設定.md`）。季節、締めの型、本家の型、出た人物。**直前と重ねないために読む。**
6. 札・帳面・記憶と怪異の法則は、その回で使う節だけ（目印の読み方、引き取り、力の借用など）。

## 草案の形

チャットに出す。ファイルにはまだ書かない。

1. **伝えること。** 主を一つ、要ればサブを一つ。**捻れ**——読者が予想する閉じ方から一度ずらすもの。本筋回なら**本筋の一段**も。
2. **時期。** 季節は掲載順に進める。本筋回は年表に載せる日付を決める（本文には出さない）。曜日は作中の暦（2021年夏始まり）で合わせる。
3. **事件。** 舞台、依頼人（年格好・癖一つ・恐怖以外の持ち札・降りられない事情）、目印の出方、始末、勘定。**本筋回は依頼人・現場・勘定の三つが立つこと。**
4. **人。** 本家の型（直前と同じ型にしない）、安藤（出ない回は三話まで）、播谷・税所・占部の出し方。
5. **締め。** 型の一覧（PROJECT_RULES「締めの型の、大上屋での使い分け」。原則は執筆の決まり.md「締めの型を続けて使わない」）から、直前と重ならないものを選ぶ。
6. **出さないもの。**
7. **決めていただきたいこと。** 題、新しい苗字、実在の地名や旧町名の使い方、筋の分かれ目。**選択肢を並べるだけにせず、推す案を書く。**

## 気をつけること（これまでに著者から受けた訂正）

- **新しい苗字は、PROJECT_RULES の使用済みの一覧に当ててから出す。** 下の名前の一覧と「使わない苗字」も見る。
- **直前の話と手触りが似ていないか確かめる。** 似ているなら、草案の時点でそう書き、どう分けるかを添える（第五十話：第四十九話の「迎える人が一人いれば盆」と、祠の世話人一人が近かったので、世話人を信心の人ではなく、当番を引き継いだだけの人にした）。
- **本筋の糸と事件の糸を交互に挟まない。** 意識が散る。前半と後半にまとめる。**締めは事件の余韻に割く。** 本筋の進みを締めに置くと、事件が前振りに見える（第五十話）。
- **実在の地名・旧町名・施設を使うなら、下調べをして、分かった結果だけを書く。出典は添えない**（執筆の決まり.md「進め方」）。 作中の暦（2021〜2023年）の時点の姿で書く。その後に変わったもの（道路の歩行者専用化、新しい地下通路など）を前倒しで書かない。
- **大きな設定変更は提案して合意を取る。** 草案の「決めていただきたいこと」に入れる。
- **伏線の回収を回の目的にしない。締めで在庫や未回収を「まだどこかにある」と引き直さない。** 伝えることを先に立て、場面をそこへ配る。百二十行台で収まる回は、伝えることが足りていない（第四十五話の初稿）。
- **著者の下書きや仕掛けに着地させるためだけの回を組まない**（第四十六話の初稿）。下書きは、伝えることへ着地する材料として使う。
  - **依頼人を説明係にしない。** 身の上・矛盾・決断を持たせ、説明は会話や物（帳簿、近所の伝聞）から出す。
  - **同じことを違うやり方でやる人を一人置く。**
  - **仕掛けのために語り手の考えを削らない。** 勘のよい読者に途中で割れてもよい。
- **定型回の型（値段→目印三枚→八文字→品名→口上）を崩す提案をしない。** 定型回の削減・統合、型の文言を変える案もこちらから出さない。その回の中の冗長な箇所を指摘するのは構わない。
- **中盤では、回をまたぐ引きを持ちかけない。** 一話ずつ読ませる作品。**終盤、とくに童子との対決（第六十二・六十三話）の前は、引きを組む相談に乗ってよい。**

## 合意したら

- **話アイデアのファイルに「草案で決めたこと」の節を足す。** 主・サブ・捻れ・時期・舞台・人物・題など、著者の判断として。**下調べで分かったこと（と、確かめきれなかったこと）もここに書く。出典は書かない。**
- **新しい苗字を PROJECT_RULES の使用済みの一覧に足す。五十音順に。**
- **改行コードは CRLF。** 書いたら `file` で確かめる。`sed -i` は使わない（CRLF を潰す）。
- そのまま本文に入るなら [episode-write](../episode-write/SKILL.md) へ。
