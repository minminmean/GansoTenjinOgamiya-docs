# 本文を書いて、辞書に登録する

## 読むもの

**PROJECT_RULES.md の指示どおり、本文を書く前に基礎設定・作法・札・帳面を読む。** 加えて、直前の話の本文を一本、口調と書式の手本として読む。安藤や本家を出すなら、その人物が前に出た話の該当場面も読む（買い方、立ち位置、言い回し）。

## 書く

- ファイルは `A_本編/0NN_第N話_題.md`。題の中の空白はアンダースコア。
- まず LF で書いてよい。**書いたら下の整形を通す。**

### 整形（書いたあと・直したあと、毎回通す）

```bash
cd "$(git rev-parse --show-toplevel)/A_本編"
perl -e '
local $/; open F,"<:raw",$ARGV[0]; $t=<F>; close F;
$t=~s/\r\n/\n/g; $t=~s/\n+$//; @l=split /\n/,$t,-1;
for $i (0..$#l){ $l[$i]=~s/ +$//; }
for $i (1..$#l-1){ next if $l[$i] eq ""; $l[$i].="  " if $l[$i+1] ne ""; }
open F,">:raw",$ARGV[0]; print F join("\r\n",@l)."\r\n"; close F;' 0NN_第N話_題.md
```

- CRLF、行末の半角スペース二つ（次の行も空行でない行だけ。題の行と段落の末尾には付けない）。
- **段落の一行目だけ全角空白で字下げ。** 記帳の行・書かれたものの引用は全角二字下げで、前後に空行。
- **`sed -i` は使わない**（CRLF を潰す）。`perl -i` にスクリプトファイルを渡さない（ファイルが空になる）。置換は `perl -i -pe` のワンライナーか、python で `newline=''` を付けて読み書きする。

### 検査

```bash
file 0NN_第N話_題.md
python -c "
import re
s=open('0NN_第N話_題.md',encoding='utf-8').read(); L=s.split('\n')
print(len(L), len(s.replace('\r\n','')))
for i,l in enumerate(L):
  l=l.rstrip('\r')
  if i>0 and re.search(r'[0-9A-Za-z!?*]',l): print('半角', i+1, l[:30])
"
```

- 一行目は CRLF であること。二行目は行数と字数（**字数は UTF-8 で数える。`wc -m` はバイト数を返す**）。
- **字数は直近の話と比べる。** 本筋回は定型回より濃くする。短すぎるときは水増しせず、伝えることか捻れを立て直す。

## 自己点検（著者に渡す前に）

執筆の決まり.md の「校正は次の順で当てる」に従う（各段の基準は PROJECT_RULES「進め方」）。加えて、これまでに著者から受けた訂正：

- **地理。** 店の前の動き（ひさし、歩道、信号、向かいの建物）は、[基礎設定.md](../../../B_設定/基礎設定.md)「舞台」の座標と配置に当てる。**ひさしは歩道を挟んだ向かい、信号は南のすぐ近く、道路を挟んだ向かいは大丸。** 「天神のほうへ」は方角にならない（店が天神の真ん中にある）。店の向かいに無いもの（解体中のビルなど）を置かない。
- **語り手が察していることは具体的に書く。察していないなら匂わせない。** 「訊けることでは、なかった」のような、中身の無い含みで止めない。大上が既に知っていること（どの話で何を見たか）から組み立てる。過去の件は人名と出来事で呼ぶ。
- **含みの向き。** 締めの一文が、意図しないものに含みを持たせていないか（第五十話：境目の札の目的を問う締めが、祠に何か居たかのように読めたので、祠そのものの由来へ向け直した）。
- **同じ場面の中の空行は、著者が軽い場面転換として入れている**（移動の境目、長すぎる段落）。校正で詰めない。書く側も、長い段落は移動の境目で区切ってよい。

## 直しを受ける

- 著者はファイルを直接直すことがある。**手を入れる前に、いまの内容を読み直す。**
- 直したら毎回、整形と検査を通す。
- 直しで新しい地名・人名が出たら、そのつど辞書に足す。

## 辞書に登録する

**標準の手順。本文を書いたら、著者の直しを待たずに、続けて辞書登録まで済ませて報告する**（著者の指定、第五十九話から）。登録を頼まれるのを待たない。

辞書は `Z_その他/変換辞書/読み.tsv`（分類／語／ルビ／通し／備考、タブ区切り、CRLF）。判断の基準は [テキスト変換規則.md](../../../Z_その他/テキスト変換規則.md)「読みの辞書」。

1. **本文に出た地名・人名（屋号・建物名・店名を含む）を拾い、辞書に無いものを出す。** 一語ずつ `grep` で当てる。
2. **読みは著者の確定。** 普通の読みで足してから、足した語と読みを報告して確かめる。**割れうる読み（高木＝たかぎ／たかき）は必ず報告に出す。**
3. 行を足す。備考に「第N話。何者か」。
   ```bash
   cd "$(git rev-parse --show-toplevel)"
   printf '人名\t原田\t｜原田《はらだ》\t\t第五十話。…\r\n' >> Z_その他/変換辞書/読み.tsv
   file Z_その他/変換辞書/読み.tsv
   ```
   送り仮名のある地名（○○通り）は親文字から外す形にする（`｜渡辺通《わたなべどお》り`）。長い語の中の短い語の食い込みに注意する。
4. **波及検査。** 足した語が過去の話に当たるかを見る。
   ```bash
   perl .agent-shared/skills/export-honbun-txt/henkan.pl --dry Z_その他/変換辞書 - なろう A_本編/*.md 2>/dev/null | grep -E "語1|語2"
   ```
   **過去の話に当たったら、話数・行数と掲載状況を報告する**（予約中なら差し替えが間に合う）。
