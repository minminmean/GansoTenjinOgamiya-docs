# 本編の txt 書き出し

`A_本編/*.md` を投稿用の `A_本編/txt/<変換先>/*.txt` に変換する。**辞書は `Z_その他/変換辞書/` の TSV 四枚**で、スクリプトはそれだけを読む。**正は md のほうで、txt は使い捨ての生成物**（`A_本編/txt/` は .gitignore 済み）。

**既定は単話。**頼まれた話だけを出し、ほかの話の txt には触らない。**全話を出し直すのは、規則のほうを変えたときだけ**（下の「手順」）。話数が増えるので、用が無ければ全話を回さない。

**通しルビは前の話を読まずに解ける。**連載を通して一度だけ振る語（`安藤`・`本家`・`天神`・`渡辺通り`・`元祖天神大上屋`・`大上屋`）は、どの話で振ったかを `Z_その他/変換辞書/通し初出.tsv` に持たせてある。**書き出しはその台帳だけを見る。**だから一話だけ渡してよい。

**md には投稿サイトの記法を一切書かない。** ルビも傍点も、この書き出しのときに足す。

## 辞書

**辞書と台帳は `Z_その他/変換辞書/` の TSV 四枚。**一行目が見出し、区切りはタブ、CRLF、UTF-8。

| ファイル | 列 | |
|---|---|---|
| `読み.tsv` | 分類 / 語 / ルビ / 通し / 備考 | 読みの辞書。「通し」に字が入っていれば通しの語 |
| `通し初出.tsv` | 語 / 初出の話 | 通しの台帳。**`--ledger` が書き直す唯一のファイル** |
| `位置指定.tsv` | 語 / 話 / 行の目印 | 初出の位置を名指しする語 |
| `傍点.tsv` | 話 / 語 / 文脈 | 傍点にするカギ括弧。文脈の列は覚え書きで、変換には使わない |

**語を足すのはここ。**[テキスト変換規則.md](../../../Z_その他/テキスト変換規則.md) が持つのは判断の基準だけ——何を辞書に入れるか、通しにするか、傍点にするか。**読みや扱いを決めるときはそちらを読む。書き出すだけなら読まなくてよい。**

## 変換先

**二つある。変換先ごとにディレクトリを切り、ファイル名の頭に接頭辞を付ける。**

| 変換先 | 出力先 | 接頭辞 | 傍点 |
|---|---|---|---|
| なろう | `A_本編/txt/なろう/` | `narou_` | 中黒ルビ（`｜七《・》`） |
| カクヨム | `A_本編/txt/カクヨム/` | `kkym_` | `《《七》》` |

- **何も言われなければ二つとも出す。**
- 「なろう向けに」「カクヨム向けに」と言われたら、そのひとつだけを出す。**そのときももう一方は消さない。**
- **違うのは傍点だけで、ルビはどの変換先も同じ形。**だから変換記録のルビの行は両面で一致する。一致しなければ変換が化けている。

## 出力の形

md の一行目 `# 第十話　白金一丁目　野良猫　受　壱` から見出し記号だけを落とす。**話数と題は改行で割らず、全角空白区切りの一行のまま置く。**

```
第十話　白金一丁目　野良猫　受　壱

　テーブルを畳もうとしたところで、男が一人、店の前に立った。
```

- 一行目が題の行、二行目は空行（md の二行目の空行がそのまま来る）。
- 全角空白は一つも触らない。話数と題のあいだも、題の中も、そのまま。
- 本文は行末の半角スペース二つだけを落とす。段落の字下げ（全角空白）や記帳行の二字下げ・三字下げはそのまま残す。
- UTF-8（BOM なし）、改行は CRLF。ファイル名は md と同じ連番＋話数＋題で拡張子だけ差し替え、**頭に変換先の接頭辞を付ける**（`narou_001_第一話_元祖.txt`）。接頭辞は `henkan.pl` が付けるので、こちらで足さない。
- **md と txt の行数は同じになる。** ルビと傍点は行の中に入るだけで、行を増やさない。増減があれば変換が化けている。

## 対象

**頼まれた話だけ。**話を一本書き上げたら、その一本を出す。**番外（`E001_番外_名札.md`）も同じ規則で出せる。** 一行目が `# 番外　名札` なのでそのまま `番外　名札` になる。

全話を回すのは、次のどれかに当たるときだけ。

- **辞書に語を足した**、読みを直した。
- **傍点の特例を足した**、ルビの位置指定を足した。
- **通しの語を増やした**、ルビの書式を変えた。
- 出力の形そのものを変えた（見出し、行末、改行コード）。

**話を一本足しただけなら、全話は要らない。**

## 手順

### 単話（既定）

```bash
cd "$(git rev-parse --show-toplevel)"
m=A_本編/021_第二十一話_題.md
b=$(basename "$m" .md)
for t in なろう カクヨム; do
  mkdir -p "A_本編/txt/$t/変換記録"
  perl .agent-shared/skills/export-honbun-txt/henkan.pl \
    Z_その他/変換辞書 "A_本編/txt/$t" "$t" "$m" \
    > "A_本編/txt/$t/変換記録/変換記録_$b.tsv"
done
```

- **ディレクトリを消さない。**ほかの話の txt はそのまま置く。
- 「なろう向けに」と言われたら `for` を外して `t=なろう` にする。**他の変換先には触らない。**
- **記録は各面の `変換記録/` にまとめる。** txt と同じ階層に置かない。話ごとに `変換記録_<連番>_<話数>_<題>.tsv`。全話を回したときの `変換記録.tsv` とは別に置く。
- **記録を残しておくのは、辞書に語を足したときの当たりを引くため**。txt と同じく使い捨ての生成物で、全話を出し直せば作り直される。

### 全話（規則を変えたとき）

```bash
cd "$(git rev-parse --show-toplevel)"
for t in なろう カクヨム; do
  rm -rf "A_本編/txt/$t"; mkdir -p "A_本編/txt/$t/変換記録"
  perl .agent-shared/skills/export-honbun-txt/henkan.pl \
    Z_その他/変換辞書 "A_本編/txt/$t" "$t" A_本編/*.md \
    > "A_本編/txt/$t/変換記録/変換記録.tsv"
done
```

ひとつの変換先だけ出し直すときは `t` を差し替えて中身だけを回す。**他の変換先のディレクトリには触らない。**

### 波及検査（`--dry`）

辞書に語を足したときに、過去の話へ当たっていないかを見る。**txt は一枚も書かず、記録だけ出す。**

```bash
cd "$(git rev-parse --show-toplevel)"
perl .agent-shared/skills/export-honbun-txt/henkan.pl --dry \
  Z_その他/変換辞書 - なろう A_本編/*.md 2>/dev/null | grep 七隈線
```

**当たっていたら、書き出し直すのはその話だけでよい。**単話の手順で出せる。

### 通しの台帳の数え直し（`--ledger`）

```bash
cd "$(git rev-parse --show-toplevel)"
perl .agent-shared/skills/export-honbun-txt/henkan.pl --ledger \
  Z_その他/変換辞書 - なろう A_本編/*.md
```

**`Z_その他/変換辞書/通し初出.tsv` を書き直す。**ほかの三枚には触らない。合っていれば「台帳は本編と合っている。通し初出.tsv は触っていない」と出て、書き込みもしない。

**走らせるのは二つの場合だけ。**通しの語を増やしたとき。**既にある話の本文を直して、通しの語の出どころが動いたとき**（初出の話から消した、もっと若い話に足した）。**話を一本足しただけなら要らない**——通しの語は既に前の話で振り済みで、台帳は動かない。

**台帳が動いたら、その語の絡む話は txt を出し直す。**初出が移った先と、移る前の話の両方。

**通常の書き出しは台帳を書き換えない。**読むだけ。だから**通しの語を増やしたら、まず `--ledger` を通す。**通さずに書き出すと、全話一括なら正しく出るが（台帳の無い語は話をまたいだ振り済み判定に落ちる）、**単話では出る話ごとに振り直されて通しが効かない。**起動時の警告がその合図。

### `henkan.pl` がやること

1. CR を外し、一行目の見出し記号を取り、行末の半角スペースを落とす。
2. 丸括弧で書かれた読みをルビ書式に変える（送り仮名は親文字から外す）。
3. その話の傍点の特例に載っているカギ括弧を、傍点にする。
4. 辞書の語に、その話で初出の一箇所だけルビを振る。**題の行と記帳の行には振らない。**
5. **通しの語は、台帳に書いてある話でだけ振る。**ほかの話では素のまま出す。**番外は台帳の外**で、通しの語を一律に振らない。
6. CRLF で書き出し、変換の記録を TSV（話／行／種別／変換前／変換後）で標準出力に出す。

**辞書も傍点の特例も通しの台帳も、`Z_その他/変換辞書/` の TSV から読んでいる。** スクリプトの中に読みを書き足さないこと。増やすときは TSV に行を足す。

**台帳に行の無い通しの語があると、起動時に `! 通し初出.tsv に行が無い` と出る。**そのまま単話で出すと、その語にルビが振られない。**警告が出たら止めて、`--ledger` で台帳を作る。**

## 報告

書き出しが済んだら、**変換記録を表にして出す。** 話ごとに、行番号・種別・変換前・変換後。

```bash
awk -F'\t' 'NF==5{print $1"\t"$2"\t"$3"\t"$4" → "$5}' A_本編/txt/なろう/変換記録/変換記録_$b.tsv
```

全話を出し直したときは `変換記録/変換記録.tsv` を見る。**出すのは出し直した話のぶんだけでよい。**

**両面出したときも、表に出すのは一つでよい。**ルビと丸括弧の行は両面とも同じなので、違うのは傍点の行だけ。**傍点は変換先ごとに形が変わることを一行添えれば足りる**（なろうは中黒ルビ、カクヨムは二重山括弧）。

**辞書に無い地名・人名が新しい話に出てきたら、そこで止めて読みを確認する。** 勝手に決めて通さない。確認が取れたら `変換辞書/読み.tsv` に行を足してから出し直す。

**辞書に語を足した回は、その語が過去の話に当たっていないかを `--dry` で見る**（上の「波及検査」）。ルビは話ごとに数え直すので、**新しい話のために足した語は、既に投稿した話にも振られる。**当たっていたら、話数・行数と掲載状況（公開済／予約中）を添えて報告に書き、**その話だけを出し直す**（[テキスト変換規則.md](../../../Z_その他/テキスト変換規則.md)「読みの辞書」）。**なろうと全話を突き合わせない。**

**地の文の強調のカギ括弧も同じ。** `変換辞書/傍点.tsv` に無い形が出てきたら、傍点にするかどうかを確認してから行を足す。発話の引用と、書かれた文言の引用は傍点にしない（規則ファイルの「置かないもの」）。

## 踏んではいけない穴

**全角空白や全角記号を正規表現のブラケットに入れない。** ロケールによって sed がバイト単位で動き、`[^　]` が「E3・80・80 のどのバイトでもない」の意味になる。`一`（E4 B8 80）や `十`（E5 8D 81）は 0x80 や 0x81 を含むので、特定の話だけ変換が素通しする、という形で化ける。

同じ理由で `[[:space:]]` も避ける。**`《》「」｜` を sed や grep で扱わないこと。** ルビと傍点の処理を perl に寄せてあるのはこのためで、`:encoding(UTF-8)` で読んで文字単位で動かしている。

**`perl -CSD` だけでは足りない。ワンライナーには `-Mutf8` も付ける。** `-CSD` が開くのは入出力だけで、`-e` の中に書いた `《` や `（` はバイトのまま残る。**入力は文字、パターンはバイトで、噛み合わないので一度も当たらない。** エラーは出ず、静かに「異常なし」と出る。**下の確認の節で全角文字をパターンに書いている行には、全部 `-Mutf8` が要る。**

- **`-CSDA` の `A` はファイル名のぶん。** 無いと `$ARGV` が化けて、どの話で当たったのか読めない。
- **`close ARGV if eof` を付けないと `$.` がファイルをまたいで通し番号になる。** 行番号として使えなくなるので、変換記録と突き合わせられない。

**短い語が長い語の中に食い込む。** 「大上屋」の中の「大上」、「元祖天神大上屋」の中の「天神」。スクリプトは位置で判定して弾いているが、辞書に語を足すときは重なりを意識すること。

## 確認

**構造の検査は両面に当てる。**出したぶんだけでよい。`pat` を出した話の名前にすれば単話に、`'*'` にすれば全話に当たる。

```bash
cd "$(git rev-parse --show-toplevel)"
pat=$b            # 単話のとき。全話を出し直したときは pat='*'
for f in A_本編/txt/*/*$pat.txt; do
  n=$(basename "$f" .txt); n=${n#narou_}; n=${n#kkym_}
  m="A_本編/$n.md"
  [ -f "$m" ] || { echo "元の md が無い: $f"; continue; }
  [ "$(sed -n 2p "$f" | tr -d '\r')" = "" ] || echo "二行目が空行でない: $f"
  a=$(sed 's/\r$//' "$m"|wc -l); c=$(sed 's/\r$//' "$f"|wc -l)
  [ $((c-a)) -eq 0 ] || echo "行数が md と違う: $f ($((c-a)))"
  n=$(grep -cv $'\r$' "$f" || true); [ "$n" != "0" ] && echo "CR のない行: $f ($n)"
done
grep -l '^#' A_本編/txt/*/*$pat.txt || echo "見出し記号の残りなし"
grep -cH ' $' A_本編/txt/*/*$pat.txt | grep -v ':0$' || echo "行末の半角スペースなし"
for f in A_本編/txt/なろう/*$pat.txt; do head -1 "$f" | tr -d '\r'; done
```

**記法の検査はなろう版だけでよい。**ルビは両面とも同じものが入るので、一面見れば足りる。カクヨム版に当てると `《《…》》` を入れ子のルビと誤認する。

**`grep -c` には `-H` を付ける。**当たるファイルが一つだと件数だけが出て、`:0$` で弾けない。**単話の検査では必ず一つになる。**

```bash
cd "$(git rev-parse --show-toplevel)"
grep -cH '｜｜\|《[^》]*《' A_本編/txt/なろう/*$pat.txt | grep -v ':0$' || echo "記法の重なりなし"
perl -CSDA -Mutf8 -ne 'while(/《([^》]+)》/g){print "ルビが十文字超: $ARGV:$.: $1\n" if length($1)>10} close ARGV if eof' A_本編/txt/なろう/*$pat.txt
```

一行目が全話「第N話　題」の形で出ていること、行数がどの話も md と一致していること、ルビが入れ子になっていないこと、ルビが十文字を超えていないこと（なろうの上限）を見る。
