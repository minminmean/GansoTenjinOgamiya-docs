# 怪異「三〇一号の境」

**第十一話／中央区平尾二丁目・メゾン平尾三〇一号。** 前の入居者が七年、居間と洋室から先へ出なかった記憶。**場の系統で、相手が点ではなく線だった初回。** 記帳は「メゾン平尾三〇一号　居間敷居　受　壱」だが、**入ったのは木の敷居一本だけで力は付いてこない。** 一般則は[記憶と怪異の法則.md](../記憶と怪異の法則.md)、回の側は[話別設定/011](../話別設定/011_メゾン平尾三〇一号_居間敷居_受_壱_設定.md)。

- **前の入居者が七年、居間と洋室から先へ出なかった。** 覚えているのは気持ちではなく**動いた範囲**。止める意志も追い返す意志もない。**転居しており存命**（鳥飼さんは「亡くなっとらんとは、言えます」までしか言わない）。
- **止まるのは内見の客だけ。** 鳥飼さんは四十回入って何ともなく、大上も何も感じない。「決めに来た人だけです」。**再現できない現象**なので、札で読むほかにない。
  - **鳥飼さんが何ともないのは、役割の差だけではない。** 住む部屋を選んでいるわけではない、という差もあるが、それ以上に**この人が記憶に鈍いたち**（[記憶と怪異の法則.md](../記憶と怪異の法則.md)「受け手の感度は、人によって違う」）。**人を相手にものを売る仕事の人間には、えてしてそういうことがある。** 大上は逆に敏感なほうだが、**この回の力は薄いので、歩いただけでは拾えない。**
  - **本編では一切説明していない。** 「わたしは、何ともなかとです」「四十回は入っとります」で置いただけで、感度という言葉も、その理由も出していない。**設定として持つに留める。**
- **力の分布は、内側に薄く一様、外側にはゼロ。** 敷居が内と外を区切っていて、**その上できっぱり切り替わる。** にじみも勾配もない。
- **したがって最初の三枚は、三枚とも白い。** 居間・洋室・廊下、どこに貼っても差が無いので何も出ない（[札.md](../札.md)「反応は差分で出る」。第一話・坂口家と同じ無反応）。**内側の白と外側の白は、同じ白で意味が逆**——一様だから出ないのと、無いから出ないのと。
  - **大上は一度、坂口家型（濃すぎて差が出ない）を疑う。** 外したのは客の歩き方——部屋じゅうが同じだけ濃いのなら玄関で帰る客がいるはずで、十一人が十一人とも廊下を三歩歩いてから止まっている。**切り替わるところがある。**
- **三枚から交点を出す手順は、源が一点にあるときの手順だった。** この部屋に一点は無く、あるのは内と外を分ける一本だけ。**手順の前提のほうが露見した回。**
- **解いたのは、札を並べて差の出る場所を潰す手。** 玄関から居間の中まで三十センチおきに十二枚（全部白い。またぐ一枚が無かった）、十センチおきに並べ直して四十枚を越えたところで、**敷居の上に置いた一枚だけが、居間の側の半分だけ黄ばむ。** 続けて間口いっぱいにまたがせて十枚、十枚とも同じ出方で、**壁から壁まで、敷居の上をまっすぐ一本。** 曲がりも途切れもない。
  - **札の上で、境目が直線になっている。** にじまず、端に向かって薄れもせず、そこで色が変わる。**黄ばんだのが居間の側なので、力があるのは内側だと分かる。** 中心の位置から源の向きを読む出方ではないので、**真下か真上かという読みは出てこない。**
  - **目印は嘘をついていない、と本文で言わせている。** 内側の二枚は「内側はどこも同じだ」と、廊下の一枚は「外側には何も無い」と言っていた。**読めなかったのは大上のほう。** 札の信頼を落とさないための一段。
- **裂けは出ない。目盛りも読ませない。**
- **『番』は「員数　合」。** 三〇一号も空室のまま合と出る。大上の読みは「戸のあるものは戸ごとに数える。戸の内側は一つの戸として数えられている。それより細かいものは、あれには見えない」。**第九話（合なのに匂う）、第十話（行そのものが無い）と外し方を重ねていない。**
