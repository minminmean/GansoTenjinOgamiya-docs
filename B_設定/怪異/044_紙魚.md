# 怪異「紙魚」

**第四十四話／博多区御供所町。** 観清寺の書庫で、代々紙を食っていた紙魚の、食う動きだけが残ったもの。**引き取っていない。** 品名「紙魚」と数（千二百余）は立ったが、大上は書かなかった。一般則は[記憶と怪異の法則.md](../記憶と怪異の法則.md)、回の側は[話別設定/044](../話別設定/044_蔵書庫_設定.md)、骨格は[I022](../../C_執筆管理/話アイデア/執筆済み/I022_044_蔵書庫の切れ.md)。

- 現象：**夜のうちに、書庫の棚から本が落ちる。** 古い和本は綴じが弱っていて、落ちれば傷む。人には何もしない。
  - 裂けは出ない。**祓えば素直に消える程度。**
- 正体：**動物の記憶。** 紙魚の、紙を食う動き。**問いを持たない**——餌を探しているのでも、増えたがっているのでもない。そうしていた動きが、そのまま在る。
  - **紙魚は絶えている。** 先代のころにわき、書庫ごと燻蒸された。以来一匹も見ていない。**生きた群れの記憶ではないので、同源の規則で消えるものは無い。**
  - **駆除したから残った、という筋にはしない。** 取り消しの拒否は『家』の理屈。ここは居た動きが残っているだけ。
  - **なぜ濃いのかは決めない。** 住職の見立て（寺の中で強まった）は当て推量のまま。「場の力が別系統の記憶を強める」を規則にしない。
- **数**：千二百余。**まっとうに、蔵書に湧いた虫の数としてそれくらい居た。**
- **いつから出ていたかは決めない。** 本が落ちはじめたのは春先。

## 目印——札が現場になる

- **記憶は蔵書の全体に薄く広がっているので、ふつうなら差が出ず白いまま。** ところが**札もまた紙で、記憶はいちばん近い紙へ移ってくる。** 差の出ないはずの場所で、札の上にだけ差ができる。
- **三枚とも、自分のところを指す。** 線が引けない。
- **焦げは、距離ゼロの焦げ。** 遠いほど広くぼやけ、近いほど狭く鋭い（[札.md](../札.md)「消耗の出方」）の極北で、源が札の上に乗れば消耗は点になる。**新しい規則ではない。**
- **しかも動いている焦げ。** 源が札の上を移るので、点が増えてつながる。**切れは消耗ではなく損壊**——焦げた紙が食われて抜けた穴の成れの果て。

**裂けとの見分け（設定として持つ。本文で表にしていない）**

| | 裂け | 切れ |
|---|---|---|
| 色 | **必ず伴う。** 色の上に乗る | 伴わないように見える。**縁だけが焦げている** |
| 位置 | 消耗の中心と同じ位置から入る | **点から始まり、点がつながる** |
| 時間 | 浴びた時点で出る | **進む。見ていれば進むのが分かる** |
| 匂い | —— | **焦げの匂いがする** |

- **「裂けは札が自ら破れる」という機序は、大上に悟らせていない。** 観察どまり。

## 厄除け

- **厄除けは傷まない——はじめの数晩は。** 選んで吸い、自分が傷んで焼く札なので、紙魚の力では貫けない。目印は受けるだけで身を守らない。
- **数晩たつと、縁がうっすら焦げる。** 力を焼いた痕。
- **厄除けは、紙魚を焼いている。** 弱い相手なら、来たものをそのまま焼いて片をつける札（[札.md](../札.md)「厄除けでは、焼いてしまう」）。**一晩ごとに、来た分だけ減る。** 祓いの分割と同じこと。
  - 『番』の数で見える——千二百余（一日目の晩）→千百余（厄除けを貼って四晩）→千余（一週間後）。**三枚なら週に百ほど。** 合になるまで三月ほどの見込み。
  - **合になれば、もう貼らなくてよい。** 記憶は焼けて残らない（何だったのかは、大上が先に読んでいる）。

## 『番』の数

- **一晩回らせると「千二百余多し」。** 全部が紙魚。
- **蔵書は一冊も多しに立たない。** 書庫の場の記憶は、新しい本が棚に収まることを自然なこととして受け取る。
- **場が何を自然な住民と認めるかは、場ごとに決まる。** 家にとって虫も鼠も人以外の住民で、数に立たない。**書庫にとって紙魚は住民ではなく、書庫の形を害する敵。** 認めないものが千二百余居るので、多しに立つ。**『家』の「何を満ちた形とするかは根城ごとに決まる」と同じ形。**
- **本文では説明していない。** 大上はなぜ本が立たないのかを考えていない。
- **書庫が一息に読めるのは、戸で区切られた一室だから。**
- **焼けていく目盛りとしても働いた。** 減っていく数を、大上は「焼いとる」の物証として読んだ。

## 始末

- **引き取っていない。** 理由は恐れ（紙を食う虫を紙の綴じ本に入れたら、帳面が食われるのではないか）。**記帳は紙の上にないので、恐れは当たっていない。本編では解かない。**
- 厄除け三枚を棚の三方に。**大上が週に一度、貼り替えに来る。合になるまで。** 一回三千円、手間賃なし。
