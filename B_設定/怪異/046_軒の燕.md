# 怪異「軒の燕」

**第四十六話／中央区大名。** 和菓子屋「陣内」の軒を、四十年ぶんの燕がくぐっていた記憶。**引き取っていない。焼ききってもいない**——本家が厄除けを三日だけ貼り、依頼人の頼みで剥がした。いまも軒をくぐっている。回の側は[話別設定/046](../話別設定/046_軒_設定.md)、骨格は[I037](../../C_執筆管理/話アイデア/執筆済み/I037_046_軒の燕.md)。

- 現象：**暖簾をくぐる人が、何も無いのに首をすくめる。** 頭の上を何かがかすめた気がする。**五月から**（今年の燕が四月に来て、向かいの床屋へ移ったあと）。
- 正体：**動物の記憶。** 代々の燕が、毎年同じ高さでこの軒をくぐっていた動き。一羽の、ひと番いのものではない。
  - **群れの記憶は、群れの個々と同源ではない**（[記憶と怪異の法則.md](../記憶と怪異の法則.md)）。焼いても、向かいの燕にも南の燕にも何も起きない。本家は考えていない（引き取らないので要らなかった）。
  - **出てきたきっかけは巣が落とされたこと。** 本家の誤訳（今年の燕が、落とされた巣を探しに来ている）は外れ。**問いを持たない**——くぐる先の巣を失っても、くぐる動きが続いているだけ。
  - 裂けは無い。人に害は無い。
- **目印は薄い焦げ。** 交点は庇の上の、巣の泥の弧。薄い理由は決めない（本家の読みは、一羽ずつはひと夏かふた夏しかくぐっていないから）。
- **厄除けで焼ける。** 三日で指の先ほど、一枚で十日、彼岸まで八枚——本家と陣内さんの見込み。**三日ぶん焼けたところで剥がした。** 焼けたぶんは戻らない。
- **秋に去るかどうかは決めない。** 来年、陣内の巣台に燕が来るかどうかも書かない。
