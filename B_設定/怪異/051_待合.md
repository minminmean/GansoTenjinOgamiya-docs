# 待合（小笹坂上の停留所）

**第五十一話／中央区小笹、坂の途中の架空の停留所「小笹坂上」。** **場の記憶。** 回の側は[話別設定/051](../話別設定/051_小笹坂上_待合_受_壱_設定.md)。

- **器は屋根の下。** 細い柱二本に薄い屋根を渡しただけの小さな待合所で、壁も柵も無い。**内が言えれば区切りは立つ**（[記憶と怪異の法則.md](../記憶と怪異の法則.md)「霊的な区切りとは」）。この辺りの停留所は標柱だけか屋根だけが多く、ここは屋根の下にベンチがある。
- **待つことに触れて育った場。** 何十年ぶん、屋根の下でバスを、人を待った人たちの「座って待つ」に触れて育った（[記憶と怪異の法則.md](../記憶と怪異の法則.md)「場の記憶は、無から生まれて育つ」）。**誰を待っていたかは持っていない**——それは待った人の側のもので、坂を上って家まで持って帰られた。**待ち人はいない。**
- **現象。** 屋根の下のベンチに座ると、立ち上がる気になれない。背もたれの無い、長く座れないように作ったベンチが、どこよりも座り心地よく感じられる。誰のことも考えないまま、ただ待っていられる。昼は年寄りがバスをやり過ごし、夜は終バスに手を上げて乗らず、朝まで座っている。**害は弱い**（定型回の水準）。
- **目印は黄ばみ。三本は一点で交わらず、屋根の縁をなぞる**（前の縁、坂上の端、坂下の端）。**中心は区切りそのもの。** ベンチを指す線は無い。第十一話の敷居（源が境）に近く、第四十八話の結界型（内が白く外が黄ばむ）とは違う——屋根の下は仕切りが無いので、外へ洩れる。
- **呼ばれれば終わる。** 待っていたものが来て名を呼べば、腰が上がる（始発の運転士の「兄ちゃん」）。本文では「自分で立ったのか、呼ばれて立ったのか、分からなかった」まで。
- **引き取ったあと、ベンチは見たとおりの座り心地に戻った。** 本文では理由を書いていない。
- **大上の読み。** 「誰かを、待っている」と読み、待ち人を探して聞き込みを重ねた。待った話は出てきすぎて、一人に決まらなかった。夜通し座って、自分が誰のことも考えていないのに気づき、「ここは、待つところだった」と読み直した。**誤訳を自分の身で正した**ので、当たったとは書いていない。
- **記帳は夜明けの屋根の下、無人で**（「小笹坂上　待合　受　壱」）。仕切りが無いので、帳面の気配は道の向こうのコンビニの前まで届いた。
- **力は「座って待つのが苦にならない」。** 人には作用しない。**まだ発現していない。** 新天町の夜番（立って待つのが苦にならない）と同じ種類で、積み重なると「姿勢によらず、じっとしているのが苦にならない」になる（[帳面.md](../帳面.md)「力の借用」）。**大上は力だと思い当たらない**（『取次』と同じ扱い）。
- 主は場所なので、同源の規則で消えるものは無い。待合所はそのまま立っている。
