# 第一話　元祖

**第一話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)、本文を直すときの縛りは[各話の規則/001_第一話.md](../../C_執筆管理/各話の規則/001_第一話.md)。相手は[怪異/増えるもの](../怪異/001_増えるもの.md)。

- **本文は（１）（２）の二つに割ってある**（2026年10月12日、完結後の改稿で）。割れ目は、遥の家から靴下で帰った晩、薬院の玄関でスニーカーが二足になっていて「数えなかった。」の直後。**この設定ファイルも各話の規則も掲載表も、第一話一本として扱う。**
- 開業二十七日目（金）。二十七日で売上三万五千円、家賃四万二千円。
- **遥が来たのは二十八日目の土曜。** 土曜出勤の帰りで、急ぎの仕事はなかったと自分で言う。家に居たくなかった（空に近いコンビニの袋）。意味づけは本文に書かず、読者に任せる。
- 空模様：二十八日目は夕方まで雨で、上がったところへ遥が来る（看板をビニールから出して縛り直した直後）。七時を過ぎても空は明るい。靴下の夜道は雨上がりの舗装。二十九日目の朝は、夜のうちにまた降って坂の舗装が濡れている。同じ日の昼の路上は日差し。
- 二階の八畳の畳に、箪笥を出した跡が四角く青く残っている（四十九日の翌日に遺品を処分した跡）。
- **二十七日間で看板の前に足を止めたのは四人**（三人は地図アプリ、一人は「元祖ってことは本家があるんですか」と訊いて信号が変わった人）。**依頼に至った客はゼロ。** 二件の仕事はどちらも足で取ったもので、看板経由ではない。坂口遥が**看板から来た初めての客**であり、**看板の前にいちばん長く留まった人間**でもある。ここを崩すと「誰も止まらないはずの流れの中で、一人が止まった」が成立しない。
- 店の設え：折りたたみテーブル八百円（脚が一本ぐらつく）、パイプ椅子四百円、ともにリサイクルショップ。看板はベニヤ板に千五百円。厄除け三枚を三千円の値札で並べ、隅に「怪異　ご相談ください」の紙。**相談料は書いていない**（相場を知らないから）。
- 手持ちは札十二枚（留め六・祓い四・目印二）と現金二万三千円。厄除け三枚は店頭。
- **三万円の退治**：足で稼いだ、やっとの一件。留めで止めて祓いを一枚打った。効いた。だが「いま消したものに名前はあったのか」が残る。**引き取りに行き着く動機の根**。なけなしの一件だったからこそ重い。**第一話の時点では、打たない理由が本人にも言葉になっていない。** 言葉になるのは第五話の冒頭で、そこで「怪異を祓いたくない。祓ってしまえば消える。消えれば何もわからない。ならば、抱えてしまいたい」と述懐する。**以後は言語化済みとして扱ってよい**（第十話「何もわからないまま消してしまうことは、やはり嫌だった」）。**まだ結び付いていないのは、番外で同じ答えを一度受け取っていること**のほう。
- 依頼人は坂口遥。前金二万、残金三万。
- 目印を廊下の柱に貼るが何も出ない。**場全体が濃すぎて差が出なかった**（無反応は「力がない」ではない）。
- 二階の八畳間に仏壇と、崩れかけた座布団の山。数えなかった。仏壇の縁に貼った留めは、翌日**二枚になっていた**。
- 夜、安藤が薬院に来る。**白い布**で三和土のスニーカーを一足減らす。札も祝詞も使わない。自分を削っている（大上は知らない）。
- 安藤は家に上がらず外で待つ。上がって何かを置けば、抱えているものごと登録されるため。
- 大上は靴を置いて帰ったので、**すでに坂口家の家人として数えられている**。安藤「なら、まだ外にある」＝家の外ではなく、お前の外。
- 二十九日目、母三人。「捨てなければいい」に到達。**札十二枚の裏に屋号を書き、引き取りを発明する。** 祝詞八文字→「元祖天神大上屋、大上大介がお受けします」。
- 引き取り：箸五膳・湯呑み四つ・スリッパ三足・歯ブラシ五本・スニーカー二足。札で包んで紙袋へ。帳面はまだない。
- 「人は、引き取れません」「うちは、そこまでの店やないとです」。
- **三人を等しく扱う指示**：大皿と鍋で出す。めいめいに盛らせない。茶碗も箸も新しく出さない。買わない。引き取ったぶんも戻させない。遥だけは自分の茶碗で食べる。
- 安藤「看板、書き直せ」「元祖の字が薄い。屋号は、はっきり書いとかんと通らん」。役所の書類の話をするような言い方。
