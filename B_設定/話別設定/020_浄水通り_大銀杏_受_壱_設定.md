# 第二十話　浄水通り　大銀杏　受　壱

**第二十話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/大銀杏](../怪異/020_大銀杏.md)。縛りは[各話の規則/020](../../C_執筆管理/各話の規則/020_第二十話.md)。

**定型回の十一本目。時期は決めない。** I012（[話アイデア/I012](../../C_執筆管理/話アイデア/執筆済み/I012_020_浄水通りの銀杏.md)）から起こした。**植物の系統の二本目**で、高砂一丁目の楠に続く。**帳面は一行も増えない。**

- **題は「浄水通り　大銀杏　受　壱」。** **記帳は無いが、行は立った**ので、その行を題にした（第十四話と同じ扱い。[PROJECT_RULES.md](../../PROJECT_RULES.md)「話の題」）。
  - 本文では**頭の中で書いてみた行**として一度だけ、二字下げの独立段落で出る。**帳面にも手帳にも書いていない。**
  - **同源の規則が明かされたあと、題が遡って効く**（[記憶と怪異の法則.md](../記憶と怪異の法則.md)「帳面は、同源を一つと読む」）。
- **品名は、草案では「銀杏」だった。** 並木の樹種を確かめておらず、宛先が一本に絞れるかが怪しかったので「大銀杏」にした。**周りよりひときわ大きく、界隈で名が通っていて、周りの人がそう呼んでいる**（吉武さん、酒屋の主人）。第十三話の「楠」と同じく、呼び名が人のほうに残っている形（[帳面.md](../帳面.md)「品名は、指す者がいて初めて立つ」）。

## 芯——書けるのに書かない

- **品名も数も立つ。** 場所は浄水通り、並木の銀杏は何本もあるが大銀杏はこの一本、数は一本。**頭の中で書いた行が、どこにも引っかからない。それが気味悪い。**
- **止めるのは安藤の一言。**「その木は、生きとるとか」「生きとります」「生きとるもんは、受けたらいかん」「なんでですか」「知らん。やったことなか」。
  - **理由を説明させていない。** 同源の規則は伏せたまま。
  - **「高砂のときも、この人は同じようなことを訊いた」の一行を置いた**（第十三話「その木は、まだ在るとか」）。安藤が生死を確かめる人だという物証だけで、**なぜ確かめるのかには触れていない。**
- **大上の引っかかり。**「生きているものなら、前に受けたことがある。坂口の家で書いた晩に」「やったことがない、というのは、あの人の話だ。俺の話ではない」「それでも、帳面は出さなかった」。
  - **命があるから受けない、とは言わせていない**（[話アイデア/I012](../../C_執筆管理/話アイデア/執筆済み/I012_020_浄水通りの銀杏.md)「注意」）。**押し通しかけて、引く。**

## 舞台と人物

- **舞台**：中央区浄水通り。両側に並木があり、低い建物の一階に服屋・菓子屋・花屋が並ぶ。**並木の銀杏のうち一本だけがひときわ大きい**（大人二人でも腕が回りそうにない。幹の皮が厚く割れ、下にこぶがいくつもあり、枝が両隣の木の上まで出ている）。**市の街路樹。**
  - **根元の四角い囲いから根がはみ出し、縁石が浮き、タイルが三枚割れて段になっている。** 段はいちばん高いところで**四センチ**（大上がメジャーで測った。第十三話で買った安物）。区役所が置いていった赤いコーンが一本。
  - **来歴**（角の酒屋の主人の話）：昔このあたりにあった屋敷の、庭の隅の木。道を広げるときに塀が下がって、木だけが歩道に残った。**ほかの並木は、そのあとに植えたもの。** 屋敷の家の名前は主人も覚えていない。**誰かが死んだ、祀った、切ろうとして何かあった、の類は一つも出ない。**
  - **区役所**：古い木なので、根に手を入れるのは慎重にしている。根を切れば弱る。弱れば倒れる。
  - **実在の通り。並木の樹種は確かめていない。** 本文は「並木の銀杏は何本もある」で通している。
- **吉武さん**：四十代半ば。浄水通りの眼鏡屋、親の代から三十年。**持ち札は責任。**
  - **来かた**：店を開けたとき、既に客用の椅子に座って息を整えていた。**看板を見ても、読んだ顔ではない**（『番』の代償。机と客用の椅子は員数の外なので目に入る）。
  - 先月、七十過ぎのお客さんが遠近両用を作り直して受け取り、**店を出て三歩目で段に転び、手首を折った。**「うちで作った眼鏡ば掛けて、うちの前で転んだとです」。
  - 区役所に「木ば切ってくれ」と言って断られた。**依頼が「木ば拝んでもらう」の形でずれている。ずれているのは、ほかに頼むところが無いから。** 無知にしていない。
  - **怖がっていない。困っている。**
  - **降りられない事情**：「また誰か転んだときに、うちは何もしとらん、ち、なるとがいちばんきつかとです」。
- **酒屋の主人**：八十近い。「大銀杏ね」「あれは、道の広うなる前から立っとったとよ」「昔から止まりよったよ。わしも止まる」。

## 現象（怪異ではない）

- **夕方、大銀杏の下で人が止まる。** 歩いている人の半分くらい。一歩か二歩ぶん、長くて三つ数えるほど。上を見て、何を見たのか分からない顔をして歩き出す。**急いでいる人と自転車は止まらない。**
  - 大上が数えて、**一時間に四十三人が通り、二十六人が止まった。**
  - **大上自身も止まる。** 何を見ようとしたのか、自分でも言えない。
- **止まった人は理由を言えない。** 転んだお客さんも止まって上を見ていて、足元を見ていなかった。
- **実害は段のほう。** 止まることそのものは、誰にも何もしていない。

## 調べ

- **目印三枚**：吉武さんの店のシャッターの脇、並木を二本先へ行った街灯の柱、道を渡ったバス停の標識の柱。**銀杏には貼っていない**（理由は書いていない。草案にあった「市のものだ」は、街灯も市のものなので削った）。
  - **翌日、三枚とも濃く湿る。** 高砂の駐輪場で見たのより濃い。黄ばみも焦げも裂けも無い。**三本の線は幹で交わる。**
  - **理屈の段は畳んだ。** 焦げ始めた向きも「一枚では線が一本引けるだけだ」も書いていない。**交わるところまでで足りる**（[札.md](../札.md)「執筆上の扱い」——初出より解像度を落とす）。
  - **二日目も三日目も同じ。濃くなってもいない。薄くなってもいない。** 怪異でないことの物証だが、**大上は読んでいない**（[札.md](../札.md)「二人の読み方の差」）。
- **聞き込みは角の酒屋、電話は区役所。** 調べて出たのは「百年ぶんの木が、百年ぶん立っていた」だけ（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「真相が分かりませんでした、で帰らせない」——調べたら出て、出たうえで怪異と繋がっていない）。
- **『番』は回していない。触れていない。**

## 始末

- **引き取らない。祓わない。**
- **歩道の話として返す。** 段の高さ、割れたタイルの枚数、測った日付を書いた手帳の頁を破って渡す。「区役所には、木のことやなくて、歩道の段のこととして言うてください」「木ば切ってくれ、は通らんでも、段ば直してくれ、は向こうの仕事です」。吉武さん「……拝み屋さんの仕事やなかですね」、大上「はい。うちの仕事やなかとです」。
- **大上の誤訳**：「みんな、挨拶しよるとやなかですか。古か木やけん」。吉武さんは目を丸くして笑う。「誰も、頭は下げとらんですよ」。**外れている。植物の系統なので、人の物差しは載らない。** 地の文で機序を書いていない。
- **厄除けは断る。**「あの木には、除けるもんの無かとです。厄除けは、貼っても紙のままです」。
- **境目の札を、依頼人の前で貼る。** 鞄の底にあった、第十八話で書き起こして使わずに残っていたもの。
  - 「効くかどうかは、分からんとですけど」「境目の札、ちゅうとがあります。区切りば作る札です」「木の周りに貼っとくと、木の声が、通る人に聞こえにくうなるかもしれんです」。
  - **根元の囲いの縁石の四隅に一枚ずつ。八文字。** 何も起きない。紙は白いまま縁石に貼りついている。
  - 吉武さんは四枚を順に見て回り、赤いコーンを段の真上に置き直す。「これで、何もしとらん、ち、ならんで済みます」。**店主の不安に添う形。**
  - **設定側の効き**：強い霊格を囲ったので、封印に近い形で働く。**場の記憶の種は立ったが、木が器を支配しているので育ちにくい**（[札.md](../札.md)「区切りは弱い。時間をかけて馴染む」「強い霊格を囲えば、封印に近くなる」）。**本文では匂わせない。効いたかどうかも書かない。**
  - **草案では、終わったあとに一人でこっそり貼りに行く形だった。** ボランティアが過ぎるうえ、店主の気持ちに寄り添えていないので改めた。
- **骨格（I012）の「札も置かない」からは外れた。** 帳面が一行も増えないのは変わらない。

## 数と値段

| | |
|---|---|
| 見積 | 見に行くのに一万、引き取れば別に二万 |
| 実際 | **一万千円。** 見に来たぶんの一万と、境目の札の札代千円。封筒で受け取る |

- **札代は四枚で千円。** 四枚そろわないと働かない札を、一枚ずつ数えて取る男ではない。**厄除け、占部の御守と同じ値段**になり、占部の場面に繋がる。
- **「取れる金も返す」は出していない。** 見に行った仕事のぶんは取っている。

## 占部きみ子——役に立たないものでも、人の役に立つ

- **名前は本文に出ない。** 地の文は「占いのおばさん」。
- **大上は、効くかどうか分からないと自分で言って取った千円のことを、まだ考えている。** そこへ若い女の人が手相を見てもらい、開運御守を千円で買う。**中に何も入っていないのを、大上は知っている。** 女の人は袋を両手で持って笑い、来たときより背が伸びて見え、軽くなって帰っていく。
  - 「あれには、何の力も無い。／それでも、あの人は来たときより軽くなって帰っていった。」**そこで止める。** 教訓の一行（「力が無くても、いいことはあるのだ」）は削った。
- おばさんは「あんた、何ば売りよると」と訊く（何度目か、もう数えていない。『番』の代償）。「そんなら、ああいうとも一緒に置いたらよかとに。千円で売れるよ」。**大上は「うちのは、と言いかけて、やめた」。**
- **助言にしていない。世間話。当たる占い師にしていない。** 明るくなった側だけを書いた（[登場人物.md](../登場人物.md)「運が、いい」）。

## 人の出し方

- **本家**——**型①（路地の口）。** 一報は「本家の携帯に、浄水通りに行く、とだけ入れた」の一行。場面は締めの店じまい。
- **安藤**——**電話一回。対面なし。** 缶コーヒーの二度目は消化していない。
- **占部**——上記。
- **播谷・税所は出ない。**

## 締め——本家との短いやりとり

- 店じまいの路地の口。「浄水通りは」「受けんかった」「そうですか」。
- **本家が占部から開運御守をもらっている。**「三つ隣の方が、開店祝いち言うて」。**どの開店のことかは、訊かなかったらしい**（代償を説明しない）。袋を指で押しても中で何も鳴らない。鞄の内ポケットにしまって口を閉める。
- **型の一覧では第四話・第九話に続く三度目。** 第十九話（金の勘定）、第十八話（街の景色）と続いていない。**振り返りは途中（吉武さんの店からの帰り道）に一度だけ置いた**——第十八話の締めが振り返りなので、締めには使わない。

## 方言

- **「ちいう」ではなく「ちゅう」で揃えた。**「持って帰る、ちゅうことです」「境目の札、ちゅうとがあります」。冒頭の吉武さんは「っちゅうとは」。

## 書いていないもの

- **同源の規則。** 受ければ木ごと消えることは伏せたまま。
- **「伐ってから引き取る」手。** 吉武さんはもともと切ってほしい人だが、誰にも言わせていない。
- **帳面の重さ、記帳の気配。** 記帳が無い。**『家』『番』の呼び名も出ない。**
- **境目の札が効いたかどうか。**
- **並木の樹種の実景。**

## ルビ

- **「銀杏（いちょう）」を本文の初出（吉武さんの話の「店の前の歩道に、銀杏（いちょう）が一本ある」）に丸括弧で書いた。** 特例は[テキスト変換規則.md](../../Z_その他/テキスト変換規則.md)。**辞書には入れない**——第十五話の「銀杏ではない」に食い込む。
