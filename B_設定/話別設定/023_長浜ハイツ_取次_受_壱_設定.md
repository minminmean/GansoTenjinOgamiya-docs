# 第二十三話　長浜ハイツ　取次　受　壱

**第二十三話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/取次](../怪異/023_取次.md)。縛りは[各話の規則/023](../../C_執筆管理/各話の規則/023_第二十三話.md)。

**定型回の十三本目。季節は秋、十月の半ばから先**（第十六話より後、第二十四話の十一月より前）。**日付は決めない。** I015（[話アイデア/I015](../../C_執筆管理/話アイデア/執筆済み/I015_023_二軒でやる仕事.md)）から起こした。**人の系統の四本目**で、ホテル白水、清川の牟田さん、堤書店に続く。**題は記帳の行そのまま。**

**初対面の人物に姿と癖を描き、場面ごとに季節と空模様を置いた最初の回**（[PROJECT_RULES.md](../../PROJECT_RULES.md)「場面は目に浮かぶように書く」）。

## 芯——同じ一件が、二件として動く

**『番』の代償が、初めて商売の段取りそのものを壊した。** 怪異は一つで、二つあるのは商売のほう。

- **依頼人は同じ件を二度頼んだ。** 表の店で元祖に頼み、財布に名刺をしまって店を忘れ、天神を歩いて高架下の路地で本家を見つけ、**別の拝み屋だと思って**頼み直した。「一軒では心もとない」。
  - **間抜けにしていない。** 頼んだことは覚えている。忘れたのは店と顔だけで、それは代償の側。**保身の持ち札が、二軒に頼む判断をそのまま普通のことにしている。**
- **一報は完璧に回っていて、それでも重なった。** 四畳半で「明日の昼は、出ます」「俺は明後日の昼に出る」を交わしている。**運ぶのは在・不在だけで、行き先を言っていない。** 地の文は何も言わない。「一報は入れとったのに」とも言わせていない。
- **二人とも、同じことを同じ順にやった。** 同じ値段を言い、同じ名刺を渡し、同じ場所に三枚貼り、江藤さんに押してもらい、同じ葉書を見せてもらった。
  - **目印は六枚、位置も焦げの中心も広がり方も濃さも同じ。**「六枚並べても、三枚ぶんのことしか分からなかった」。**丸ごと無駄。**
  - **一日空いた二組でも、差は出ていない。** 目盛りを読む材料にはしていない（I015の「候補」は採らなかった）。
- **二度頼まれていたと分かる場面は、笑いに振った。** 江藤さんの部屋で「昨日のお兄さん」「昨日も来たろうが」「昨日も見せたろうが」。**江藤さんは本家を元祖と取り違えただけで、顔が同じなのだから当然。『番』の代償ではない**（本家は江藤さんに屋号を名乗っていない前提）。「顔は、同じだ。」で落とした。

## 大上のクセ——取れる金を返す（本家と並べて）

**一つだけ。** 依頼人は二軒ぶん払うつもりでいた。**取れる金だが、取らない。**

- **本家が一度だけ言う。**「調べは、二人ぶんやっとります」。勘定としては合っている。**押さない。**
- **元祖は「頼まれたとは、一件たい」を二度言う。** 本家は「はい」で受ける。**説明させていない。**
- **樋口さんも同じことを言う。**「調べは、二軒ぶんしてもろうとるとでしょう」——「本家と同じことを言った」。二人が正しくて、片方だけが手間を負う（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「クセは、対比で見せる」）。
- **増長は出していない。** 褒める場面を置いていない。

## 本家が先に動いて正しかった場面

**一度だけ。** 江藤さんから「明日の昼にも拝み屋の来るげな」と聞き、元祖の「明後日の昼に出る」と結びつけて、**先に気づいた。** 翌朝、合鍵を樋口さんの郵便受けに返すとき、紙を一枚付けた。

　　表の店と同じ店の者です。続きは、表の者が伺います。

- 元祖はそのとき、江藤さんの部屋で何も考えていなかった。**「助かった」「はい」。それだけ。** 含みを持たせていない。
- **気づいた手がかりが一報だったことを、地の文で言わない。**

## 舞台と人物

- **舞台**：中央区長浜、魚市場のほうから二本入った通りのマンション「長浜ハイツ」（**架空**）。七階建てで築は古い。外壁のタイルが貼り替えたところだけ新しい。
  - **玄関は二重。** 外の自動ドア → 狭い風除室（呼び出しの盤。**部屋番号の下に一つ離れて「管理人室」のボタン**、字が擦れて白い。**盤の上に小さい丸いカメラ**）→ 内側のガラス扉 → 玄関ホール。ホールの左手の壁に**管理人室の窓口（小窓）**、カーテンが引いてある。
  - **管理人室**：四畳半ほど。窓口に向けて机一つと椅子一脚。壁に鍵を掛ける板（フックの半分が空き）。机の上に受話器付きの機械と小さい画面（盤と繋がっている）。机の端に、宅配の会社の名前と来る曜日を手書きした黄ばんだ紙。奥に流し。
  - **長浜の匂いは豚骨**（[基礎設定.md](../基礎設定.md)「舞台」）。
- **樋口さん**：六十を半ば過ぎ。痩せていて、白髪を短く刈り込んでいる。灰色のジャンパーの前をいちばん上まで閉め、**背広を着ていないのに背広を着ているような立ち方。** 輪番で今年だけ理事長。**元銀行員という設定は本文に出していない。**
  - **癖：ジャンパーの引き手をつまんで、いちばん上まで閉まっているのを確かめる。** 初対面で一度、「私の年に」のあと、精算の「私の年のことですけん」のあとで、**計三度。以後の回で使わない。**
  - **持ち札は保身。**「私の年に、こげなことにならんでもよかったとですけど」。**恥ずかしそうに言う。** 二軒に頼んだのも同じ札で、**言い訳にしていない。**
  - **降りられない事情**：防犯（誰でも入れるなら防犯にならない）、気味悪がって理事会に言ってくる住人、**来月の総会。**
  - **締めの台詞**：「総会では、直りました、とだけ言います」「何が、とは、訊かれんでしょう」。少しだけ笑う。
  - **封筒を二つ用意してきた**（ボールペンで小さく「一」「二」、三万ずつ）。
- **江藤さん**：四階の角部屋。八十過ぎ。小さい。**白い髪をネットでまとめ、カーディガンのボタンを一つ掛け違えている。耳が少し遠いのか、話すたびに顔を寄せてくる。** 居間は南向きで、ベランダの鉢植えの影が畳まで伸びる。
  - 末次さんといちばん長い付き合い。**喪中の葉書を座卓の下の箱に取ってある。**
  - **二日続けて同じ葉書を見せ、二日続けて盤を押した**（一度目は本家、二度目は元祖。本人は同じ人だと思っている）。
- **宅配の運転手**：四十くらい、首まで日に焼けている。制服の帽子。**帽子のつばを指で押し上げながら喋る。** この区域を回って十五年。管理人室を押して入るのが当たり前で、「管理人さんでしょ」「……奥におらすとでしょう」。
- **末次さん**（前の管理人）：**二十年勤め、三年前に七十を越えて辞めた。** 娘さんのところへ移り、**去年の十月に八十歳で亡くなった**（喪中の葉書。差出人は娘さん、去年の暮れの日付）。住人の顔を全部覚えていた。**下の名前は本文に出していない。**
  - **管理は三年前から巡回に切り替わった**（管理会社の人が週三回、午前中だけ）。**辞めたのは本人の歳で、誰かのせいではない。** 原因となる所業を置かないため。

## 数と値段

| | |
|---|---|
| 見積 | 調べるのに二晩で一万、引き取れば別に二万。**元祖も本家も同じ額を言った** |
| 依頼人の用意 | 三万ずつの封筒を二つ（計六万） |
| 実際 | **三万。「一」の封筒だけ。** 引き取りのあとに受け取る。「二」は内ポケットに戻る |

- **調べは元祖が二晩と江藤さん、本家が一晩と江藤さん。** 請求には何も乗せていない。
- **値段は第十八話・第十九話と同額。**

## 調べ

**登記も住宅地図も『番』も使っていない。**

- **一晩目**（元祖）——日が落ちてから長浜へ。管理人室に目印を三枚（窓口の枠、鍵の板の脇、流しの上の壁）。ホールの隅で待つ。**九時過ぎ、宅配の運転手が管理人室を押して「はい、どうぞ」、扉が開く。** 運転手が出たあと元祖が押すと、鳴るだけで返事は無い。
- **翌朝の目印**——三枚とも焦げ、濃い、人ひとりぶん、裂けなし。窓口の枠は狭く鋭く、鍵の板は右寄りから、流しの上は左の下から。**交点は窓口に向けた椅子。** 手順は二文で流した（「一枚では、線が一本引けるだけだ。三本を延ばした」）。
- **樋口さんへの電話**——末次さんの名、二十年、辞めて娘さんのところへ、「亡くなったげな」。**生死は確かめなければならない**（「生きとるもんは、受けたらいかん」、第二十話）。江藤さんを紹介される。**樋口さんが押せば返事が来る。**
  - **大上の読み**：「末次さんは、画面の顔を見て開けていたのだと思う」。**人の系統なので当たっている。当たったと書いていない。**
- **二晩目**（元祖）——若い女の人が指を迷わせて管理人室に触れ、返事なし、部屋番号で開けてもらって小窓の前を足早に過ぎる。**十時過ぎ、年寄りの男の人が押して「はい、どうぞ」。** 帰りに合鍵を郵便受けに返す。
- **本家の調べ**（語りの外）——二日目の午後に樋口さんから同じ件を受け、**合鍵の二組目**を借りる。三日目に同じ三か所へ目印を貼り、夕方に病院帰りの江藤さんに会って押してもらい、葉書を見る。四日目の朝に目印を読み、合鍵を紙と一緒に返す。
- **元祖が江藤さんに会うのは四日目の昼。**

**合鍵は二組**（「玄関と管理人室のと、理事会で二組、預かっとります」）。**一組目が元祖、二組目が本家。** 樋口さんが同じ顔の二人に鍵を渡しても気づかないのは、店と顔を忘れているため。

## 引き取り

- **人払いは段取りとして流した。** 樋口さんには外の自動ドアの向こうにいてもらい、**元祖が携帯を一回鳴らしたら管理人室を押してもらう。** 元祖は管理人室に入って戸を閉め、カーテンも閉めたまま。**仕切りが二枚ある。**
- **品名と数は、来る道で決めてあった。**
  - **末次さんとは書かない。** 残っているのは人ではなく、毎日くり返されていた一続き（ボタンが鳴る、画面の顔を見る、知った顔なら返事をして開ける）。**「来た人を、中へ取り次ぐ。管理人の仕事の言葉だ」——取次。**
  - **宛先はマンション名。**「行の頭は、長浜では広すぎる」。
  - **壱。** 返事をするのも開けるのも、ひとつの取次の中にある。
  - **第十九話の「名前で書けば、堤さんを書くことになる」とは言い回しを変えた。** 同じ組み立てを同じ文で繰り返さないため。
- **書く瞬間**：機械が鳴り、画面に風除室と樋口さんが映る。膝をつき、祝詞八文字。**声が机の上から「はい、」まで出る。** 名乗ると、**続きは来なかった。** 気配は一文（「壁の鍵の一本ずつまで、数えられていた」）。

- **止まったことだけを書いた。** 理由も因果も書かない（[PROJECT_RULES.md](../../PROJECT_RULES.md)「大上が知らないこと」、結界の項）。**手順をなぞるだけの相手なので、足を止めた以上には見えない。**
- **引き取りが済んだ合図は現場の側。** 画面の中で樋口さんが扉を見て、扉は開かず、もう一度押しても返事が無く、画面が暗くなる。樋口さんは自分の鍵で入ってくる。「開かんやったです」。
- **樋口さんの「顔と名前ば、全部覚えとらした」は、何にも繋げていない。** 引き取った力（顔は覚えるが、名前は付いてこない）が発現する回で効く一文。

## 締め——手を動かして終わる

**第十四話以来。第二十二話（物に残った痕）と続いていない。**

- **名刺に一行足した。** 無地の紙を名刺の大きさに切って一から書き直し、いつもの場所の下に一行。

　　一本裏、高架の下にも、おります

- 「おります、でよかとですか」「どっちにも、おるけんな」。
- **寝る前に、その日受けた客を言い合うことにした。** 言い出したのは元祖。
- **増やすのは明日。前の名刺は捨てれば湧くので、配り終えるまで配る。** 新しい一枚を前の一枚の上に重ねて輪ゴムで留め、**「明日からは、二枚ずつ渡す。」**
- **第六話で残した、名刺が一枚しかないことの始末がこれ**（[話別設定/006](006_名刺_設定.md)）。

## 人の出し方

- **本家**——**型④（手を分ける）。** 一報の場面（「今晩、長浜に出る」「はい。表は、暮れるまで見ときます」、四畳半の「明日の昼は、出ます」）、突き合わせの場面、名刺の場面。**内面には入っていない。**
  - **「千早の厄除けを見に戻ってから帰る」**の電話で、三日目の晩に帰りが遅かった理由を置いた（第十九話と同じ現場）。
  - **本家の一人称・口調**：敬語。「頼まれたとは、いつや」に「一昨日の昼です。路地に来られて」。
- **安藤**——**電話一回。** 報告に「ああ」、生死の確認に「そうか」、二人で受けていたと言うと少し間があって「二人おるなら、二人ぶん考えろ」。**本家に直接は触れない。驚かない。**
  - **I015の案にあった「考えんね」は使っていない。** 安藤に「〜んね」を使わない規則による。
- **播谷・税所・占部は出ない。**
