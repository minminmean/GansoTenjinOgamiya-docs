# 第二十七話　権藤塾　昼寝　受　壱

**第二十七話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/027](../怪異/027_昼寝.md)。縛りは[各話の規則/027](../../C_執筆管理/各話の規則/027_第二十七話.md)。

**定型回。** [I030 回ってくる仕事](../../C_執筆管理/話アイデア/執筆済み/I030_027_回ってくる仕事.md)から起こした。**本家が調べて厄除けで押さえきれず、元祖に回ってきた初めての件。** 題は記帳の行そのまま。

**時期は一月の半ば。** 正月の飾りが街から消えたころで、共通テストまで十日。**定型回なので年表には載せない。本文に日付は出していない。**

## 芯——本家の見立てを、元祖が読む

**型③（読ませる）の裏返し**（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「本家を常設にする」）。いつもは元祖が材料を渡して本家に読ませる。**この回は、調べが済んだ状態から始まる。**

- **渡されたのは茶封筒一つ。** 目印三枚（黄ばみ）、焦げた厄除け一枚、本家の書き付け一枚。
- **書き付けは本家の字。**「家計簿で毎月見ている。見慣れているのは、それが俺の字だからでもある。」
- **同じ一枚の紙から、別の答えが出る。** 本家は「子どもば休ませよる、と見る」。大上は「十二月から昼も開けるようになった」の行が気になる。
- **差の出どころは材料ではなく、二人が持ち込んだもの**（[怪異/027](../怪異/027_昼寝.md)「二つの読み」）。
  - **本家**は権藤さんと向かい合って「今年の子は根ば詰める」「疲れとるとです」を聞いた。
  - **大上**は前の月に『朝掃き』を一月出して受け直した。誰も通らない路地でも掃き、塩まで掃き、出しているあいだも薬院の炊飯器を押した——「時刻が来れば、なぞる」。
  - **地の文で偏りだとは言わせていない。当たったとも書いていない。**
- **読みの違いが、手順の違いになる。** 本家の読みなら、休みの日の空いた部屋には受ける相手がいない（受けるなら生徒の寝ている平日）。大上の読みなら、一時になれば誰がいなくてもそこにいる。**大上は休みの日の一時を選んだ。**
- **確かめる手は立たない。** 立っていれば寝かす相手がいない。座れば寝る。「この部屋がいま、何かをしているのか、何もしていないのか。俺には分からない。」
- **本家を間違わせる回にしない。** 責めない、詫びさせない、対立させない。**締めで「俺なら、寝かしつけ、ち書いとります」「知っとる」。**

## 回ってくる形

- **寝る前にその日受けた客を言い合う段取り**（第二十三話から）の中で出た。「美野島の塾です」「収まっとらんとです」。**十日ほど前にも、同じ名を聞いている**（自習室で生徒が寝る、厄除けを一枚置いてきた）。
- **本家は判断しない。**「どうしますか、とも訊かない」。見立てについても「そこに書いとるとおりです」とだけ。
- **回ってくる理由は説明していない。** 代わりに置いたのが次のやりとり。

> 「もう一枚貼れば、また一週間は保つやろ」「保つと思います」「その次も、一枚」「はい。一週間ずつなら」——そこで、どちらも黙った。

- **毎週千円ずつ売れば済む話を、二人とも済ませない。** 屋号の決めがそのまま分担になっていることを、業務分担として説かずに置いた（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「本家は祓わない」）。
- 「明日、行く」「はい。表は、俺が立ちます」。**一報の段取り。**

## 現場と調べ

- **本家の書き付け**：美野島二丁目、権藤塾。一階が八百屋で塾は二階、奥の部屋が自習室。十二月の冬期講習から昼も開けるようになった。ストーブを消しても窓を開けても同じ。目印三枚、黄ばみ、交点は奥の押し入れ、三日貼り替えて三日とも同じ。二階は二十年ほど前まで保育所（八百屋の話）、押し入れはそのころのもの。**調べ、一万。** 厄除けを一枚、押し入れの襖に、千円。七日誰も寝ず、八日目の昼に寝た。いちばん下に一行空けて「子どもば休ませよる、と見る」。
- **本家も座って寝た。**「座ってみました。三時まで、起きられんでした」。**権藤さんも覚えている**（「前も、そこに座ってみよったですね」）。**大上は同じいちばん端の椅子に座る。**
- **大上も寝た。** 十二時四十分に座り、一時を少し過ぎて隣の男の子から順に。目を開けると五人が一斉に顔を上げたところで、三時。
- **白石さんは立っている。**「座ったら寝るとです。やけん、一時から三時は立っとります」。
- **目印を同じところに三枚**（押し入れの脇の柱、窓の下の壁、入口の鴨居）。翌日、柱は右から、壁は上から、鴨居は下から黄ばみ、交点は押し入れの中段。**本家の紙と同じ。**
- **八百屋の奥さんの聞き込み**：上は保育園やった、二十年も前。「お昼寝の時間は、うちも静かにしよったとよ。一時から三時は、トラックも店の前に停めんごと言われて」。**「あんた、この前も同じこと訊いたろうもん」**——本家と同じ顔なので。みかんを一つおまけ。**調べ直すぶん、手間はむしろ増える**（I030「本家を便利な二人目にしない」）。

## 記帳

**日曜、塾は休み。** 権藤さんは一階の八百屋で奥さんと茶を飲んでいる（依頼人を離す段取り。理由には触れていない）。二階は冷え切り、ストーブは消えている。

- **押し入れの前に立ったまま。** 中段はちょうど腰の高さで、赤本を端に寄せて帳面を置いた。十二時五十分から待つ。
- **一時。「何も来なかった。瞼も重くならない。座れば、寝る。」**
- **名付けを考える**——本家なら「寝かしつけ」と書くだろう。**『朝掃き』と名付けたのと同じやり方で、何が起こっているかではなく、何が続いているかで名付ける。** 昔から続いていたことの名でいうと寝かしつけではない。周りにも協力してもらって、静けさを保っていた二時間。昼寝。
- 祝詞八文字、「元祖天神大上屋、大上大介がお受けします」。あたりが張った。

　　権藤塾　昼寝　受　壱

- **済んだ合図は現場の側**——いちばん端の椅子に座り、一時二十分、四十分、眠くならない。三時まで座る。「三時になった。誰も起きなかった。はじめから、誰も寝ていない。」
- **受領証は使っていない。** 無人で書けるので手で書いた。
- **帳面の重さ、記帳の気配には触れていない**（「あたりが張った」「張ったものが落ちた」だけ）。

## その後

- **月曜の三時過ぎ、権藤さんから電話。**「誰も寝らんかったです」「白石先生が、座っとります」。
- **火曜に払い。** 二万。焦げた厄除けを「これは、権藤さんが買われたもんですけん」と返す。
  - **権藤さんの読み**——「こいつが、一週間、生徒の代わりに寝よってくれたとですね」。**三つ目の、人の心への翻訳。** 大上は「札が寝たわけではない、と言いかけて、やめた」。
  - 押し入れの上の壁に、天満宮のお札と並べて画鋲で留める。「験のよかけん」。

## 数と値段

| | |
|---|---|
| 本家の調べ | 一万（本家が受け取り済み） |
| 本家の厄除け | 千円（押し入れの襖に一枚） |
| 大上の調べ直し | **請求していない。**「前に、いただいとります」 |
| 引き取り | **二万**（払いは、月曜に生徒が寝なかったのを見てから） |

- **厄除けの千円は返していない。**
  - 大上は返そうとした（「千円、返そうかと思う」「そうやけど、収まっとらん」）。
  - 本家は「札は、仕事ばしとります」「七日ぶん、代わりに受けとります」。**押しはしない。**
  - 大上は「権藤さんが千円で買ったのは、札だ。札は、買われたとおりに働いた。部屋が収まるかどうかは、そのあとの話だった」。
  - 翌日、権藤さんが「あの札の貼ってあった一週間は、みんな、よう勉強しよりました」。**返すつもりでいた千円のことは、言わなかった。**
  - **決めたことを台詞で言わせていない。** 権藤さんに札を「無駄」と言わせる形は外した（依頼人を間抜けにしない）。
- **していない仕事は請求しない、の裏側**——調べ直した二日ぶんは取っていない。**手間を負うのは大上のほう**（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「クセは、対比で見せる」）。
- 締めで本家に「二万もろうた。厄除けの千円は、そのまま」「はい」。
- **[I024 厄除けの苦情](../../C_執筆管理/話アイデア/執筆済み/I024_040_厄除けの苦情.md)との差**——あちらは何も来ていないので札が働いていない回。**こちらは来たものを七日受けて尽きた札。** 身内の勘定で、客は札に感謝している。

## 依頼人は、屋号を忘れている

- **顔は覚えている。** 権藤さんは大上を前に来た男だと思っている（「ああ。先日は、どうも」）。**大上は訂正しない。**「同じ顔で来たのだから、こうなる。」
- **屋号は忘れている。** 名刺をなくしていて（「前にいただいたとが、どこにいったか」）、新しいほうを読んで「元祖……。こげな名前でしたかね」。机のマットの下に挟む。
- **八百屋の奥さんも同じ。**「あんた、この前も同じこと訊いたろうもん」。
- **依頼人が同じ顔の二人を一人と思い込む形は、この回だけの扱い。** 型にするかどうかは決めていない。

## 締め——本家との短いやりとり＋昼の路上

- **いつもと逆に、元祖が一報しに行く。**「いつもは、本家のほうが言いに来る。」高架の下で本家は厄除けを並べていて、電車が通ると札の端が震える。
- 「美野島の塾、受けた」「はい」「昼寝、ち書いた」——本家は厄除けを揃える手を止めない——「俺なら、寝かしつけ、ち書いとります」「知っとる」。
- 焦げた札がいまどこに貼ってあるかを話すと、**本家は少しだけ顔を上げる。**
- 四十歩戻って表の椅子に座る。「昼の陽気が路上に降り注いで、北風がそれを拭っていった。」「携帯を見ると、一時を回ったところだった。」
  - **一時は、この回の時刻への呼応。** 眠くなるかどうかは書いていない（書くと、実際に何も影響がなかったと読める）。
- **締めの型は「本家との短いやりとり」**（第四話・第九話・第二十話以来）。前の回（帳面の行を読み返す）と続いていない。

## 舞台と人物

- **舞台**：博多区美野島二丁目。渡辺通りから那珂川のほうへ下った古い商店街。乾物屋、布団屋、閉まったままの豆腐屋。風が抜けるたびにシャッターが鳴る。**実在の町名、店は架空。**
  - **権藤塾**：八百屋の二階。脇の階段、硝子戸に白い字で「権藤塾」、その下に小さく「自習室あり」。正面に塾長の机、後ろの壁にホワイトボード。
  - **奥の部屋**：六畳ほど。長机三つを壁向きに。窓が低い（大人の腰より下から）。外の電線が近い。押し入れは襖を外してあり、上の段に段ボール、中段に赤本。中段の縁に色の抜けたビニールテープ「おふとん」。隅に石油ストーブ。**どの机にも天満宮のお守り。**
  - 八百屋の店先に割引の札を付けた鏡餅が三つ（季節の手がかり）。
- **権藤さん**（ごんどう）：塾長。六十の手前。厚手のカーディガン、老眼鏡を額に押し上げている。机には答案の束と赤ペン、天満宮の合格鉛筆を挿した湯呑み。**癖：指先を擦り合わせる**（チョークの粉を払うような手つき。ホワイトボードなのでチョークは無い）。
  - **持ち札は験担ぎ。** 合格鉛筆、お守り、焦げた札を「験のよかけん」と天満宮のお札の横に留める。
  - **降りられない事情**：共通テストまで十日。直前の二週間は昼から自習室を開けると親御さんに言ってある。家では勉強のできない子が来る。「寝かせるために、開けとるわけじゃなかとです」。
- **白石さん**：講師。二十代の半ば。ダウンを着たまま、ホワイトボード用のペンを握る。**癖：親指でキャップを外しては嵌める。** 一時から三時は立っている。**引き取りのあと、長机の端に座っている。**
- **八百屋の奥さん**：七十近く、綿入れの半纏。**癖：みかんを一つずつ掌で転がしてから袋に入れる。** 保育所の話と、トラックの話。
- **生徒**：高校生が五人。マフラーを巻いたまま。寝ることには慣れている。

## 人の出し方

- **本家——型③の裏返し＋型②（四畳半）＋型①（路地の口）。** 本家が表に立つ回。**内面には入っていない。** 詫びない、判断しない。
- **安藤——電話。** 朝に一度、帰り道に一度かけて繋がらない。**訊きたかったのは「誰もいない部屋でも、怪異は何かしているものなのか」。** 払いを受け取った帰り道に折り返しが来る——「出とった。何か用か」「もう、済みました」「そうか」。**どこへ出ていたかは訊かない**（[進行記録.md](../../C_執筆管理/進行記録.md)「安藤の時計を刻む」の二刻目）。
  - **「ああ」は相槌なので、第一声に使わない**（[登場人物.md](../登場人物.md)「喋り方」。この回で足した）。
- **播谷・税所・占部は出ない。** 税所の「仕入　ミシン」は第二十八話以降の定期の場面に回す。

## この回で決めたこと

- **帳面の力は、元の怪異の時刻を守らない**（[帳面.md](../帳面.md)「力の借用」）。**元の時刻で働くのは、出したときだけ。**
  - **『朝掃き』にも遡って当てた**（[怪異/015](../怪異/015_朝掃き.md)）。炊飯器を押しているのは大上が起きる前で、四時十分とは限らない。第十五話の「春吉の道と、同じ時刻だった」は大上の推測として読む。**本文は直さない。**
- **「昼寝」を出す手は、昼間に人が居る場所を突破する札として置いた**（[アイデア.md](../../C_執筆管理/アイデア.md)）。

## 書いていないもの

- 怪異の機序（静けさの二時間）。どちらの読みが当たっているか。
- 誰もいない部屋でも働いていたかどうか。
- 保育所の名前、閉じた理由。
- 本家が権藤さんと最初に会った場面、厄除けを貼った場面（結果しか届かない）。
- 引き取った力。
