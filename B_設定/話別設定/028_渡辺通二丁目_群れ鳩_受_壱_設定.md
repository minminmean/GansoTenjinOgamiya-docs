# 第二十八話　渡辺通二丁目　群れ鳩　受　壱

**第二十八話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/028](../怪異/028_群れ鳩.md)。縛りは[各話の規則/028](../../C_執筆管理/各話の規則/028_第二十八話.md)。

**定型回。** [I017 渡辺通の鳩](../../C_執筆管理/話アイデア/執筆済み/I017_028_渡辺通の鳩.md)から起こした。**動物の三本目**——野良猫が一匹、回り犬が経路、こちらは**数**。題は記帳の行そのまま。

**時期は一月の終わり。** 大寒を過ぎて、朝の歩道に霜が残るころ。**定型回なので年表には載せない。本文に日付は出していない。**

## 芯——群れは、なんぼで一つか

**員数が一に決まらない相手を、どうやって一と書くか。** 解決は数えることではなく、**何を一つとするかを決めること。**

- **位置は割れる。数は割れない。** 目印三枚は同じ薄さで広く焦げ、線が引けない。五十枚を屋上いちめんに貼って（前に同じ詰まり方をした手）、どこにいるかは分かった——屋上いちめん。**何羽ぶんかは出ない。** 濃さには記憶の強さと距離の両方が乗るので、一羽ぶんが広がっているのか百羽ぶんが少しずつ浴びせているのか、札は同じ色で焼ける。
- **数えても決まらない。** 夕方に大上が影を数えて三十七、翌日は四十一。朝は本家が二十六。「朝は、全部は出ていかんとかもしれません」「夕方も、全部は帰ってこんとかもしれん」——**同じことを言っている。**
- **書けば数が立つ。** 多く書けば足りないぶんを帳面が何かで埋める（座布団の六枚目）。少なく書けば残りが屋上に居残る。**ここで固まる。恐れ自体は正しい。**
- **根拠は古株の言葉から取る。**「あれは一群れですたい。ずっと一緒に動きよった」。**第九話が品名を客の言葉から取った回なら、こちらは数のほう。**
- **決める理屈は大上の読み。**「三十と書けば、その三十が何を指すのか、俺には分からない。一群れなら、分かる。……それはもう、どこにもいない」。**生きとるもんは受けたらいかん**（第二十話）を踏まえている。**設定側の線（群れの記憶は個々と同源ではない）とは筋が違うが、書いた行は線の内側に収まった。当たったとは書かない**（[記憶と怪異の法則.md](../記憶と怪異の法則.md)「同源でないものの線引き」）。
- **品名は「群れ鳩」。** 本文の地の文・台詞には一度も出さず、記帳の行と題だけに立つ。直前は「群れは、なんぼで一つか。一つだ、と決めた。」で、決めたことがそのまま行になる。**「回り犬」と同じ作り**（何をしていたかを頭に付けて一語にする）。

## 数えること

- **大上は数えた。** 影が一つ横切るたびに指を折り、三十の手前で分からなくなってやり直す。階段を下りる途中で気づく。
- **「確かめようとして、数える。みやこビルでは、それで入った。それ以来、数える癖が出るたびに自戒してきた。今回も、何も起きていなかった。」**——**数えて危ない件のほうが稀だと、大上は薄々気づいている。** 一般則だというのが大上の誤解で、実際は『番』の場に固有のこと（[PROJECT_RULES.md](../../PROJECT_RULES.md)「大上が知らないこと」）。 「運が良かった」とは読ませない（草案にあったが削った）。
- **本家も数えた。**「数えたとか」「数えました」。「俺も数えた、とは言わなかった」。**どちらにも何も起きていない**（別系統には効かない現象。[記憶と怪異の法則.md](../記憶と怪異の法則.md)「数えることと、書くこと」）。

## 『番』を当てさせない

- **七階と八階は「合」。** 寝る前に戸を思い浮かべて回した（第二十四話と同じ手順）。

　　渡辺通二丁目　永野ビル七階　員数　合
　　渡辺通二丁目　永野ビル八階　員数　合

- **屋上の行は無い。**「戸の無い駐輪場は、前に読んだ。通り抜けの通路は、読まなかった。屋上は、通路のほうらしい」。**基準が区切りだとは掴んでいない。** 境目の札で囲えば読める、にも気づいていない（[札.md](../札.md)「屋上を囲えば、『番』が数えられる」）。**読者にだけ見えている答え。**
- 屋上は「囲うものは何も無い」と本文で書いた。縁の立ち上がりは膝の高さで、その上にも針。

## 記帳

**夕方、屋上。** 永野さんは一階のロビーで待つ（依頼人を離す段取り。理由には触れていない）。風が止み、西の空がビルの隙間だけ赤い。階段の出口の脇で帳面を開く。

- 五時を少し過ぎて、南から音が来る。頭の上を一度回って、屋上いちめんに降りてくる。**給水塔のあったあたりがいちばん賑やか**——何も無い宙で、羽をたたむ音がする。
- 祝詞八文字、「元祖天神大上屋、大上大介がお受けします」。**羽の音が止んだ。**

　　渡辺通二丁目　群れ鳩　受　壱

- **済んだ合図は現場の側**——書き終えても音は戻らない。五十枚の札を一枚ずつ剥がして鞄に入れる。
- **受領証は使っていない。** 無人で書けるので手で書いた。
- **帳面の重さ、記帳の気配には触れていない。**
- **名乗りで止まったことだけを書いた。** 害意の無い相手なので、足を止めた以上には見えない（[PROJECT_RULES.md](../../PROJECT_RULES.md)「取引の瞬間に、帳面が結界を張っていることに気づいていない」）。

## 大上の誤訳

- **「まだ、帰ってきよるとですね」**（掃除の人に）。「そうですかね」で流される。**訂正しない。**
- 群れに帰る先は無い。居たという事実だけがある（[怪異/028](../怪異/028_群れ鳩.md)）。

## 数と値段

| | |
|---|---|
| 調べ | **一万**（三日。「朝と夕方を、何度か見ないと分からないので」） |
| 引き取り | **二万** |
| 締めて | **三万**。二日後、永野さんが店に持ってくる |

- **「管理費で、落とせる額ですね」**——ビル一棟ぶんだが、名目は管理費で通る額。**大きくしない。**
- 五十枚の目印の札代は取っていない。本文でも触れていない。

## 締め——翌朝の店先

- 「次の朝、店を出した。地下街に下りる階段の脇で、鳩が何羽か、歩道をつついていた。人が来ると少しだけ飛んで、また下りる。**何羽いるのかは、数えなかった。**」
- **締めの型は「翌朝の店先」**（第八話以来）。前の回（本家との短いやりとり）と続いていない。
- 「そこらの鳩になっとる」（掃除の人）への呼応。**その中にあの庇の鳩がいるかどうかは書かない。**

## 舞台と人物

- **舞台**：中央区渡辺通二丁目。店から渡辺通りを南へ、デパートの角から歩いて十分と少し。**実在の町名、ビルは架空。**
  - **永野ビル**：八階建て、白いタイルの外壁。一階はコンビニと歯医者。入口の上にガラスの庇（縁に針が一列）。**去年、建て替えた。** 鳩よけの針と網は建てたときに付けたとおり。業者を入れたが「鳥はいません」。
  - **屋上**：灰色の防水の床、室外機、階段の出口。縁の立ち上がりは膝の高さで、上に針。**囲うものは何も無い。** 北に天神のビルが見える。
  - **前のビル**：屋上の真ん中に給水塔、表に長い庇。鳩はその二か所に並んでいた。
- **永野さん**：ビルの持ち主。五十の手前。灰色のコートの下に背広、襟に小さな社章。**癖：眼鏡を外して、レンズに息を吐きかけ、ハンカチで拭く。**
  - **持ち札は見栄。** 建てるときテナントに「前のビルは鳩のひどかったけど、今度は対策は万全ですけん」と言った手前、鳥の話にできない。
  - **降りられない事情**：八階の事務所が三月いっぱいで出ると言っている。
  - **信じないまま金を出す客。**「信じとらんとですけど」「音の正体の分かれば、それでよかです」。締めで「やっぱり、鳥やったとですね」「はい。鳩でした」——**訂正しない。**
  - **店を忘れている。**「毎朝、ここば通りよるとですけどね。こげな店のあったとは、知らんかった」。払いの日は名刺を手に持ち、見ながら歩いてきた。
- **佐伯さん**：八階の事務所（図面を描く仕事）。三十の半ば。セーターの袖を肘までまくり、耳に鉛筆。**癖：話しながら、耳の鉛筆に指をやる。** 羽音は朝の八時前（上から下りてどこかへ行く）と、夕方の五時過ぎ（上へ抜けていく）。**引き取りのあと、残ることにした。**
- **掃除の人**：前のビルのときから掃除をしている女の人。六十の半ば、紺の作業着に毛糸の帽子。**癖：片方だけ軍手を外して、外したほうをもう片方の手に握る。** 名前は出していない。
  - 「表の庇に、ずらっと並んで」「多か時は、そら、百はおったかもしれん。少なか時は、二十か三十か」「あれは一群れですたい」「散りました」「いまごろ、そこらの鳩になっとるとでしょう。警固の公園やら、駅のほうやら」。
  - **依頼人と別人にした**（見栄の男に根拠を言わせると、話が早く済みすぎる）。

## 人の出し方

- **本家——型④（手を分ける）＋型②（四畳半）。** 朝を本家が見に行く（「店は、昼から開けます」）。晩に数を言い合う。**進行記録では型③だったが、第二十七話で③を使ったので替えた。** 内面には入っていない。「本家は、少し間を置いた」は家の場面なので置いた。
- **安藤——対面（店の斜向かい、ひさしの下）。** 第十六話以来。**時計の三刻目**（[進行記録.md](../../C_執筆管理/進行記録.md)「安藤の時計を刻む」）。
  - 第一声は「数の読めんとか」。**大上の顔から読める範囲に留めた**（「鳩か」は分かりすぎなので外した）。
  - 「数えた、のところで、安藤さんは空を見た。ねぐらに帰る鳥の群れが、ひとつの生き物のように飛んでいた。」——**鳩とは限らない**（福岡の街では、特定の木をねぐらにする雀やカラスの群れが夕方に一斉に飛ぶ）。**問いの出どころを目の前の景色にした。**
  - 「群れは、なんぼで一つね」「……分からんとです」「決めり」。**裸の命令形で切る。理由も機序も説明させない。**
- **缶の二度目**（下記）。
- **播谷・税所・占部は出ない。** 税所の「仕入　ミシン」は第三十話へ回した。

## 缶の二度目——趣味を失ったことを、読者にはっきり見せる

**[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「缶コーヒーを消化する」の二度目。済。**

- **大上から訊く。**「今日も、缶は持っとらんとですね」。安藤は何のことだという顔。**右手が左手のほうへ動き、腹の前で何も無いところを持ち替えて止まる。今度は二人とも見ている。**
- **安藤は自分の手を物証として読む。**「……いつからや」「中洲の次の日には、もう持っとらんでした」「持っとったとは、知っとる」「好きやったでしょう。コーヒー」「そうらしいな」——通りのほうを見て黙る（答えないときの所作）——「なんで持ちよったとか、分からん」。
  - **三段で抜けている。** 持っていた事実は覚えている → 好きだったことは他人事 → なぜ持っていたかが分からない。**記憶と好みが消え、癖は残る**（[登場人物.md](../登場人物.md)「安藤の力の値段」）。
- **大上の考察（机を畳みながら、輝国の晩を思い出す）。**
  - 輝国の晩、安藤は缶を最後まで開けず、帰り道の街灯の下で右手から左手に持ち替えた。**缶を持っている姿を見たのは、あれが最後。**（第十三話〜第二十七話に、安藤が缶を持って出る場面は無い。確かめ済み）
  - 「力を使うたびに少しずつ消える」と考えたとき、持っていかれるのは名前のような大きなものだと思っていた。
  - **「好きだったということだけが抜けて、手が残った。あの晩、俺は祓いを持っていなかった。それが、あの人を削った。缶コーヒーが好きだ、という部分を。」**——第十二話の「それが結果的に、安藤さんを削った」を受ける。
- **大上の理解が一段進んだ。** 「使うたびに消える」から、**「持っていかれるのは好きだったもので、癖は残る」**まで。**値段の体系（覚えている人の数）には届いていない。** 何が持っていかれるかを選べないことも、次に何が行くかも知らない。
- **「訊かなければ気づかせずに済んだ」は書かない**（気づかなければそれでよかった、と読めるため草案から外した）。**罪は祓いを持っていなかったあの晩の側に置いた。**
- **以後しばらく缶を出さない。** 気づいた本人が抑えるので、見ていないときだけ出る。**次に書けるのは読者が忘れかけたころ。**

## この回で決めたこと

- **群れの記憶は、群れの個々と同源ではない**（[記憶と怪異の法則.md](../記憶と怪異の法則.md)「同源でないものの線引き」）。群れはそれ一つで生き物のようなもので、群れの意志は個々の意志が合わさって生まれた別のもの。
  - **生きている群れを受ければ、群れは個体を失わず、群れとしての意志を失う。** 十分な数が残れば、また群れになる。
  - **出せば意志だけが出る。** 実体（音・影）が伴うかは、怪異化しているかどうかで決まる。
- **I017 の「主は死んでいること」は、この線に置き換えた。**

## 書いていないもの

- 群れがいつから庇にいたか。何羽死んだか、どこへ行ったか（「そこらの鳩」まで）。
- 屋上を境目の札で囲えば『番』が読めること。
- 引き取った力。
- 安藤がなぜひさしの下に立っていたか。
- 二十六・三十七・四十一のどれが正しかったか。
