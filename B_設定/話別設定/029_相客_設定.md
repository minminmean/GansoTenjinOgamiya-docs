# 第二十九話　相客

**第二十九話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/029_元栓](../怪異/029_元栓.md)と、怪異でなかった[怪異/029_上がり框](../怪異/029_上がり框.md)。縛りは[各話の規則/029](../../C_執筆管理/各話の規則/029_第二十九話.md)。

**定型回。** [I014 二つ並ぶ現場](../../C_執筆管理/話アイデア/執筆済み/I014_029_二つ並ぶ現場.md)から起こした。**由来は場＋人の混合**（由来の勘定では「混合一」）。**播谷守の五回目で、物差しは腕（観察と診断）。** 帳面は一行も増えない。

**時期は二月の上旬。** 朝の歩道に霜が降り、参道の石畳が白い。**定型回なので年表には載せない。本文に日付は出していない。** 第三十話（二月の終わり）の手前。

## 題——相客

**記帳が無く、行も立たなかったので漢字の副題。**

- **相客＝宿や茶屋で、たまたま同じ部屋に通された見知らぬ客。** 二重の意味で付けた。
  - **記憶の側**——同じ家に居合わせた、関係のない二つ（焦げと黄ばみ）。
  - **拝み屋の側**——同じ座敷に通された二人の客（播谷と大上）。久保さんは二人に同じように茶を足している。
- 「競合」で一度書いたが、**二つの記憶は張り合っておらず、播谷とも対立させない**ので替えた。
- **読みは「あいきゃく」。** 題の行にはルビが効かないが、そのまま置く。

## 芯——消えたものは、何だったか分からない

**播谷の稼業は、人を困らせているものを消すこと。それが何だったかは要らない。** この回では、それが正しい形として立つ。**大上はその正しさを目の前で見せられ、手の中に何も残らない。**

- **大上が避けているのはこの終わり方。** 第二十五話の橋の上で「消してしもうたら、何やったとかが分からんごとなります」と言った。**本文では持ち出さない。** 口からではなく、目の前の出来事で同じことを言わせた。
  - 「戸の前にあったものが、無くなった。何が無くなったのかは、分からなかった。お父さんだったのか、お父さんが毎晩していたことだったのか、そのどちらでもない何かだったのか。消えたものには、もう訊けない。」
- **後味の悪さは、どちらかが間違っていることから来ない。** 播谷は正しい——「三日も待ったら、お母さんの寝られんめえもん」は本当のことで、足音は止み、お母さんは眠れた。大上も正しい。**両方正しくて、片方だけが手間を負い、しかも何も得ない。**
- **腕は上がらず、下がりもしない。** 大上に読み方を覚えさせていない。

## 手順の違い——並べて見せるだけ

**二人とも三枚貼り、線を組み、同じ所に行き着く。** 播谷を下手に書いていない。**差が出るのはその先だけ。**

| | 播谷 | 大上 |
|---|---|---|
| 着いた時刻 | 一日目の朝六時半（勤めの開店準備の前） | 一日目の十時（名刺で呼ばれた） |
| 二色を見て | 「二つおるね。古か家やけん。こげなこともあるたい」。**騒がない** | 他人の札で割り出しまでやり、座敷で誤訳を言う。**騒いだのは大上だけ** |
| 決め方 | お母さんと茶を二杯飲み、**一時間足らずで「上やろ」**。根拠は下りてくる向きと濃さ | **三日通って比べる**つもり。濃さは距離も乗るので割れない、と知っていて黙る |
| 打ち方 | 戸に向けて祓いを翳す。祝詞八文字。**そのあとに何も続かない** | 打たない |
| 後始末 | 自分の三枚を剥がす。**剥がすとき札の色を見ない** | 自分の三枚を三日目まで残させてもらい、読みに来る |
| 金 | 見に来たのが一万、祓いが三万、締めて四万。**領収書を書く** | 見に来たぶんだけ一万 |

- **祝詞の音数の比較はここで使った**（[作法.md](../作法.md)「播谷の八文字は別のもの」。第十四話から取ってあった）。「八文字なのは同じだった。言葉が違う。」**どちらの中身も文字にしていない。**
- **続けて「そのあとには、何も続かなかった。名乗りも、申し立ても無い。」** 名乗りを持たない男（[作法.md](../作法.md)「必殺技は名乗りのほう」）を、説明せずに並べた。
- **大上の読み方（日を追った変化）は、材料を失って空を切った。** 読む手は持っているが、読むための日数が来なかった。**I014 の「大上は読めない」は、自己流で読めるようになった現行の設定（[札.md](../札.md)「二人の読み方の差」）に合わせてこう置き換えた。**
- **播谷は「下のは、家のもんやろ。古か家には、おるもんたい」と言って黄ばみを置いていく。** 見立ては当たっている（[怪異/029_上がり框](../怪異/029_上がり框.md)）。**当たっているとは書かない。**

## 鉢合わせ

- **家の中で話が通っていない。** お母さんが老人会の伝手で播谷を呼び、娘の久保さんが名刺で大上を呼んだ。**久保さんは当日の朝まで知らなかった。**
- **播谷が先着。** 大上が着いたときには、階段の途中・一階の廊下の突き当たり・二階の廊下の柱に三枚貼り終えている。**大上はそれを見てから、少しずらして自分の三枚を貼った**（階段の下の柱・廊下の反対側の壁・二階の窓枠）。**同じ壁に二組。**
- **二人が顔を合わせるのは二日目の朝七時。** 播谷は大上の札を覗き込んでいた。「なんで、あんたがおると」。**対立はない。**「二人も呼ばれたとね。ご苦労さん」。
- **『番』の代償**——屋号が抜けている。久保さんの持つ名刺を覗いて「ああ。あんた、こげな名前で商いよったね」。驚かない。
- **地の文の呼び方**——一日目に「播谷守のことだろう」で姓名を一度、以降「播谷さん」。

## 大上の誤訳

- **「上と下に、二つおるとやったら、片方が、もう片方ば呼びよるとやなかとですか」。** 二つに関係は無い（[怪異/029_元栓](../怪異/029_元栓.md)「黄ばみとの関係」）。
- **久保さんが乗る**——「家のほうが、父ば離さんとかもしれませんね」、棟上げ、建て増し、大工さんと喧嘩。**大上は止めない。訂正もしない。**

## 本家——型③（読ませる）

**路地の口、一日目の夕方。** 同じ材料（足音、先に貼られた三枚、二つの色、上と下）を渡す。

- 本家はまず**「上と下、どっちが濃かったとですか」「足音は、上から下りてくるとでしょう」**と訊く。**そこで起きていることを分かりたい未練がある。**
- そのうえで**「播谷さんに頼まれとるとに、うちで手を回してよかもんでしょうか」。** 仕事の筋はあちらにある、を気にしている程度。**ふてくされていない、投げ出していない。**
- 元祖は「頼んだとは、娘さんたい」。本家は「はい」で、それきり机の端をもう一度拭く。**決着させていない。** 同じ材料から、元祖は札を読み、本家は仕事の筋を読んだ。
- **第十四話の「他人の家では受けられない」には触れていない。** 施主の話にすると筋が一本増えるので、本家の気がかりは「頼まれた先」に留めた。

## 数と値段

| | |
|---|---|
| 播谷 | 見に来たのが**一万**、祓いが**三万**、締めて**四万**。お母さんが簞笥の封筒から払う。領収書あり |
| 大上 | 見に来たぶんだけ**一万**。久保さんが払う |
| 久保家の払い | 締めて**五万** |

- **「播谷さんは、四万でしたけど」「あちらは、止めらしたけん」。** 取れたはずの金ではなく、取るべき金だけを取った。**していない仕事（祓い）は請求していない**——クセの側。
- **札代は取っていない。** 本文でも触れていない。
- 「止めらしたけん」は「止めてらっしゃったから」。**「〜らした」に「です」を重ねない**（「止めらしたですけん」は「止めてらっしゃいましたですから」になる）。

## 締め——手を動かして終わる

- 三日目、最後の一枚（階段の下の柱）を剥がす。下寄りから黄ばんでいる。
- 「上がり框のあたりには、いまも何かがある。誰も打っていないし、誰も受けていない。これが何なのかも、俺には読めなかった。」「二階の戸の前にあったものは、もう読めない。」
- 「札を四つに畳んで、鞄に入れた。上がり框に腰を下ろして、靴を履いた。背中のほうで、階段は鳴らなかった。」
- **締めの型は「手を動かして終わる」**（第一話・第十四話・第二十三話に続く四つ目）。前の回（翌朝の店先）と続いていない。
- **感慨を言わせていない。**「たぶん、害は無い」は一度書いて外した。

## 舞台と人物

- **舞台**：東区箱崎三丁目。宮の参道から一本入った、古い家の残る筋。**実在の町名、家は架空。**
  - **久保の家**：瓦屋根の二階建て。板塀の上に葉の落ちた柿の枝。玄関の脇に名札を挿した鉢植えがいくつも。**お父さんが昭和の中ごろに建て、建て増しを重ねた**（風呂場を広げた、二階に物干しを付けた）。
  - 玄関の正面が階段。急で幅が狭く、踏み板が黒く光る。二階の廊下は窓が一つきりで暗い。二階の奥が夫婦の部屋だった。
- **久保さん**（依頼人）：五十前後。ダウンの前を開け、下にエプロン。回覧板を抱えている。**癖：話しながら相手の湯呑みに茶を足す。** 持ち札は世話焼き。「私はよかとですけど、母が」。いまは二階の奥の部屋を使っている。
  - 締め近くで急須に手を伸ばし、**急須は空だった。**
- **お母さん**：八十過ぎ。小さな人で、座椅子にもたれ、格子の膝掛け。**癖：膝掛けの端を指で揉む。** 膝を悪くしてから一階の座敷で寝ている。**降りられない事情は、動かせない親であること。**
  - 「お父さんよ」「お父さん、上がんなったとやろうね」（上がりなさった＝成仏した）。**誰も訂正しない。**
  - 三日目、膝掛けの端を指で押さえたまま眠っている。
- **お父さん**：八年前に二階の奥の部屋で亡くなった。寝る前に必ず台所の元栓を見に下りた。この家を自分で建て、棟上げのとき自分で上に乗った。名前は出していない。

## 人の出し方

- **播谷——物差しを立てる回**（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「播谷守——並の拝み屋を一人置く」の五回目）。**助言させていない**（「三日も待ったら」は自分の判断の理由であって、大上への助言ではない）。**機序も語らせていない**——「親父さんが元栓ば見に下りよらす」は当て推量を口に出す並の怖さ。**首の後ろを掻く**（第二十五話の所作を一度だけ繰り返した）。
- **本家——型③**（上記）。第二十八話は④②。
- **安藤は出さない。** 第二十八話で対面させたばかり。I014 の「二枚出たなら、二回貼らんね」は使っていない。
- **税所・占部は出ない。**
