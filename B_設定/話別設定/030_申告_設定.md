# 第三十話　申告

**第三十話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。縛りは[各話の規則/030](../../C_執筆管理/各話の規則/030_第三十話.md)。骨格は[話アイデア/I028](../../C_執筆管理/話アイデア/執筆済み/I028_030_税務署の回.md)（後半）。前半は[第二十二話](022_お尋ね_設定.md)。

**本筋⑤。怪異が出ない。帳面は一行も増えない。** 税所和美の三回目。**内訳の書き換えという手に思い至り、手を付けない。**

**時期は翌年の二月の終わり。弟子入りからちょうど一年**（[基礎設定.md](../基礎設定.md)「年表」）。本文には「二月の終わり」「弟子入りしたのが、去年の二月の終わりだった。一年になる」まで。日付は出していない。南から強い風が吹いた日に始まり、事務所に二度行く一週間ほど。

## 題——申告

**行が立たなかったので漢字の副題。** 国への申し立て。名乗り→申し立ての作法（[作法.md](../作法.md)）に重なるが、**本文では繋げていない。** 冒頭の「その一年ぶんを、国に申し立てる時期が来ていた」だけ。

## 冒頭——税所の紹介と、気の重さ

- **税所は第二十四話以来なので、冒頭に一段置いて紹介し直した。** 税理士に顧問をしてもらっていること、薬院の雑居ビルの二階で一人でやっている人であること、名前（「名前を、税所という」。読みは書き出しのルビに任せ、本文では言わない）、月一万五千円、月に一度家計簿を持っていくこと、行くたびに付箋が増えること。
- **気が重い。**「怪異の現場なら、何が出てくるかは分からなくても、何をすればいいかは分かる。こっちは、何を訊かれるのかが分からない」。隠しているもの（路上の店、店番が二人、帳面）を並べ、「一年ぶんを出せば、どこかから、どれかがはみ出してくる気がした」。
- **第二十二話の「たぶん、俺も同じ顔をしている」は使っていない**（多用しない）。

## 芯——二冊目の帳簿から、内訳に行き着いて、止まる

- **入口は税所の要求**——「来年からは、お仕事の帳簿を家計簿と分けてください。一冊、別に」。付箋「帳簿　別に」。
- **新天町の文具店、帳面を買ったのと同じ棚**（大学ノート・バインダー・和綴じの帳面。千八百円の値札も同じ）。**下の段に手を伸ばしかけて、やめる。** 内訳の「帳面　壱」が頭に来る。
  - 家計簿は表に家計簿と刷ってある。これは仕事の帳簿だ。**帳面がそれを帳面と読むかは帳面が決める。**
  - **大学ノート（百八十円）を買う。帳面には似ていない。**「似ていないから何だ、とは思った」。
  - **誤訳の推論**——机二つと客用の椅子二脚は内訳に書いていない、毎日出してしまっても何も起きない、だからこのノートも内訳に書かなければいい。「たぶん、大丈夫だ」「あとは、祈るしかなかった」。**机と椅子が無事なのは『番』の代償が届かない話で、数合わせの話ではない**（[I028](../../C_執筆管理/話アイデア/執筆済み/I028_030_税務署の回.md)「帳簿をどうするか」）。**地の文で正していない。**
- **本家に託す**——「これは、お前が持っとけ。お前がつけろ」「元祖さんの帳簿でしょう」「お前のや」「……はい」。**持ち主を分けたつもりで、分かれていない**（帳面にとって本家は大上大介と同じ。[帳面.md](../帳面.md)「書けるのは大上大介だけ」）。**本文では示唆していない。**
  - **表紙は「家計簿」。** 本家が「表に、何て書きますか」と訊き、元祖が「……家計簿、でよか」。**家計簿が二冊並ぶ。**
  - **翌朝、本家は片方を鞄に入れて一本裏へ出る。どちらを持っていったかは訊かない。** 二冊目が無事かどうかは確かめていない。

## 山場——内訳を数える

- **本家が寝たあと、街灯の明かりで帳面の最初の頁を開く。**「坂口方　員数　七」の行がいちばん重い。その隣に屋号で受け直した行、少し先に内訳。
- **内訳を独立段落で引いた**（第三話と同じ書式）。
- **「二と、二と、一と、二で、七。」**——第三話の「二、二、一、二。合わせて七。」を受けた。
- **一冊足せば八。** 七のままならどれかを外す（看板を一枚か、椅子を一脚か）。**それか、七のほうを動かすか。** ここで「書き足せる、のかもしれない」に至る。**根拠は安藤の「消して直すものではなく、書き足して直すもの」。**
- **何と書き足すかは組み立てていない。**「帳面　弐」「員数　八」の形の行は大上の頭に立っていない（立てば題がその行になる）。
- **恐れは二つとも書いた。** 出ていって、どこかでまた足しはじめる（封じが解ける側）。出ていかずに、もう手を貸さなくなる——書いても入らない、刷っても増えない、名乗っても何も起きない（取引が切れる側）。
- **区別には届かせていない。**「あの七は、あの家の七だ。坂口の家から帳面に移って、屋号で受け直しただけの、同じ七だ」——**危険な行と書き換えてよい内訳を、一つの七として読んでいる。**
- **安藤の「何を数えるか書け」を思い出す**（第三話、本家を表に連れてきた晩の電話）。「書いたから、店は静かになった。静かにしたものを、自分の手で、もう一度開けることになる」。**そこから先へ考えが進まない。**
- **店番の行には触れていない**（[連載の組み方.md](../../C_執筆管理/連載の組み方.md)「元祖と本家は、どちらも欠けさせない」）。外す候補に挙げたのは看板と椅子だけ。
- **筆ペンは取り出さない。** 紺の表紙には何も書いていない。

## 税所和美（三回目）

- **厄除けの在庫で突っ込む。**「一枚作るのに、いくらかかりますか」「……ほとんど、かかっとらんです」「ほとんど、では書けません」「紙と、墨と、糊です」。
  - 領収書は左の山にあるぶんで全部。**一年で何枚作ったかは大上に答えられない**（刷るたびに枚数は決めているが、一年ぶんを足したことはない）。
  - **税所が家計簿の売上から厄除けの行を拾い、年末の枚数を足し、材料の領収書の合計を割る。**「一枚、六円ですね」。
  - 「印刷ですか」「一から自分で作っとるけん、元手はほとんどかかっとりません」「はい」。**答えずにそらしている。言っていることは嘘ではない**（元になる一枚は自分で書いている）。**「ほとんど」で二度逃げている。**
  - 付箋「厄除け、六円」。地の文——「刷ったぶんは、一円もかかっていない。六円は、最初に書いた何枚かのぶんを、刷った枚数で割っただけの数だ」。
  - **税所を探偵にしていない。** 紙の量と売れた枚数を突き合わせる手前で、普通の説明で止まる。
  - **糊代が本文に初めて出た**（[札.md](../札.md)「糊も、原価のうち」）。
- **ミシン**——「仕入です」「売られましたか」「……売っとらんです」「では、在庫ですね」。付箋「在庫　ミシン」。「いま、どちらにありますか」「……手元に」（鞄は膝の上、帳面はその中、ミシンは帳面の中）。**第二十五話の「来月、税所さんに訊かれますよ」の回収。**
  - **「帳面に入っているもので、国の紙に載るのは、ミシン一台だけだった。」** 札は帳面に書いたものではないので、この一文と食い違わない。
- **机**——折りたたみテーブルのレシート（八百円、リサイクルショップ）が事業の側（左の山）へ。**帳面では員数の外、税では仕事の内。並べただけで、大上に気づかせていない**（[I028](../../C_執筆管理/話アイデア/執筆済み/I028_030_税務署の回.md)「机と椅子が、二つの台帳で別に数えられる」）。
- **屋号**——三度目の「決められましたか」に「書かんでください」。**届けないと決めた。**
  - 大上の理由（地の文）——屋号は名乗るもの。看板と帳面の中に書いてあるものを、もう一か所、国の紙に書けば、そこにも屋号が立つ。書いたところで、この人は来月また付箋を読む。
  - 「屋号を持たない拝み屋なら、二人知っている。一人は、親父の書いていたとおりに書いていると言った。もう一人は、訊くな、と言った。」（播谷と安藤。第二十二話）
  - **付箋「屋号なし」を、前の付箋（屋号の七文字）の隣に貼る。前の付箋は剥がされない。**
  - **税所は付箋を見ているが、屋号を読み上げない。** 忘れていることは書いていない。
- **職業欄は「拝み屋」。**「そのまま書きます」。播谷の「たぶん困る」（第二十二話）への答え——困るのは向こうで、この人ではない。**屋号の欄は空欄。**
- **やらせていないこと**——手続きの説明（台詞は要求と受領と短い理由だけ）、帳面を見る、四畳半に入る、怪異に触れる、助言。**『番』に礼を言う一幕は使っていない。**

## 安藤（電話）

- **事務所の帰り、薬院の交差点の信号待ち。**「安藤さんは、申告、どげんしよるとですか」「……知らん」。切れる。
- **第二十二話の「訊くな」を受けて、懲りずにまた訊く。**「訊くな、よりは、答えに近い気がした。近づいたところで、何も分からないのは同じだった」。**制度側の話のコミカルな面。**
- **様子の変化としては書いていない。**「少し間があった」は第二十二話と同じ程度。間が長い（第三十七話）、自分の台詞を覚えていない（第三十二話）には当たらない。**「知らん」を忘れたことと読ませない。**

## 本家——型②（四畳半）

- **一年ぶんの領収書を月ごとに輪ゴムで束ねている。** 六月がいちばん薄く、十二月がいちばん厚い。
- **在庫の書き出し**——「仕入れた、ち書いとるとは、ミシンだけです」「厄除けは」「作ったもんも、入るとですか」「たぶん、入る」。「ミシンは、どこにあることにしますか」「どこにあることにする、て何や」「訊かれますよ」「手元や」「……はい」。
  - 家計簿に横書きで「ミシン、一台」。**「帳面なら、壱と書くところだ。」** その下に厄除けの枚数（**大晦日に数えてあった。枚数は本文に出さない**）。
- **帳簿を託される場面**（上記）と、**封筒を数える場面**（下記）。

## 数と値段

| | |
|---|---|
| 所得税 | **四万六千二百円** |
| 申告書の作成料 | **八万円**（厄除けで八十枚）。顧問料（月一万五千円）とは別 |
| 厄除けの原価 | **一枚六円**（材料の領収書の合計を一年に作った枚数で割ったもの） |
| ミシン | 在庫。仕入二万四千円（第二十五話） |
| 仕事の帳簿 | 大学ノート百八十円。表紙は「家計簿」 |

- **「払います」は三度目で、いちばん小さい**（第二十二話で二度）。
- **足りた。** 本家が封筒を二度数えて「足ります」「……足りるとか」「足ります」。**どこから出たのかは訊かない。家計簿をつけているのは本家だ**——理由を本家の遣り繰りに預けて、『家』の波及（[001_増えるもの.md](../怪異/001_増えるもの.md)「波及——満ちた形で止まる」）には一言も触れていない。
- **住民税・国保・予定納税には触れていない。**
- **税金は帰りに銀行で納めた**（一行）。

## 締め——金の勘定

- **二度目の訪問で控えに署名。**「大上大介」を独立段落で置いた。屋号の欄は空いたまま、職業の欄に拝み屋。
- 税所が八万円を数え、領収書を書く。**宛名は「大上大介様」。**「俺が切る領収書には、屋号が入っている。」
- **財布の中は百円玉が三枚と、十円玉がいくつか。「足りた。」** 領収書を畳んで、札の入っていたところに入れる。
- **締めの型は「金の勘定」**（第十九話以来）。以後、二話続けて使わない。

## 先へ残るもの

- **屋号は届けていない。個人の拝み屋として申告した。** 屋号は看板と帳面の中と、税所の付箋の上にだけある。
- **仕事の帳簿が一冊増えた。** 表紙は「家計簿」で、つけるのは本家。**「帳面　壱」の指す先に入ったかどうかは、確かめていない。以後も確かめさせない。** 何も起きないのが既定（[帳面.md](../帳面.md)「数を収めることと、帳面が読むことは別の軸」）。
- **内訳を書き換える手があることを、大上は知った。** 三つ目の禁止は「気づいたうえで、それでも動かさない縛り」になった（[PROJECT_RULES.md](../../PROJECT_RULES.md)「自分に課した、実在しない禁止」）。**何と書くかは組み立てていない。区別（危険な行と内訳）にも届いていない。** 実際に動くのは更地（第七十五話）。
- **厄除けの原価は一枚六円。** 以後、税所の場面で使ってよい（第四十・I024で返した金の扱いを訊かれるときなど）。
- **次の申告は第六十六話から第七十六話のあたり**（欠番の時期に重なりうる）（[進行記録.md](../../C_執筆管理/進行記録.md)「季節」）。一行で置ける。
- **帳面は一行も増えていない。取り除く側にも、『家』の波及にも触れていない。**
