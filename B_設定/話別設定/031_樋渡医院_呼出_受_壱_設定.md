# 第三十一話　樋渡医院　呼出　受　壱

**第三十一話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/031](../怪異/031_呼出.md)。縛りは[各話の規則/031](../../C_執筆管理/各話の規則/031_第三十一話.md)。

**定型回。** [I033 医院の呼出](../../C_執筆管理/話アイデア/執筆済み/I033_031_医院の呼出.md)から起こした。**増えない本筋（第三十話）の直後に、品名が立って引き取る回。** 題は記帳の行そのまま。

**時期は三月の初め。** 雨が続き、梅は終わりかけ、待合は花粉の患者で埋まる。**定型回なので年表には載せない。本文に日付は出していない。**

## 芯——読み違えて、色に正され、居座って品名に着く

**余分な患者がいるのではない。余分な呼出が一つある。**

- **① 誤読。** 名義が全員この医院で死亡した患者だと分かって、大上は人の記憶と読む。「世話になった医院だ。亡くなっても、まだ診てもらいに来ている」「来たいという気持ちは、分かる気がした」。**色を見る前の誤読**で、怪異の動機を人の心に訳す型そのもの。
  - **品名は「患者、八」まで頭に立った。** 人は名前ではなく数で書く流儀（第二話）。**書いてはいない。**
  - **手当ても組んだ。** ここで亡くなる人がいる限り九人目が来るので、受けて回るより入口を固める——玄関に境目の札を一枚、受付に厄除け、ひと月ごとに見に来る。**牛島さんに電話で話した。**
  - **本家も同じに読む。**「世話になった病院なら、来たかでしょうね」「そうやろ」。**そのうえで「目印は、何色でした」とだけ訊く。** 同じ頭が、読むのが先という手順だけは押さえている。
- **② 訂正。** 翌朝、目印は三枚とも黄ばみ。交点は受付の小窓の内側、透明な箱のすぐ後ろ。「人の記憶なら、焦げが出る。人も動物だからだ」。**読み違えた。**
  - 「患者、八、とは、まだ書いていなかった。書いていたら、どうなっていたのか。考えないことにした。」——**無いものを受ける記帳の代償には触れていない。**
  - 「境目の札も、まだ貼っていなかった。場が相手なら、区切りを強めれば、強くなるのは向こうだ。」——**境目の札の本来の働き**（[札.md](../札.md)「なぜ古くから使われてきたか」）**なので、大上が知っていてよい知識として書いた。** 手当ては取り下げた。
- **③ 待つ。** 待合で一日数える。入る人、呼ばれて奥へ行く人、会計を済ませて出る人。**昼まで一度も狂わない。** 十二時半に休診、受付にブラインドが下り、待合に大上一人。**一時を少し過ぎて、ことん。** 自動ドアの鈴は鳴っていない。箱の底に券が一枚。牛島さんが引いて、八人のうちの一人。
- **④ 品名が立つ。** 人で埋まっているうちは入らない。誰もいなくなってから入る。診てもらいたいなら診察の時間に来るのが筋。**場が満ちた待合に戻ろうとしている、と思いかけて打ち消す**——「戻ろうとしているのが待合なら、人を座らせるはずだ。券は、座らない」。券が入れば受付のすることは決まっている。**呼ぶのだ。**
  - 「来ていたのは、亡くなった人ではなかった。使われていたのが、亡くなった人の名前だった。」
  - **「当たっているかどうかは、分からない。黄ばみは、場の色だ。札が言うのは、そこまでだ。」で止めた。** 設定側の答えと重なるが、当たったとは書いていない（[怪異/031](../怪異/031_呼出.md)「機序」）。
  - **平田さんに裏を取る。**「券が入っとるのは、待合が空いとるときですか」「……そうです。朝いちばんとか。夕方の、最後の人が帰ったあととか」「やけん、怖かとです。誰もおらんとに、呼ばないかんけん」。

## 品名と数

- **受付、は書けない。** 書けば受付が消える（小窓も、カウンターも、たぶん箱も）。
- **順番、でもない。** 何の順番か、帳面にも大上にも決めようがない。
- **案内は本文で検討していない**（骨格にはあった）。二つで足りた。
- **呼出。** 朝から何十と呼んでいる、あれは全部まっとうな呼出で、そのうちの一つだけが余分に立っている。
- **壱。** 余分な一つだけを受け、正常な呼出と切り分ける。
- **宛先は医院の屋号「樋渡医院」。** 町名の鳥飼では広い。

## 記帳

**翌日の昼休診。** 牛島さんに頼んで休憩室の戸を閉めておいてもらう（人払いの段取り。理由には触れていない）。雨は上がり、散り残った梅に薄い日。

- **受付の小窓の前に立ったまま**、胸の高さのカウンターで帳面を開く。一時を回って、**ことん、と箱が鳴った瞬間に**祝詞八文字、「元祖天神大上屋、大上大介がお受けします」。あたりが張った。

　　樋渡医院　呼出　受　壱

- **現象の湧く条件と、書ける条件が一致している**（待合に誰もいない時間）。骨格どおり。
- **済んだ合図は現場の側。** 箱の底に券が一枚残ったまま、二時半まで鳴らない。**夕方、最後の患者が出て長椅子が空いても、箱は空のまま。** 平田さんはブラインドを下ろさずに、しばらく空の箱を見ていた。
- **受領証は使っていない。** 帳面の重さ、記帳の気配には触れていない（「あたりが張った」「張ったものが落ちた」だけ）。

## 湧いた券の始末

- **券は消えずに残った。十五枚**（初めの十三枚、昼休みの一枚、記帳の瞬間の一枚）。**引き取ったあとはただの紙**（[怪異/031](../怪異/031_呼出.md)「引き取ったあと」）。
- **引き取らない。医院の紙だ。**「これは、うちで処分します」「個人情報ですけん」（牛島さん）。
- **平田さんが輪ゴムを外し、揃えて、とん、と一度叩いてから、シュレッダーに一枚ずつ入れる。** 一枚ごとに機械が短く唸る。

## 数と値段

| 引き取り | **二万** |
| 合わせて | **三万。** 払いは一週間様子を見てから |

- **一週間後の電話**——「出ません」「昼は、待合に誰もおりません。当たり前のことですが」。**払いを受け取る場面は書いていない**（締めの前で切れる）。

## 依頼人と人物

- **舞台**：城南区鳥飼。バス通りから一本入った住宅地。**実在の町名、医院は架空。** 天神からは城南方面のバス。
  - **樋渡医院**（ひわたし）：四階建ての白いビル。一階の軒に「樋渡医院　内科・外科」の緑の字。**二階から上が病室**で、どの窓にも同じ色のカーテン。**この医院で亡くなった患者がいる筋は、入院の床で立てた。** 玄関の脇に梅が一本（花の色は書いていない）。
  - **待合**：長椅子四列。隅に加湿器、壁の高いところに音を消したテレビ。自動ドアが開くと小さく鈴が鳴る。
  - **受付**：ガラスの小窓の向こうに二人。小窓の手前に透明な箱、蓋に細長い口、「診察券をお入れください」の貼り紙。箱の蓋は鍵で開ける。昼休診はブラインドが下りる。
  - **診療時間**：午前は十二時半まで、午後は二時半から六時前まで（本文から読める範囲）。
- **牛島さん**（事務長）：五十の半ば。紺の背広に、事務員の黒い腕カバーを付けたまま路上へ来た。**癖：腕カバーの縁を引いて、手首のところで直す。** 手帳は背広の内ポケット。
  - **持ち札は「気にしない」。**「気にしとったら、事務の仕事は回りませんけん」。**怪異と同じ理屈で回している人**（骨格）。
  - **降りられない事情は、受付が辞めること。**「いまどき、受付は、人が見つからんとですよ」。信じていないと言い切って金を出す。
  - **気づく場面で初めて揺れる。** 番号を引く手が速くなり、画面の上で指が止まり、「全部、うちで看取った方ですね」の声が低い。**腕カバーの縁に手をやって、引かずに、そのまま押さえていた。**「気にしとったら〜」は、平然の台詞ではなく立て直しの台詞。言ってから八人目の画面を閉じる。
  - **見せられるのは番号と通ってきた記録まで。カルテは出せない。** 転帰の欄は通院の記録の側に入る。「その方の治療結果、ちゅうところです」「この方は」「死亡退院、ですね」。
- **平田さん**（受付）：二十をいくつか過ぎた女の人。薄い水色の事務服、髪を後ろで一つに括っている。**癖：受け取った券を、カウンターの上で揃えて、とん、と一度叩く。**
  - **待合を数える癖**——「受付した数と、座っとる人の数。合うとったら、安心するけん」。気づいたのもそれで、受付した数が座っている人より一つ多い。**骨格の「受付事務は数で見る」を本人の癖にした。**
  - **「私だけ、済まんとです」**——看護師も医師も「来られんかったとやろ」で済む。
  - **辞めたくない理由**——「お年寄りの方が、私の名前ば覚えてくれるけん」。**名を呼ぶ仕事の人が、呼べない名に怯える。** 屋号を忘れられる大上とは、読者の側でだけ響く。
  - **怖い理由の核心は後ろに取っておいた。** 事務室では「あの名前ば呼ぶとは、もう嫌です」まで。**誰もいない長椅子に向かって呼ぶのが怖い、は昼休みのあと。**
  - **券の名義が死者だとは、本文で平田さんに伝えていない。**
- **看護師長**：六十の手前。胸のポケットにペンライトと体温計。「来られんかった人のことは、気にせんでよかとよ」。**医師・看護師は患者を人として見るので「来なかった」で終わる**（骨格）。平田さんは返事をしない。
- **院長は出ていない。**「院長に、上げときます」だけ。

## 締め——名を呼ばれて立つ

- **一週間後、払いを取りに行った待合。** 混んでいる。牛島さんは事務室で電話中で、待ってくれと手で示し、大上は長椅子の端に座る。隣のお年寄りが膝の上で診察券を裏返しては戻す。
- 名前が順に呼ばれ、呼ばれた人が立って奥へ行く。**牛島さんが小窓に顔を出して平田さんに何か言い、平田さんがカウンターの端に挟んであった名刺に目を落とす。**
- 「……元祖、天神大上屋の、大上さん」。**待合の誰も、顔を上げなかった。**「はい」。**呼ばれて、立った。**
- **名刺は、冒頭で平田さんが待合で拾ったもの**（誰が落としたかは分からない）。**冒頭と締めが同じ一枚で繋がる。**
- **第一話との重なりは読者にだけ置いた。** 第一話の地の文「あの人は屋号を持たないので、名乗った時点でこっちが元祖になる」——**空いた名を名乗れば元祖になる、を受付と同じ理屈として**（骨格「要検討」）。**大上に結びつけさせていない。**
- **締めの型は新しい。「名を呼ばれて終わる」。** 前の回（金の勘定）と続いていない。

## 人の出し方

- **本家——型①（路地の口）。** 夕方、店を畳む前。本家は机の上の厄除けを雨よけのビニールの下に並べ直している。**同じ誤読をしたうえで、目印の色を訊く。** 電車が上を通ってビニールの端が震える。
  - **雨よけが要る理由は[基礎設定.md](../基礎設定.md)「本家の店の場所」に書き足した**（高架の真下ではなく、雨を避けられるほど高架の下には入れない）。
- **一報は省いた。**
- **安藤・播谷・税所・占部は出ない。** 安藤は第三十話で電話、第三十二話で電話なので、空くのは一話だけ。

## この回で決めたこと

- **本家の店の場所を改めた**（[基礎設定.md](../基礎設定.md)「本家の店の場所」）。見上げれば高架があるが、店は高架の真下ではない。雨を避けられるほど高架の下には入れないので、机には雨よけが要る。東西を建物に挟まれた路地で薄暗い。**上には西鉄の線路の高架と、高速バス用の高架道路の両方がある。本文では電車で書く**（第二十七話・第二十九話・この回）。
- **湧いた券は、引き取っても消えない**（[怪異/031](../怪異/031_呼出.md)「引き取ったあと」）。
- **締めの型に「名を呼ばれて終わる」を足した**（[PROJECT_RULES.md](../../PROJECT_RULES.md)「締めの型の、大上屋での使い分け」）。
