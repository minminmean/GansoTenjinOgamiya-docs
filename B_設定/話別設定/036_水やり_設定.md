# 第三十六話　水やり

**第三十六話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/036](../怪異/036_水やり.md)。

**定型回。** [I019 貸し植木](../../C_執筆管理/話アイデア/執筆済み/I019_036_貸し植木.md)から起こしたが、**骨格から大きく組み直した**（下記「骨格からの変更」）。**物の系統の四本目。** 品名は立ったが書いていないので、**題は漢字の副題「水やり」**（第三十五話と同じ扱い）。

**時期は五月の半ば。** 曇りの続く、梅雨の手前。**第三十五話（五月の上旬から中旬）と重なるが、並行して互いに触れない。** 本文の冒頭は「五月も半ばを過ぎると」。二度、小雨。**定型回なので年表には載せない。本文に日付は出していない。** 曜日（月曜・木曜・日曜）は出している。

## 骨格からの変更

- **鉢は会社の備品ではなく、得意先の先生の母親の形見にした。** 会社の備品なら替えれば済み、話が成り立たないため（著者の指摘）。
- **木と読み違える段を置かなかった。** 依頼人が初めから鉢を疑っており、植物の記憶は急がないので、十日前に来た木がここまで覚えているはずがない。**大上もすぐ鉢と認める。** 湿りの階段の一段目は「色では割れず、記録で割れる」になった（[進行記録.md](../../C_執筆管理/進行記録.md)「湿りの階段」）。
- **詰まりを「鉢が何をしているか」に移した。** 読むのは依頼人の控え（曜日）。
- **引き取らず、手続きで噛み合わせて閉じた。** 鉢は花の世話を覚えきっており、木を嫌っているのではなく、木にとってその手順が噛み合わない（著者の指定）。
- **安藤の「動くけん物、は当てにならん」は使っていない。** 安藤は出していない。

## 芯——花の世話を覚えた鉢

- 西新の宮原歯科の待合、受付の小窓の脇に据えた大鉢。**先生の母親（医院では「大奥さん」）が、毎週月曜の朝、市場の帰りに花を抱えてきて、前の週の花を抜き、鉢を洗い、水を張って生け替え、それから医院を開けていた。** 三年前に亡くなるまで一週も欠かさず、**水替えだけは人にさせなかった。**
- 先生が「空けとくとは寂しか」と言い、貸し植木の木（黒いプラ鉢ごと）を入れるようになった。
- **鉢は月曜ごとに底に水を張る。** 木はプラ鉢の底から水に浸かって根が腐り、二週ともたない。
- **花を入れた週は、月曜に水が澄んで、同じ深さに張られていた。** 誰も替えていない。
- **目印の目盛り**——木を入れていた週は湿りが進み（木曜より月曜が濃い）、花を入れた週は変わらなかった。**大上に読ませていない。** 説明もしていない。

## 品名の段——立って、書かない

1. 西新の駅のホームで品名が立つ。溝口さんの「水は、私しかやりよらんとです」から。「もう一人、いや、もう一つ、やっているものがいる」。
2. **「行の頭は、宮原歯科。品名は、水やり。壱。」「書けば、入る。」**
3. **藤崎の小引き出しの音を思い出す。**「巻き癖と書いて、時計ごと入った。巻き癖は、時計から出たものだった。」「水やりは、あの鉢から出たものだ。」「書けば、鉢ごと入る。先生の、お母さんの鉢が。」**「また、これだった。」**
4. 電車に乗らず、次の電車までホームの端に立つ。「帳面は、鞄から出さなかった。」

- **同源への疑念の三度目**（第三十二話・第三十五話・この回）。**規則には届いていない。** 第四十二話に積まれる。
- **帳面は開いていない。**

## 誤訳と処方

- 大上の読み：**「あの鉢は、花を待っているのだ。月曜の朝に、市場の帰りの花が来るのを。三年も。」** 実際は待っていない。世話の手順を覚えているだけ（[怪異/036](../怪異/036_水やり.md)）。
- **処方だけが当たった。** 訂正しない。当たったとは書いていない。
- **先生には、器のしていることをそのまま話した**（著者の指定）。月曜ごとに水を張る、中のものは一週間で替わると覚えている、花の世話を覚えている、木には合わない。
- **誤訳を先生と分け持った。**「お母さんの花ば、待っとったとやなかでしょうか」「……待たせとったとですね。三年も」。**感傷を残してよい回として書いた。**
- 先生「花に、します」。溝口さん「生け込みは、うちでも請けよります。月曜の朝、私が持ってきます」。

## 試した手順

- 日曜の晩、天神の地下街の花屋で、一週間もつものを、と頼んで買う。白い菊、黄色い小菊、名前の分からない緑の枝。**千五百円。**
- 月曜の朝八時、木を抜くと鉢には手の幅ほどの水が澄んで張られていた。**水は足しも抜きもせず、そこへ花を入れた。** 大上が束のまま差して倒し、**受付の人が見かねて生け直した**（「大奥さんの、見よう見まねです」）。
- 次の月曜、花は一週間ぶん萎れ、水は澄んで同じ深さ。

## 数と値段

| | |
|---|---|
| 見に行く | 一万（提示） |
| 調べ | 二日で二万（提示） |
| 受け取り | **見に行ったぶんと調べを合わせて二万。** 三日後、溝口さんが表の店に持ってきた |
| 花代 | **千五百円。** 大上は「うちが勝手に買うたもん」と断ったが、溝口さんが「伝票の、合わんとです」で置いていった。本家に家計簿へ付けてもらう |

- 生け込みは溝口さんの判で足りる。**木より花のほうが単価が高い。** 得をするのは会社で、会社から取った（第十九話「得する人から取る」）。
- **帳面は一行も増えていない。**

## 締め——物に残った痕

- 溝口さんが控えを一枚抜いて見せる。宮原歯科の欄に「ドラセナ、交換」の行が日付を変えて何本も並び、その下に新しいインクで一本。独立段落にした。

　　宮原歯科　大鉢　生け込み　毎週月曜

- 溝口さんの字、行の端に「溝口」の判。束を机の縁で揃えて帰る。**「行が一本、立っていた。うちの帳面ではなかった。」**
- **締めの型は「物に残った痕」**（第三十三話以来）。前話（依頼人のその後が向こうから届く）と続いていない。

## 依頼人と人物

- **溝口さん**（みぞぐち）：**初登場。** 貸し植木の脇山緑化（**架空**）の現場担当。三十の半ばくらいの男性。深い緑のポロシャツ（胸に葉の形の印と社名の縫い取り）、腰の革のケースに鋏と小さな物差し。**癖：伝票の束を机の縁に立てて、とん、とんと二度落として揃える**（何度も出した）。**持ち札は几帳面**——差し替えのたびに器の底の水の深さを測り、控えに書いていた。**降りられない事情は、得意先を切れないこと**（鉢は先生の母親の形見で、「この鉢が木を枯らす」とは言えない。先生とは前の担当のころからの付き合いで、ほかにも六鉢）。月一の約束を自分の判で二週に早め、この春から四本余計に替えた。**「伝票の、合わんとです」がいちばん困る。** 怖がっていない。
  - 下の名前は決めていない。
- **宮原先生**（みやはら）：歯科医。六十を少し過ぎたくらい。白衣の袖を肘までまくる。**癖：膝のあいだで組んだ両手の、親指の先を擦り合わせる。** 話を聞いて一度だけ萎れた菊を見る。**母親の名前は出していない。**
- **受付の人**：名前なし。五十の手前くらい、薄い水色の上っ張り。**癖：話しながら小窓の硝子を布巾で拭く。拭くところが無くなっても拭く。** 勤めて二十年。大奥さんの月曜を覚えている。
- **大奥さん**：先生の母親。故人（三年前）。
- **本家——型①（路地の口）。** 日曜の晩、看板を下ろしているところへ花を抱えて戻る。「花ですか」「仕事たい」「はい」「水に浸けとかんと、明日の朝までもちませんよ」「分かっとる」（分かっていなかった）「バケツ、店にありますけん」。前話の型②と続いていない。
- **安藤・播谷・税所・占部は出ていない。**

## 舞台

- **西新**：天神から地下鉄で十分ほど。商店街は夕方に店じまい、八百屋が青いシートを畳む、学生。**月曜の朝はリヤカーの行商**（キャベツ、玉ねぎ、朝採りの胡瓜）。
- **宮原歯科**（**架空**）：商店街から一本入った古い二階建ての一階。硝子戸に金文字。待合は長椅子二つ、雑誌の棚、受付の小窓。消毒の匂い。七時で閉まる。日曜休診。
- **大鉢**：膝の高さほど、口の広い、白地に藍の唐草。縁に小さな欠けが一つ。**有田とは本文に書いていない。**
- **目印**：小窓の下の腰板（左寄りから）、窓際の長椅子の端の壁（右の下のほうから）、硝子戸の脇の柱（真ん中より少し左）。交点は小窓の脇の床。

## 書いていないもの

- 鉢が何年、花の世話をされてきたか（「何十年か」）。
- 鉢がどうやって水を張っているか。
- 圃場へ戻った木のその後（感慨を置かない）。
- 生け込みが始まってからの宮原歯科。
