# 第三十九話　蒲池ビル　蔦　受　壱

**第三十九話の確定事項。** 基本の設定は[基礎設定.md](../基礎設定.md)。相手は[怪異/039](../怪異/039_蔦.md)。

**定型回。** [I023 大手門の蔦跡](../../C_執筆管理/話アイデア/執筆済み/I023_039_大手門の蔦跡.md)から起こした。**植物の系統の四本目**で、**現場に植物が一本も無い回。** 本筋⑦の直後なので、仕事をして引き取る回。題は記帳の行そのまま。

**時期は六月の上旬。** 梅雨入りから四日目の晴れ間で始まり、十日あまりのちの梅雨の晴れ間で閉じる。**雨は書いていない。** 第三十八話の安藤の場面（梅雨入りの日）の数日後から。**定型回なので年表には載せない。本文に日付は出していない。**

## 骨格からの変更

- **締めを「物に残った痕（余った塗料の缶）」から「街の景色」に替えた。** 第三十八話が「物に残った痕」で閉じているため。塗料の缶は、本家の読みを試す小道具として途中に置いた。
- **占部の「ひさしの下に立ちよった人、最近見らんね。……どげな人やったかね」を冒頭に置いた**（[進行記録.md](../../C_執筆管理/進行記録.md)「安藤の時計を刻む」）。
- **本家の読み（塗料）を足した。** 型③。
- **安藤の一言のあと、大上は「木」と訊いて外す段を足した。**
- **「半年たって出てきたら、返します」を入れた**（著者の指定。「実に大上が言いそうなことだ」）。
- **力を「天が分かる」にした**（著者の指定。[怪異/039](../怪異/039_蔦.md)「力」）。
- **写真館の奥さんには名前を付けていない**（著者の指定）。

## 芯——動かないものも、伸びる

- 大手門の蒲池ビル（四階建て。一階が蒲池不動産、二階が写真館、三階と四階は空き）。**北の外壁に、茶色がかった筋が地面から四階の窓の下まで這う。** 塗り直せば消え、半年で戻る。**塗り直しは蒲池さんの代で三度。** 今年は写真館の白い背景の壁にも出た。**秋が契約の更新。**
- 北の路地は隣の月極駐車場とのあいだ。日が回らず、昼でも夕方の色。**草一本無い。** 室外機が一台。路地の舗装に、畳半分ほどの新しいコンクリートの四角。
- **蒲池さんは筋の先に鉛筆で線を引き、日付を書いている**（一週間ごと。上のほうは三階の窓から身を乗り出して）。子どもの背丈を柱に刻むやり方。

## 読み——外す

1. 一日目：目印を三枚。北の壁の腰、路地の向かいのブロック塀、写真館の白い壁の隅。
2. 二日目：三枚とも湿る。「湿りは、植物か、物だ。」**路地に草一本無い。染みは上っている。**「木は動かない。根を張ったところから動かないから、木なのだ。」（第九話の言い方を継いだ）「動くのは、物だ。壁の中を、何かが上っている。」交点は北の壁の地際、コンクリートの四角の端。**「物なら、上っていくぶん、源も一緒に上るはずだった。源は、いちばん下にいた。」**
   - コンクリートの四角は「水道か何かの工事の跡だろう」で流した。
3. 本家の読み（下記）→翌日、倉庫の缶を見る。**線は東へ寄っていない。缶ではない。** 三日目の三枚は二日目より濃い（「濃くなるのは、覚えているだけのものではない」）。
4. 安藤の電話（下記）→翌日、蒲池さんに「この路地に、木の植わっとったことはありますか」「なかです」。**蔦は木ではないので、嘘ではない。**
5. **上へ追いかける（一度だけ）。**「下から読んで分からないなら、上から読めばいい。」四階の空き室の北の窓から身を乗り出して、筋の先の脇と窓の横に一枚ずつ、三枚目は三階の窓から。蒲池さんが後ろでベルトを掴む（「落ちんでくださいよ」）。
6. 翌日：上の三枚も湿り、**線は下を向いて、同じ地際の四角の端に行き着く。**「源は、上っていなかった。」

- **答えを言うのは依頼人。** 蒲池さんが窓枠の外に鉛筆で今週の線を引き、筋を鉛筆の尻で上から下へ辿って「はじめは、そこの根元から出よりました」「蔦の根元です」。父親が夏に涼しいからと這わせ、北向きでよく育たなかったが四階まで上り、十何年前に枯れて剥がした。
- 「木は動かない。だが、伸びる。」**地の文で機序を説明していない。**

## 生き死にと同源——一行

- 「根は、どげんしました」「掘りました。残っとったら、また出てくる、ち言われて。掘って、コンクリば打ちました」。**あの四角だった。**
- 「蔦と書けば、蔦ごと入る。その蔦は、根まで掘られて、もう無い。」**同源の疑念の五度目。第三十七話ほど重ねず、一行で済ませた。** 規則には届いていない。
- **安藤の「生きとるもんは、受けたらいかん」（第二十話）に照らした確かめ。** 本文では安藤の言葉を持ち出していない。

## 本家——型③（読ませる）

- 四畳半。本家は流しで、占部にもらった新玉ねぎを薄く切って水にさらしている。
- 同じ材料から、本家は「**塗料やなかですか**」。三度塗って三度出た、塗るたびに同じ塗料が運ばれてきて壁に乗る、動く物ならそっち。**第九話の理屈（物は動く）には、本家の読みのほうが合っている。**
- 「塗り屋は、たいがい一缶置いていきますけん」「なんで分かる」「塗装のバイトで、置いていきよったでしょう」。**元祖も覚えていた。思い出さなかっただけ。** 同じ頭が別の答えを出す。
- **本家の読みも外れた**（倉庫はビルの東の端の階段下。缶は三つ、同じ塗料屋。二つは使いかけ、一つは四度目のぶんで封を切っていない）。**本家に当てさせない。**

## 安藤——電話

- 三日目の晩、大上からかける。三度目の呼び出しで繋がる。「なんか用か」。
- 「動く物が、動かんとです」「動かん物か」「草木の無かとこで湿るなら、無うなった草木ば探せ」「無うなった」。切れる。
- **観察は正確で、答えは言っていない。** 大上は「無くなった草木」を植え込みや木と取って、路地の横を探し、見つけられない。
- **様子の変化は置いていない。** 前話で立っている姿を見せ、この回は占部の一行が痕。**間は長くない。**

## 占部——痕

- 冒頭。梅雨入りから四日目の晴れた朝、八百屋の余りの新玉ねぎを二つ。
- 「ひさしの下に立ちよった人、最近見らんね」「こないだの雨の日に、来とりましたよ」「そうね」（ひさしの下を見たまま）「……どげな人やったかね」「紺のジャンパーの」「ああ、そうそう。そげな感じやった」。
- **大上は繋げない。** 玉ねぎを机の端に寄せただけ。**名前を知らない同士の二人（占部と安藤）の、片側が抜けはじめている。** 地の文で触れていない。
- 「玉ねぎは薄う切って水にさらさんね」が、四畳半の本家の手元に渡る。

## 値段——相手の持っている数字

| | |
|---|---|
| 見に行く | 一万（「何も無かっても、一万ですか」「見に行くぶんですけん」） |
| 引き取り | 別に五万 |
| 塗り屋の見積もり | 北面のみ、足場共、四十二万（蒲池さんがシャツの胸のポケットに畳んで持っている） |

- 「安すぎる」「塗り屋が四十二万で、半年しかもたん。五万で、なんで止まるとですか」。**止まる理由は帳面だとしか言えない。**
- **「半年たって出てきたら、返します」**（著者の指定）。蒲池さん「塗り屋は、そげんこと言わんかった」。見積書の隅に鉛筆で「五万、半年」。
- **それでも四度目は塗る**（「塗るのは、塗りますけん」「はい」「止める理由は、無かった。」）。**どちらも正しい。**
- 十日ほどあと、表の店で六万円（一万と五万）。「半年たったら、また見ます」「出てきたら、返します」「返してもらいますけん」。
- **大上は手帳に「蒲池ビル、五万、半年」と書いた。「柳橋、二万、次の晦日」の行のすぐ下。** 待ってもらう金と、返すかもしれない金が並ぶ。
- **帳面は一行増えた。**
- **第四十話（厄除けの苦情）への地ならし。** 引き取りには「返します」を付けた。唯一の売り物の厄除けには、何も付けていない。**本文ではこの対比に触れていない。**

## 引き取り

- 夕方、北の路地。蒲池さんには一階の事務所で待ってもらった（段取りとして流した）。駐車場の車は出払い、室外機も止まっている。
- コンクリートの四角の脇に膝をつく。**記帳の前に、壁に向かって口の中で誤訳**——「上りたかとやろ」「まだ、上れると思うとる」。壁は何も返さない。
- 祝詞八文字、「元祖天神大上屋、大上大介がお受けします」。

　　蒲池ビル　蔦　受　壱

- **書き終えても、壁は何も変わらない。** 筋は筋のまま。「半年で半年ぶんしか上らないものは、止まったかどうかも、その速さでしか分からない。」
- **済んだ合図は、依頼人の記録が届く形にした。** 十日ほどあと、蒲池さんが「線ば、越えとらんです」。**鉛筆の線が証になった。**
- **帳面の重さは書いていない。** 結界も書いていない（蔦は何も害しにかかっていない）。

## 締め——街の景色

- その週の終わり、梅雨の晴れ間。北の壁は四度目の白で、路地の暗がりの中でそこだけ少し明るい。**筋は無く、壁の腰の鉛筆の線も日付も一緒に塗り込められている。** コンクリートの四角は乾いたまま。
- 帰りにお濠端を回る。**石垣の下の濠を、蓮の葉が一面に覆い、水の色が見えないほど。花はまだ無い。丸い葉の幾百が茎の上に持ち上がって、どれも空のほうを向いていた。**
  - 福岡城の濠の蓮は、五月には一面が葉に覆われる（著者の見聞）。**花は七月から八月で、早朝に開いて昼には閉じる**ので、昼に通る人は花を見ないことが多い。六月の上旬に「花はまだ無い」で合う。
  - **力（天が分かる）の唯一の手がかり。説明しない。**
- **締めの型は「街の景色」。** 前話（物に残った痕）と続いていない。前に使ったのは第三十四話。

## 依頼人と人物

- **蒲池さん**（かまち）：**初登場。** 大手門の蒲池ビルの持ち主。六十の半ば。半袖の開襟シャツに灰色のズボン。**癖：右の耳に大工の平たい鉛筆を挟んでいて、話の切れ目に抜いては挟み直す。** 筋の先に鉛筆で線と日付を引く。**持ち札は意固地**（四度目も塗る）。記憶に鈍いたちで、壁の前で何も感じない。困っているのは体裁と家賃。**来た理由は「何も無か、ち言うてもろうて、塗るため」**——写真館の奥さんに言われて。
- **写真館の奥さん**：二階の借り手。五十くらい。**名前は付けていない**（著者の指定）。証明写真の白い背景の壁に筋が写り込み、一枚ずつ直して渡していた。「ここに立ってもろうたら、ちょうど肩の後ろに来るとです」。更新の判を押した。
- **本家**：四畳半（型③）の一場面。
- **安藤**：電話。**占部**：冒頭。**播谷・税所は出ていない。**

## 舞台

- **大手門**（実在。中央区）。天神から西へ歩いて二十分ほど。明治通りから一本入ると人が減る。古いビルと新しいマンションが交互に並ぶ。**蒲池ビルは架空。**
- 蒲池ビル：角の丸い四階建て。一階の硝子戸に金の字の剥げかけた「蒲池不動産」。北側は月極駐車場とのあいだの細い路地。倉庫は一階の奥、東の端の階段下の物入れ。
- お濠：福岡城の濠。石垣の下、蓮。

## 書いていないもの

- 力が何か。**名付けも。**
- 半年後。
