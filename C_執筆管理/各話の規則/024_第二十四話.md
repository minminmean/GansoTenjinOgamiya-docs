# 第二十四話　点検　の規則

確定事項は [024_点検_設定.md](../../B_設定/話別設定/024_点検_設定.md)。ここにあるのは本文を直すときの縛りだけ。

## 直してはいけない——「合」は中身を言わない

- 報告書の「『番』の行には、合、とある。数が合っている、という意味だ。何もいない、という意味ではない」を残す。**最後の段がこの一文に掛かっている。**
- **報告書に「異常なし」と書かせない。**「変わりありません」のまま。花田さんに押し切られる形に直さない。
- 最後の段の「四〇二の合も、そこに丸椅子があるとは言っていなかった」「帳面の中に入っているのが母でも座布団でも、『番』は合と書く。帳面も、そうなのかもしれない」を削らない。**点検の話と帳面の話を繋いでいるのはここだけ。**

## 直してはいけない——帳面の推測は、推測のまま

- 「坂口方の母が弐。坂口方の座布団が弐。数は、どちらも同じだ」「帳面にとって合っていたのは、はじめから数だけだったのかもしれない」は、**「かもしれない」で止める。** 言い切りに直さない。
- **「入っていない」「消している」とは書かない。** 「入っているのが母でも座布団でも」の言い方のまま、**中に何かが在るという確信を残す**（[PROJECT_RULES.md](../../PROJECT_RULES.md)「大上が知らないこと」）。
- **確かめる場面を足さない。** 帳面を開いて見比べる、出して試す、は書かない。
- 思考実験で**出てくるのが複製だとは言わせない。**「あのとき入れた遥さんが、あのときのまま出てくるのだろう」のまま。

## 直してはいけない——座布団の始末

- **座り心地を書かない。運び先を書かない**（第二十一話の縛りと同じ）。
- 「名乗っているあいだも、脈は打っていた」を残す。**止まった、縮んだ、とは書かない**——取引の瞬間の結界に見える描写にしない。
- **分量をこれ以上増やさない。** 第二十一話から回したぶんは、これで払い終えている。

## 直してはいけない——四〇二の読み筋

順番を崩さない。**点検で壱多し → 目印が白い → 記憶ではない → 丸椅子かもしれない → その場で『番』を回して合 → 夜だけ何かが増えている → 箒とちりとり → 二晩目に立つ。**

- 「なんの変哲もない物か、生きている動物だ。もちろん、人も含まれる」を「物か人」に縮めない。
- **その場で回す手順は、第五話・第十二話と同じ文にしてある**（「帳面を開いて、『番』を回した。手を触れていないのに、頁が勝手にめくれて、最後の一枚で止まった」）。**寝て回す形に戻さない。** 寝たときに働くのは遠いところで、目の前は意識して回せば数える。
- **箒の目にしない。** 箒とちりとりは流しの下にしまってあり、取りそこねた埃が少しあるだけ。**埃が溜まるほど汚れていたことにしない。**
- 園田さんが箒を持って上がる描写を戻さない（昼に流しの下で見つけているので食い違う）。

## 直してはいけない——店の位置

- **苦情を出したのは三階の奥の店。四〇二はその真上。園田さんは三階の手前の店。** 入れ替えると、園田さんが自分の店の真上で寝ていることになる。
- 大上が園田さんに言うのは「下の店に」。「隣の店に」に戻さない（四〇二の前で話している）。

## 直してはいけない——通路と駐輪場

- **通路は訊かれて答える形で一度だけ。** 苦情の場所にしない。困り事に膨らませない。
- 「いま分かるのは、『番』なりの基準がある、ということだけだ」で止める。**基準が区切りや役割だと言わせない。** 境目の札で囲う発想に繋げない（[札.md](../../B_設定/札.md)「屋上を囲えば、『番』が数えられる」）。
- **駐輪場は「合」。** 読めない場所に直さない（[帳面.md](../../B_設定/帳面.md)「緩い線でよい」）。
- 駐輪場の料金を取らないことに、地の文で触れない。

## 直してはいけない——約束と電話

- 「電話は来なかった。」「こちらからは、かけなかった。」のあとに何も足さない。**『番』の代償だと言わない。** 知っていて受けた男なので、驚かせない。
- 税所さんとのやりとりは「……毎月の、約束でした」「でした」「はい」で終える。**税所さんに理由を訊かせない。**

## 税所さん

- **付箋の「点検」を書くのは税所さん。言葉を出したのは大上。** 税所さんに「点検ですね」と言わせる形に直さない（助言になる）。
- 顧問料と点検料が同じ一万五千円であることに触れない。
- 「『番』に礼を言いたくなった」はこの回では使っていない。**足さない。**

## 本家

- **場面を持たない回**（型⑥）。一報の一行と、香椎へ出ていた一行だけ。**寝る前の言い合いの場面を足さない。**

## 題

- **行が立っていないので漢字の副題「点検」。** 「一階通路　見られず」は報告書の一行で、帳面の行ではない。題にしない。

## 表記と方言

- **花田さんは標準語。** 博多弁を混ぜない。
- 園田さんの「言うとらすと思うとったけど」は鶴田さん（第三者、自分の意思で言う側）について。**「言うとらっしゃる」に置けるので通る。** 次の「言うとらんとやろうね」は否定なので「らす」を付けていない。
- 読みは[変換辞書/読み.tsv](../../Z_その他/変換辞書/読み.tsv)に登録済み（花田・鶴田・園田・二日市・香椎）。**本文に丸括弧は書かない。**
