# 番外「童子」の規則

確定事項は [怪異/E002_失わせるもの.md](../../B_設定/怪異/E002_失わせるもの.md)。

## 語りの時間軸——二十二年前の安藤が、いま経験している

**述懐の枠を置かない。** 語っているのは二十二年後の安藤ではなく、二十一歳のその秋にいる安藤。地の文は過去形だが、視点は現在から振り返っていない。

- **置かない語**——「そのころは」「いま思えば」「いまでも」「その後」「あとで」「のちに」「当時」「それから何年か」「〜ようになった」。**先の人生を要約する形は全部これに当たる。**
- **効くのは、読者だけが仕掛けの外にいるという構造。** 語り手が先を知っていると、消された師匠の穴を語り手が先に埋めてしまい、**気づかないまま進む一夜が成立しない。**
- **場面の中で気づいたことは書いてよい。** 「面白がっている間、俺は消されずに済む」は申し立ての最中にその場で思ったこと。**その場の気づきは、あとからの解説とは別。**
- **修行のころの回想も可。** その晩の彼が思い出したものなので、時間軸の内側にある。

## 分からせておくこと——勘定だけ

**力が囲いに吸われていること、外へ出せるぶんがそのぶん減ったことは、街へ戻って札が込まらなかった晩に自分で詰めている。**

- **「考えたが、分からなかった」と書かない。** 封じた直後にもう「囲いを保つほうへ、内側から引かれている」と分かっている以上、あとから分からなくなるのは辻褄が合わない。
- **書くのは「俺が組んだ封印が、俺の力を吸っている。残った力はこれだけだ、ということだ」の水準まで。**
- **術式を理解している書き方をしない。** 封じは即席で、その場の理屈で閉じたもの。**「どこに何を通したかも覚えている」「分からないところは一つもない」は書きすぎ。** 分かるのは勘定で、機序ではない。
- **ただし、できると思った理屈は書く。** 境目の術式の場の力を自分の力に置き換える、留めの力の源を自分に繋ぎ変える、術式は自分の内にあるから消されない——**封じの場面を盛り上げるための、その場の読み。** 理屈が無いと、封じがあっけらかんと通ってしまう。
  - **書き方は短い言い切りで。** 「術式」「結界のようなもの」「つまり〜ということだ」のような、機序を分かっている人の言い方をしない（最終確認で三段落を書き直した。著者）。**この段を直すときも、理屈を説明に戻さない。**
  - **通らないかもしれない、と対にして置く。**「この申し立てが通じなければ、俺は消えるのだ」。**確信のない読みなので、機序の保証にはならない。**
  - **読みは当て推量のままでよい。** 実際に通った理由は、向けていないから（[怪異/E002](../../B_設定/怪異/E002_失わせるもの.md)「封じの作法」）。**「内にあるから消されない」とずれていて構わない。** 観察は正確で、機序は当て推量——この人の型どおり。**地の文で正さない。**
- **分からないから困っているのではない。** 引かれる先が分かっていて、それでも残りがこれだけしかない。**そこから「札を切らさない」が出る。**
- **戻らないことも分かっている。** 囲いは下ろせないので、上限を知ったうえで残りをやっていく形。
- **分からないままにしておくのは代金のほうだけ**——趣味が、友人が、名前が抜けること（[怪異/E002](../../B_設定/怪異/E002_失わせるもの.md)「封じた直後の手応え」）。

## 橋の上——増長は、その日のうちに裏返す

**前半の思い上がり（名指しされたのは名が売れているから）は、橋の上で本人が正す。** 語り手が後年から訂正する形にしない。

- 順は、釘十一本 → 無いと明日が止まるものだけが穴になる → 拝み屋は誰の朝も止めない → **残っていたのが俺だけだった** → あれを疑う。
- **疑いで止める。** 何が師を消したのかは証明できない（[怪異/E002](../../B_設定/怪異/E002_失わせるもの.md)「守る線」）。**「証拠になるものは、証拠になる前に無い」の一行を残すこと。**
- **最後は、疑いの先が自分の中にいるところで閉じる。** 訊く口が無く、あったとしてもあの言葉が分からない。**ここを削ると、二十二年確かめないことの説明が落ちる。**

## 締め——手を動かして終わる

街の六畳で紙を漉く一連。**その後の二十二年を要約しない。**

- 年賀状が何年か続いて途切れる形の締めは外した。**立石さんとの関係は「番号だけ書いて渡した」で閉じている。**
- 札の生産量は、その年の前半（百五十枚超）と、これから書けない見込み（残り三ヶ月で二十枚）の二つだけ。**落ち着いた先の五十枚は書かない。**
- 「札を切らさない」は、あとで身についた作法ではなく、**その晩に決めたこととして書く。**

## 安藤を駆け出しにしない

独立して一年半、片づけた仕事が三十いくつ、伊田でも後藤寺でも名前で話が通る。**増長には腕の裏付けがある**（[怪異/E002](../../B_設定/怪異/E002_失わせるもの.md)「駆け出しにしない」）。第一話の大上との対比は、地の文でも台詞でも説明しない。
