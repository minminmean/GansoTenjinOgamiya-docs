# 番外「家」の規則

確定事項は [話別設定/E003_家_設定.md](../../B_設定/話別設定/E003_家_設定.md)。

## どちらの大上か、を決めない

**家は二人の大上を区別しない。** 「廊下の奥に、増やしたほうを立たせた」「元のほうが書いた」の類を足さないこと。**どちらが先にいたかは、数には関わらない**、で止める。第二話の「その行を書いたのが本物のほうだったかどうかは、分からない」を、番外が精算しないため。

- 番外で大上を外から書かない規則（[PROJECT_RULES.md](../../PROJECT_RULES.md)）の例外。**語り手が『家』で、しかも同一性を気にしないので、一人であることを保証しない。**
- 地の文で「大上」と呼ばない。「男」「家人」のまま。

## 家の語彙を崩さない

- **人を名で呼ばない。** 聞こえた台詞の中にだけ名が出る。
- **自分のことは「自分」と言う。** 『家』は自分がこの家だと思っているので、「この家が」「家が」と三人称で自分を指さない。
- **第二話の「四隅が寄った」は、覗き込んだこととして書く。** 部屋を動かした、寄せた、とは書かない。
- **機序を説明させない。** 家は自分のしていることを「増やした」「消した」「移した」としか言わない。帳面の仕組み、噛み砕き、代償には触れない。

## 祖母の覚えていたことの段

- **「帳面」の語を変えない**（著者の指定）。「帳簿」にしない。後段の大上の帳面と同じ語であることが筋。
- **得た、覚えた力だ、とは書かない。** 並べるのは出来事だけ——残っていた、覚えた、一緒に数えた、箱が出た、無くなった、数えるのは自分だけになった。**「何がそれを叶えたのかは分からない」を残す。**
- **香典・香典返し・四十九日の語を出さない。** 白い包み、同じ数の箱、七を七回。
- **「ほかに、することがなかった」を戻さない。** 数えることには、祖母の記憶という相手がいた。
- **祖母の記憶に触れるまでは、数の語を置かない。** 冒頭の「いちばん多かったのは、七だった」「三になって、長いあいだ三だった」「三が、二になった」のような形に戻さない。形で書く（すき間ができた、誰も座らないのができた、また空いた）。
- **「覚えている形を、数えてみた」を残す。** 七が初めて出る一行。
- **「抽斗（ひきだし）」を「引き出し」に、「薬缶（やかん）」を「やかん」に直さない**（著者の指定）。古い怪異の語りなので、あえて古い字を使う。ルビは丸括弧で振る（[テキスト変換規則.md](../../Z_その他/テキスト変換規則.md)「特例」）。

## 全員を消した場面

- **遥も含めて全員。** 「増やしたぶんだけ消した」と読める書き方に直さないこと。
- **出し直した二人が騒ぎを覚えていないことは、説明しない。** 「何も言わなかった」「いつものように出ていった」で置く。
