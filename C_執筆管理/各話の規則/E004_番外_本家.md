# 番外　本家　の規則

本文は [A_本編/E004_番外_本家.md](../../A_本編/E004_番外_本家.md)、確定事項は [話別設定/E004_本家_設定.md](../../B_設定/話別設定/E004_本家_設定.md)。

## どちらの大上か、を決めない

**本家がどうやって坂口家の廊下に立ったかを足さないこと。** 「玄関に座っていたはずが」「気がつくと廊下に」の類も、「廊下へ歩いていった」の類も、どちらを書いても第二話の「その行を書いたのが本物のほうだったかどうかは、分からない」が精算される。**書くのは、最後に覚えているのが廊下だということまで**（番外「家」の規則と同じ）。

- 「書いたほうが帳面を持っていて、書かれたほうは持っていない。それだけのことだった」は、**どちらが元だったかではなく、どちらが書いたか**しか言っていない。直すときもこの線を越えない。

## 本家に、二週間ぶんを自覚させない

- **見ていない行を知っていることには触れてよい。** 本家の読みは「中にいたからだろう」で止める。
- **札を押し出す手つきを、本家が自分の手に見つける場面を足さない。** 元祖の二週間を持って出てきたと本家が気づけば、出されたのは入れたものではない、という最奥に寄る。

## 感情を書き足さない

- 元祖への感謝・執着・嫉妬・元祖を失う恐れは、[登場人物.md](../../B_設定/登場人物.md)で**描かない**と決めてある。
- **四晩目に書いたのは、自分が本物でないことの勘定だけ**（弁えの根本。著者の指定）。消えるかもしれないことも、そこに入れてある。**元祖への感情に広げない。** 「消えても、消えなくても、俺は本物ではない」から先へ、嘆きや願いを足さない。最後は「どれも、もうやっていた」で行いに戻して閉じている。
- **「本物」の線は、出されたかどうかで引く。** どっちが先に廊下にいたかで引き直さないこと（上記「どちらの大上か、を決めない」）。
