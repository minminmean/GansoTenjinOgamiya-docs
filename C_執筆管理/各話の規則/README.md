# 各話の規則

その話だけに効く縛りを、一話につき一ファイルに置く。

- 全話に波及する規則は [PROJECT_RULES.md](../../PROJECT_RULES.md)。話ごとの確定事項（何が起きたか、いくらだったか）は [話別設定/](../../B_設定/話別設定/) の同じ連番のファイル。
- **ここに置くのは、その話の本文を直すときにだけ要る指示。** 直してはいけない箇所、既に本文にある逸脱の扱い、その話に限った据え置き。
- ファイル名は本編と同じ連番＋話数（`001_第一話.md`）。**番外は本編と同じファイル名を使う**（`E002_番外_童子.md`）。
- **縛りのない話にはファイルを置かない。** 第五話・第九話のように無い話は、無いままでよい。
- **読むのは、その話の本文に編集が及ぶときだけ。** 新しい話を書くときに全部を読む必要はない。
