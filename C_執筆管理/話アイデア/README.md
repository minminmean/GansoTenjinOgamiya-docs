# 話アイデア

**話の骨格の置き場。** 一案につき一ファイル。合意も着手もしていない、素の案の段階。

**番号は `I` ＋三桁の通し番号。** 案ごとに一度だけ振り、以後は動かさない。新しい案は続きの番号を取る（欠番は詰めない）。ファイル名は `I0NN_題`。

**本文にした案は [執筆済み/](執筆済み/) へ移す。** 移すときにファイル名へ話数を挟んで `I0NN_話数_題` にする（`I001_008_唐人町の預かり札.md`）。一覧の行はこの表に残したまま、題の後ろに済の印を添える。

確定した設定は[B_設定/](../../B_設定/)へ、未使用の伏線と本筋の材料は[アイデア.md](../アイデア.md)へ移す。**アイデア.md の材料を本文にしたら、その回の話アイデアへ移す**（既にある回ならファイル末尾の「アイデア.md から移した材料」へ。回のファイルが無ければ、そのとき番号を振って執筆済みに置く。I071〜I074がこれ）。**ここから本文に入るときは、まず提案して合意を取る**（[PROJECT_RULES.md](../../PROJECT_RULES.md)「進め方」）。

## 由来のバランス

**場に寄せない。** 記憶の由来は場・人・動物・植物・物の五つで、場はその一種にすぎない（[記憶と怪異の法則.md](../../B_設定/記憶と怪異の法則.md)「由来の五系統」）。『家』も『番』も場の系統なので、放っておくと全部が場になる。

- 既出で場でないのは**ホテル白水の泊まり客（人）**、**純喫茶まりもの煙草の匂い（物）**、**白金一丁目の野良猫（動物）**の三つ。
- **I007・I008・I009 が動物・植物・人の一本目**にあたり、**I010・I011・I012 がそれぞれの二本目**。**I007・I008・I009は済んだ（第十話・第十三話・第十七話）。動物の二本目にあたるI010も済んだ（第十八話）。人の二本目にあたるI011も済んだ（第十九話）。植物の二本目にあたるI012も済んだ（第二十話）。**
- **I002の由来は、場から物（空気）へ振り替えた**（[進行記録.md](../進行記録.md)「決まったこと」）。匂いは空気に乗るので、そのまま物の記憶にできる。**動くので目印の反応が移り、客の服にまとわりついて店の外へ出ていく。** 大上は場だと読んで空振りする。**物の系統の一本目。**
  - **湿りの初出がI002に移る。** 湿りは植物と物で同じ色なので、I008では「同じ色なのに相手が違う」という二度目の読み違いが作れる。**I002→I008が二段になる。**
  - 「人へ振る」案は消えた（先代一人の記憶にする案。I009と役割が重なる）。
- **残る場は I001・I003・I004 の三本**（屋台の話を数えれば四本）。数（票）、範囲、繰り返し。
- **動物の系統は I007・I010・I017・I022 の四本。** 一匹、経路、数、そして**小さすぎるもの**。**I007は済んだ（第十話）。I010も済んだ（第十八話）。I017も済んだ（第二十八話）。**
- **I005・I006・I013・I024・I027・I029 は由来を持たない回**（断る、出す、点検、保証、渡し、払う）。**I015は人で確定した。**
  - **I024とI027は、怪異が一つも出ない。** 出ないこと自体が芯なので、途中で「実は本物だった」に転ばせない。
  - **由来なしはこれ以上増やさない。** 並べると商売の話ばかりになる。
- **物の系統は I002・I016・I018・I020 の四本**（I019は物と植物の境目）。道具・石・水・空気の記憶で、**場といちばん読み違えやすい**（[記憶と怪異の法則.md](../../B_設定/記憶と怪異の法則.md)「物の記憶」）。**動くので札の反応が移り、中のものにまとわりついて持ち出される。**
  - **四本で撃ち分けが違う。** I002は空気で**受けても出せない**、I016は道具で**現物ごと入る**、I018は形見で**現物ごと入るから引き取れない**、I020は水で**出せないと分かったうえで受ける。** 同じ規則の四つの面。
  - **物を増やさない。** 四本で足りている（[進行記録.md](../進行記録.md)「由来の勘定」）。
- **植物の系統は I008・I012・I019・I023・I025・I026 の六本。** あった形、生きている百年、周期（実は物）、伸びていた向き、季節の繰り返し、育っていた高さ。**どれも「急がない」の別の面。**
  - **I019・I023・I026で一つの階段になる。** 外す（答えは物）→外す（答えは植物）→**割れない。** 三度めで決着そのものを諦め、**割れないまま書けてしまう。**
    - **裏づけは[記憶と怪異の法則.md](../../B_設定/記憶と怪異の法則.md)「植物は、物に近い生き物」。** 湿りが同じ色なのは、植物が生き物でありながら物の側の性質を多く持つから。**目印が割らないのではなく、割れる線がそこに無い。**
    - **湿りが続けて出ること自体は避けない。** 同じ色で相手が違うのがこの作品の読み違いの型なので、**続くほど「今回はどっちだ」と読者の側で考えることになる。**
    - **避けるのは、素直に植物で通る回が並ぶこと。** 既出の素直な回はI008とI012の二本だけで、**I019から先は一本も素直に通らない。**
    - **三本は続けない。** 三十六・三十九・四十三で、あいだに二話ずつ入る（[進行記録.md](../進行記録.md)「湿りの階段」）。**同じ手順を続けて見せないためであって、湿りを散らすためではない。**
    - **四度目は要らない。** 三度めで決着そのものを諦めるのが山なので、以後は湿りで読み違えさせない。
  - **由来の数に上限は置かない。** 並べるときは目印の色で見る。動物と人はどちらも焦げ、植物と物はどちらも湿る（[進行記録.md](../進行記録.md)「由来の勘定」）。

## 読み心地の目安（決まりではない）

- **I001 と I007 を早めに。** 系統が場に寄っている印象を、はじめのうちに割っておく。I007で目印の焦げを出す。**どちらも済んだ（第八話・第十話）。**
- **I001 → I002 を続けると二話一段になる。** I001が「引き取れるが対象が決まらない」、I002が「数では読めない」。合わせて、引き取りの実務は員数ではなく**品名を決めること**だ、という理解が積まれる。
- **I004 は空振りのあとに。** 数読みが素直に通る回なので、I002・I003・I008で読めない回が続いたあとに置くと呼吸が戻る。

## 共通の縛り

- **強い力を渡さない。** 引き取る怪異は祓えば素直に消える程度のものだけ（[連載の組み方.md](../連載の組み方.md)「定型回の怪異は弱いものにする」）。
- **帳面の真相に近づかない。** 「分かるのは一回につき一つまで」は本筋回の枠。
- **大上の代償を進めない。** 忘れられることも、暮らしの水準も、一定のまま動かさない。
- **大上を熟練させない。** できることが増えるのと同じ速さで、分からないことが増えること。
- **時期を決めない。** 年表に載せない。季節や気候に寄りかかると、その回が時系列に縛られる。
- **数を追わない。** 帳面の頁も行数も、札の枚数も、財布の中身も、伝票も。**記帳の場面で何行目かを指定しない**（[PROJECT_RULES.md](../../PROJECT_RULES.md)「執筆の作法」）。
- **目印の色は読ませてよい。** 由来は当たる。**外させるのは、日を追ってどう動くかのほう**——一度貼っただけでは怪異かどうかは出ない。大上はその型を習っていない（[札.md](../../B_設定/札.md)「二人の読み方の差」）。**色が読めることと、相手を理解することは別。**
- **裂けを出さない。** 裂けは害意のしるしで、定型回の怪異は害意を持たない。**裂けが出た時点で、その回は定型回ではなくなる**——受けるべきでないのに受けざるをえないジレンマは、本筋の重さを持つ（[札.md](../../B_設定/札.md)「裂けは、断る理由にならない」）。
  - **例外はI022で、あれは裂けではない。** 色を伴わない切れを大上が裂けと読み違えるだけで、正体は距離ゼロの焦げ。**裂けそのものは消費しない。** ただし**本物の裂けの回より後**に置くこと——前だと、身構える最初の一度が空振りのほうになる。
- 依頼人は普通の人のまま。**恐怖以外の持ち札**と、**降りられない事情**を必ず一つずつ持たせる。**既出と重ならないことは条件にしない**（[連載の組み方.md](../連載の組み方.md)「依頼人の持ち札」）。回ができてから当てるので、結果として重なることがある。**重なっても選び直さない。**
