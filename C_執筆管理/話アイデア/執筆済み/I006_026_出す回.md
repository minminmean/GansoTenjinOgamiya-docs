# I006　出す回

**第二十六話として書いた。** 確定事項は[話別設定/026](../../../B_設定/話別設定/026_春吉三丁目_朝掃き_渡_壱_設定.md)、出したものは[怪異/015](../../../B_設定/怪異/015_朝掃き.md)、縛りは[各話の規則/026](../../各話の規則/026_第二十六話.md)。**骨格から変えたもの**——現場は西中洲の小料理屋「ちとせ」の裏路地（取り壊し前の最後の月）。相手は一つではなく、よそから来て入れ替わる記憶で、**品名も数も立たない**。『朝掃き』を**主として一月置いた**（計器としては使っていない）。選ぶのは現場ではなく前の晩の四畳半。伝票は使わず、出すのも受け直すのも手で書いた。**痛みは書く手間ではなく、夜明け前に戻ってくる手間。**炊飯器の読みは「行が在るから力も在る」ではなく**「貸しているだけで、うちのもの」**にし、疑いを残して**大上大介の行まで考えを及ばせた**。気づきは帰り道ではなく、受け直したあと路地で帳面を読み返す締めに置き、**目的をもって最初の頁を開き、「坂口方　員数　七」の行を見る**。選ぶ場面では『家』の行に触れていない。安藤には報告していない。**以下は着手前の骨格のまま残す。**

**もとは先送り中だった。第十二話から第二十五話へ送った**（[進行記録.md](../../進行記録.md)「I006を先送りにした」）。**出す候補が三枚とも外れたため。** 空いた第十二話には、安藤の残量が見える回を繰り上げた。

**引き取った弱い怪異を、力としてではなく、そのものを現場に出して働かせる。** [連載の組み方.md](../../連載の組み方.md)「弱い怪異をその場に出す」で採用済みの手を、初めて実行する回。

**半分だけ本筋に触る。** 手札が一つ増えると同時に、**恐れの中身が確定する**（[連載の組み方.md](../../連載の組み方.md)「弱い怪異をその場に出す」）。定型回を何本か挟んでから出すこと。

## 前提条件

- **出しても害が無く、しかも役に立つ札が一枚あること。** 手札の枚数ではない。**二枚あっても、どちらも出せなければ選ぶ場面にならない。**
  - **匂い**（I002）は書けない。空気は一意に決まらないので渡しの行が立たない。**規則で外れる。**
  - **猫寄せ**（I007）は出せるが、**出せば寄ってきた猫が居着いて、食わなくなる。** 白金一丁目で茶トラに起きたことが、出した先で起きる。**倫理で外れる。**
  - **線**（I003）は**無い。** 入ったのは木の敷居一本だけ。**本人だけが持っているつもりでいる。**
  - したがって候補は、**朝掃き**（I004・第十五話）から先に入るものになる。
- **定型回で引き取る怪異は、出しても役に立たないのが道理。** 祓えば素直に消える程度のものは現場を動かせず、**出せば元の振る舞いに戻るだけ。** この道理そのものを回の中身にする手もある（並べて、三通りの理由で全部外して、それでも「あれも出る」に行き着く形）。
- 出す作法は受けと同じ。祝詞八文字 → 口上「元祖天神大上屋、大上大介がお渡しします」 → **記帳**。品目と数は口で言わず書く。
- **書いた数は出しきるまで止まらない。** 弱い怪異でも、二と書けば二つ出る。
- **伝票は使える**（渡しの道具）。ただし品名と数を先に決めておく必要があるので、**下見をした現場でしか切れない。**

## 中身

- 現場で手が足りない。札では届かない。引き取るには早すぎるか、対象が定まらない。
- 帳面をめくって、**「これなら出しても害はない」と判断する。**
- 出す。働く。片づける。
- **片づけが手書き**なのがこの回の痛み。出すのは一瞬、しまうのは膝をついて記帳し直す（[札.md](../../../B_設定/札.md)「出すのは一瞬、しまうのは手書き」）。**出したまま帰るわけにいかない**という一幕を必ず入れる。
- **出したものは、出した場で元の怪異として働く。受け直すときは、出した場の名前で受ける**（[帳面.md](../../../B_設定/帳面.md)「出した怪異は、出した場で元の怪異として働く」）。**受け直さなければ、客の家に怪異を一つ置いて帰ることになる。** 片づけの記帳は宛先が変わるので、**帳面に一行増える。**
- **出したものは言うことを聞かない。** 時刻も手順も元のまま。**使えるのは、元の振る舞いがたまたま現場の役に立つときだけ。**

## 出す候補と、その働き

| 在庫 | 出したら何ができるか |
|---|---|
| **線を引くもの**（I003） | **無い。** 第十一話で入ったのは木の敷居一本だけで、力は付いてこなかった（[011_メゾン平尾三〇一号_居間敷居_受_壱_設定.md](../../../B_設定/話別設定/011_メゾン平尾三〇一号_居間敷居_受_壱_設定.md)）。**大上だけが持っているつもりでいるので、外し方は「出したら木が落ちる」になる** |
| **匂い**（I002） | **出せない。** 空気は一意に決まらないので渡しの行が書けない（[記憶と怪異の法則.md](../../../B_設定/記憶と怪異の法則.md)「物の記憶」）。**規則で外れる札**として一度検討させる |
| **猫を寄せるもの**（I007） | 動物を寄せる。**出せば寄ってきた猫が居着いて食わなくなる**ので、使いどころの問題ではなく**倫理で外れる。** 自分の現場の都合で、よその生き物を殺す手 |
| **朝掃き**（I004・第十五話） | **当たり札。****出せば、元の朝掃きとして、出した場で掃く**——夜明け前の四時十分、出した場の前を十一往復。軽いものを寄せ、同じ形の筋を残す。**大上の癖をなぞるのは借りている力のほうで、出した朝掃きは覚えない。**（[怪異/015](../../../B_設定/怪異/015_朝掃き.md)）。使い道の当て（未決）——**毎朝きっちり同じ形に寄せるので、夜のあいだに何かが通れば形が崩れる。掃いた跡がそのまま計器になる** |

- **選ぶ場面を書く。** 並べて、外して、一つを出す。**外し方の質が違うのが要**——匂いは規則で外れ、猫寄せは倫理で外れ、線は最初から無い。**残るのが朝掃き。** 在庫を持っている商売の見せ場であって、力の見せ場ではない。

## 出したあとに一つ残ること（最奥の証拠）

**出しておいても、薬院の炊飯ボタンは押される。** 出したのに手元の力が減らない、という食い違いがここで初めて観測できる（[怪異/015](../../../B_設定/怪異/015_朝掃き.md)「出しても、力は減らない」）。

- **大上は詰まらない。**「渡と書いても受の行は消えていない、行が在るから力も在る」で説明がついてしまう。**理解は進まず、確信が太くなるだけ。**
- **気づきの形は「そういえば、『番』もそうだ」。** 新しく分かるのではなく、ずっと目の前にあったものに今ごろ気づく。
- **本家にも安藤にも言わせない。**

## 気づき

- 帰り道に**「ということは、あれも出る」**と思い至る。
- **『家』も『番』も、書けば出る。**
- 思い至るだけで、何もしない。**恐れが確定するだけの回にする。**
- **理由を掴ませない。** 出したら何が起きるか分からない、という以上のことを考えさせない（[PROJECT_RULES.md](../../../PROJECT_RULES.md)「大上が知らないこと」）。

## 波及（設定側）

- **帳面の急所を守っているのは規則ではなく、大上が書かないという一点だけ**になる（[帳面.md](../../../B_設定/帳面.md)）。この回のあと、うっかり手放す事故が起きないという安全弁は無い。
- 「思い込みの禁止ではなく、選んで引いた線」が、初めて本人の中で線として自覚される。**金は増やさない、祓いは売らないと同列に並ぶ。**
- 以後の定型回で、**出す手が常時の選択肢になる。** 引き取るか、出すか、断るか。手札が三枚になる。

## 注意

- **強い怪異を出させない。** この回で出すのは弱いものだけ。
- **出したものが暴れる展開にしない。** 素直に働いて、素直に片づく。**危険だったという実感ではなく、できるという実感だけを残す。**
- **本家に先に気づかせない。** 本家が自分にも書けると気づく回は別に用意してある（[アイデア.md](../../アイデア.md)「本家が、自分にも書けると気づく」）。ここでぶつけない。
- **安藤には報告しない、あるいは報告しても取り合わせない。** 「出した」と言われて安藤が驚く形にすると、安藤が仕組みを知っていることになってしまう。**「そうか」で流す。**

## 未決

- 現場と依頼人。**この回は道具の回なので、事件のほうは小ぶりでよい。**
- 伝票を使うか、その場で記帳するか。**その場で記帳するほうを推す**——伝票は事前に切る道具なので、「その場でめくって選ぶ」という見せ場が消える。
- 気づきをどこに置くか。**帰り道が定番だが、片づけの記帳をしている最中のほうが効くかもしれない。** 出した行を戻しながら、同じ手つきで別の行も戻せることに思い当たる。

## 定型回としての位置

- **I002かI003、そしてI004のあと。** 在庫が二つ以上溜まってから。
- 直前にI005（断る回）を挟むと、**増えないことを一度見せてから、使えることを見せる**形になって効きが良い。
