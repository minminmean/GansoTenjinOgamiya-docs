# I072　屋台の話

**済（第十六話「ふく八　十一席目　受　壱」）。** 人前では記帳が隠せないことが露見し、受領証が生まれた回。確定した形は[話別設定/016](../../../B_設定/話別設定/016_ふく八_十一席目_受_壱_設定.md)、怪異は[怪異/016](../../../B_設定/怪異/016_十一席目.md)。

**[アイデア.md](../../アイデア.md)から移した**（2026年10月6日。本文にした材料を、その回の話アイデアへ寄せた）。中身はアイデア.mdに置いていたときのまま。番号はこのとき振った。

## アイデア.md から移した材料

- **人のいる場所で書かねばならない回**：記帳のあいだ『家』は気配を撒き、周りの全てを数える。これまでは全部無人の場所で書いてきたので露見していない。**客の目の前で、あるいは往来で書く**しかない状況を作れば、隠せない術という縛りが初めて牙を剥く。数えられる側に依頼人が立つ、という形にもできる。
- **屋台の話**：**第十六話で済んだ**（[話別設定/016](../../../B_設定/話別設定/016_ふく八_十一席目_受_壱_設定.md)、[怪異/016](../../../B_設定/怪異/016_十一席目.md)）。確定事項はあちらへ移した。**ここに残すのは、先へ効くものだけ。**
  - **人前では記帳が隠せない**が本編で露見した。以降の定型回に乗る縛りは[連載の組み方.md](../../連載の組み方.md)「屋台以降に乗る縛り」。
  - **うちの店の前で、人前では一度も書いていない**、が本文で立った。**歩道には閉める戸が無い。** いつか自分の店で書かねばならない日が来ると効く。**使いどころは未定。**
  - **記帳に四十秒**という数が確定し、**その場で受領証（受け札）が発明された**（[札.md](../../../B_設定/札.md)「受領証」）。**伝票の裏返しの席は埋まった。**
    - **ただし切れる回は稀。** 下見で数を確かめ、同じ数がもう一度立つと分かっているときにしか切れない。**定型回の引き取りは、ほとんど四十秒のまま。**
    - **「切れなかった」ことが、調べが足りていない物証になる。** 定型回で使える手として空いている。
  - **引き取った力は「その場が満ちているかどうかだけ分かる」。数は出ない。** 発現の回は未定（[怪異/016](../../../B_設定/怪異/016_十一席目.md)）。
  - **中洲の屋台の一列は、舞台として再利用しない。** 同じ制約をもう一度使えば、詰まりの見せ場が二度目になる。
