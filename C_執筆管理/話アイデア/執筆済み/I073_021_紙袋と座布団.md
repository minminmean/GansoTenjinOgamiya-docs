# I073　紙袋と座布団

**済（第二十一話「包み」）。** 紙袋（十九点）が捨てても増えないと分かる回で、座布団の代償の一件を回想で置いた。肉の様子と始末の続きは第二十四話（[I013](I013_024_点検を売る.md)の「遥を見かける」）。確定した形は[話別設定/021](../../../B_設定/話別設定/021_包み_設定.md)。

**[アイデア.md](../../アイデア.md)から移した**（2026年10月6日。本文にした材料を、その回の話アイデアへ寄せた）。中身はアイデア.mdに置いていたときのまま。番号はこのとき振った。

## アイデア.md から移した材料

- **紙袋に気づく回**：第一話の十九点はもう怪異ではなく、捨てても増えない。大上だけがそれを知らずに二か月抱えている。気づく場面は、そのまま『家』が「増やす力」ではないと知る場面になる。四畳半の隅に置いたままの紙袋を、いつ、誰に指摘されるか。

- **代償の一件（第二十一話に回想で置く。中身は確定）**：第七話のあと、九月のどこか。座布団を出すのに癖で**六**と書いた。手元は五枚（一枚は警察の証拠品）。**大上の数が間違っている。**
  - **『家』が合わせにいくのは、大上が立てた数のほう。** 六と書いたからには六無ければならない。**破綻したとき優先されるのは『家』の数。**
  - **足りない一を、増やさずに在庫から埋めた。** 増やすより、適役の在庫があれば出すほうが優先される——**本家の出現がその先例**（「店番　弐」に対して「大上大介　壱」を出した）。
  - **坂口方の在庫は、ほかに母と娘しかない。** 帳面は**「坂口方　母　弐」の行を「坂口方　座布団　弐」に読み替えた**（[帳面.md](../../../B_設定/帳面.md)「読み替えは、訂正ではない」）。
    - **変換したのではない。** 母を座布団に変えたのではなく、**坂口方の母とは座布団だったということにした。** だから訂正の痕も、行き先の記録も要らない。**消して勘定を覚えているだけなので、どこにも行っていない。座布団だっただけ。**
    - **人の論理では通らない形で通る**のが見どころ。**最奥がいちばん露骨に顔を出す一件。**
  - **出てきた六枚目は肉。** 生きている。少し動く。年老いた女性の匂いがする。**手足も眼も鼻も口もない。心臓はあるようで、脈打っている。** **座り心地には触れない**——大上は試そうとしないし、読者も座りたくない。
  - **埋められないし、置いておけない。帳面にしまうしかなかった。座布団として。** 結果、**坂口方の座布団は棚ごと死蔵**になった——肉が一枚混ざっているので、以後この棚からは何も出せない。**唯一自由に出せる物資を失っている。**
  - **安藤には言っていない。** 本家は知っているが、二人とも口に出さない。
  - **分量の配分**——第二十一話は**少なめ**（六と書いた／六枚出た／血が通っていた／行が無い／しまうしかなかった）。**肉の様子と、しまうまでの始末は第二十四話へ回す**（[I013](I013_024_点検を売る.md)の「遥を見かける」の回想で補完）。
  - **効かせる先**：第二十四話の「考えたくもなかった」が、想像ではなく**既知**になる。**答えを知っている男が、考えたくない。**
