# 元祖天神大上屋

福岡・天神を舞台にした連作小説「元祖天神大上屋」の、本文と設定の置き場。**第一話から第七十七話（第六十八〜七十三話は欠番）と番外五本、全七十六本で、2026年11月13日に完結した。投稿先では第一話を（１）（２）に割って載せているので、七十七本になる。**

妖怪退治の話ではなく、拝み屋という稼業とその哲学を綴る話。怪異は倒す相手ではなく商売の相手で、読みどころは、どう祓ったかではなく、どういう理屈で、どういう手順で、いくらで引き受けたか。各話は勝敗ではなく「どう始末をつけたか」で閉じる。

**執筆と校正の規約は [PROJECT_RULES.md](PROJECT_RULES.md)（この作品だけの決まり）と [執筆の決まり.md](執筆の決まり.md)（作品を問わない決まり）にある。** 作法も、表記も、世界のルールの要点も、あちらが正。このファイルが持つのは置き場の案内だけ。[CLAUDE.md](CLAUDE.md) と [AGENTS.md](AGENTS.md) は、執筆に使う道具（Claude Code と Codex）への入口。

## はじめて見る人へ

- **これは何か。** 「元祖天神大上屋」を書くのに使った作業場を、完結してからそのまま公開したものです。本文と設定、回の組み方、校正の規約、執筆に使った AI への指示（技能）が入っています。連載中の履歴は残さず、一つのコミットにまとめました。
- **どう書いたか。** 設定と構成は作者が手がけ、本文の執筆には生成 AI（Claude Code。校閲に Codex）を使いました。作者は草案と本文に赤を入れ、決めたことをその都度ここのファイルに書き足していきました。規約の中の「著者の指定」「著者の指摘」は、そのとき作者が言ったことです。
- **ネタバレにご注意ください。** 設定のファイルには、結末と、本文では明かしていない真相まで書いてあります。本文を先にお読みになることをお勧めします。
- **お使いいただけるもの。** 世界観と設定は自由にお使いいただけます。二次創作も歓迎します。本文の転載はご遠慮ください。条件は [LICENSE.md](LICENSE.md) にあります。
- **本文を読むなら。** 正は `A_本編/` の md です。掲載の順は [C_執筆管理/掲載表.md](C_執筆管理/掲載表.md) にあります。投稿先は[小説家になろう](https://ncode.syosetu.com/n6672mr/)と[カクヨム](https://kakuyomu.jp/works/11054822661915983401)です。
- **書き方を見るなら。** まず [PROJECT_RULES.md](PROJECT_RULES.md) と [執筆の決まり.md](執筆の決まり.md) をご覧ください。AI に毎回読ませていた入口で、ここから各設定へ辿れます。一話の組み方は [C_執筆管理/連載の組み方.md](C_執筆管理/連載の組み方.md) に、案の段で決めたことは `C_執筆管理/話アイデア/執筆済み/` に残っています。
