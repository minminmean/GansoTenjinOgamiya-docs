# テキスト変換規則

`A_本編/*.md` を投稿用テキストに書き出すときの、ルビと傍点の入れかた。**正は md のほうで、md には記法を一切書かない。**ルビも傍点も、書き出しのときにここの規則で足す。

書き出しの手順そのものは [.claude/skills/export-honbun-txt/SKILL.md](../.claude/skills/export-honbun-txt/SKILL.md)。ここに書くのは、その中で使う判断の基準と、話ごとに積み上がる特例。

**既定の変換先は「小説家になろう」。**指定がなければこれで出す。**変換先は二つ——なろう、カクヨム。**違うのは傍点の形だけで、ルビはどちらも同じ書式で足す。**ノベラボには出さない**（2026年10月1日にやめた。変換先からも外した）。

## なろうの記法（実仕様）

- ルビは `｜親文字《ルビ》`。縦棒は全角でも半角でもよい。
- 漢字にひらがな・カタカナを振るときは縦棒を省略でき、`《》` の直前の漢字部分が親文字になる。**この自動判定には頼らない。**親文字の切れ目を取り違えるので、必ず縦棒を書く。
- **親文字は一〜十文字、ルビは最大十文字。**超えると設定されない。長いものは分けて振る。
- `&` `"` `<` `>` が混じると、字数以下でも通らないことがある。本編には無いが、増えたら避ける。
- **なろうに傍点の記法は無い。**`《《…》》` は効かない。傍点はルビに中黒を入れて代用する。

## ルビ

### どこに振るか

- **初出の地名・人名に振る。**屋号・建物名・店名も人名地名の扱い。
- **一つのテキストファイルの中で一度振った語には、以降振らない。**話をまたいだ引き継ぎはしない。話ごとに数え直す。
- 台詞の中か地の文かは問わない。**その話で最初にルビを置ける箇所に振る。**
- 一般語には振らない。難読でも、丸括弧で読みが書かれていなければ触らない。

**通し。**辞書の「通し」の列に字が入っている語は、話ごとに数え直さず、**連載を通して一度だけ**振る。毎話出てくる名前にルビが繰り返されるのを避けるため。いまのところ `安藤`・`本家`・`天神`・`渡辺通り`・`元祖天神大上屋`・`大上屋`。屋号は第一話冒頭の看板で一度出れば足りる。`渡辺通り` は店の場所なので毎話出る。**通しの初出は本編の連番の若い話から数える。**

**どの話が初出かは、[変換辞書/通し初出.tsv](変換辞書/通し初出.tsv) が持つ。**書き出しは前の話を読まずにこの台帳を見るので、**一話だけ渡して書き出せる。**台帳に行が無い通しの語は、単話で書き出したときに振られない。**通しの語を増やしたら、`--ledger` を通して台帳を作ること。**

**通しにするのは、毎話出る語だけ。**師匠、相方、屋号、店の場所。**飛び飛びに出る人物は通しにしない。**`播谷`（四回）と `税所`（税の回まわり）は、通しにすると初登場の一話でしか読みが出なくなる。**難読なぶん、間が空く人物こそ振り直すほうが親切。**一度検討して、通しにしないと決めた。

**番外では、通しの語を振らない。**`E` 付きの別連番で、**本編のあいだに順不同で差し込む**。どこに挟まっても、通しの語は本編の側で読みが済んでいるものとして扱う。番外の中で改めて振ることもしない。**番外で振らなかったことは本編の勘定にも影響しない。**通しでない語は、本編と同じく番外の中の初出に振る。

**吸収。**長い語のルビが短い語のルビをそのまま含んでいれば、短いほうも振り済みとして数える。`元祖天神大上屋` のルビには `｜天神《てんじん》` が入っているので、第一話冒頭の看板で `天神` の読みも済んだことになる。だから本編で `天神` 単独にルビが付くことはない。

**位置指定。**初出の位置を辞書任せにできない語は、[変換辞書/位置指定.tsv](変換辞書/位置指定.tsv) で行を名指しする。指定のある語は、**その話の、その目印を含む行でしか振らない。**

### ルビの位置指定

**表は [変換辞書/位置指定.tsv](変換辞書/位置指定.tsv)**（語／話／行の目印）。

`本家` は第一話にも第三話の前半にも出るが、そこはどれも「元祖に対する本家」という一般の言い方で、人物を指していない。名乗った台詞が人物としての初出なので、そこに振る。看板の行（二字下げ）は記帳行と同じ扱いで振らない。

`白鳥` は第三十三話の喫茶白鳥（しらとり）だけに振る。第五十五話の白鳥ボートは「はくちょう」なので、位置指定で第三十三話の「白鳥という店だという」の行に縛った。**喫茶白鳥がほかの話に出るときは、その話の行を足すこと。**

### 通しルビの初出

**通しの語を、どの話で振ったかの台帳。**この表があるので、単話で書き出しても通しの勘定が合う。**書き出しはこの表だけを見て、ほかの話の本文は読まない。**表に載っていない話では、その語は素のまま出る。

**表は [変換辞書/通し初出.tsv](変換辞書/通し初出.tsv)**（語／初出の話）。

- `天神` と `大上屋` は、第一話冒頭の看板で `元祖天神大上屋` に吸収されたぶん。単独でルビが付いた行があるわけではない。
- `本家` は位置指定があるので、第三話の「うち、本家です」の行。
- **番外はこの表の外。**`E` 付きでは通しの語を一律に振らない。
- **表は手で書き換えない。**書き出しの技能の `--ledger`（[SKILL.md](../.claude/skills/export-honbun-txt/SKILL.md)）が本編全話から数え直し、**この表をその場で書き直す。**通しの語を増やしたときと、**既にある話の本文で通しの語の出どころを動かしたとき**に走らせること。

### 振らない場所

- **一行目の題。**なろうのサブタイトル欄はルビ記法が効かない。初出の数にも入れない。
- **記帳の行**（全角二字下げ・三字下げの独立段落、および地の文にカギ括弧で埋め込んだ行の引用）。帳面に書いた文言なので記号を混ぜない。ここも初出の数に入れない。
- したがって初出とは、**題と記帳行を除いた本文で最初に出た箇所**を指す。

### 丸括弧で読みが示されている語

**初出の規則とは別建て。**本文に丸括弧で読みが書いてあれば、それはルビにする。丸括弧は落とす。

```
三和土（たたき）  →  ｜三和土《たたき》
```

**送り仮名は親文字から外す。**丸括弧の読みと親文字の末尾が食い違うぶんを、ルビの外に出す。

```
留め（とめ）  →  ｜留《と》め
```

- 同じ語がその話で後にも出るなら、**丸括弧のある初出だけ**をルビにする。以降は素のまま。
- この変換は初出規則より優先する。地名・人名に丸括弧が付いていれば、丸括弧の読みを採る。

### 読みの辞書

**読みはすべて著者の確定。**推測で足さないこと。辞書に無い地名・人名に当たったら、そこで止めて確認する。

**辞書そのものは [変換辞書/読み.tsv](変換辞書/読み.tsv)**（分類／語／ルビ／通し／備考）。分類は六つ——人名、地名、まだ本文に出ていない地名、造作・建具、屋号・建物、一般語。**一般語は、読み違えやすい語だけ**（山笠を「やまがさ」と濁る、夜番を「よばん」と読む。第四十七話から）。**「まだ本文に出ていない地名」は先に読みを決めてあるぶんで、使えば自動で振られる。**「通し」の列に字が入っていれば通しの語で、初出の話は [変換辞書/通し初出.tsv](変換辞書/通し初出.tsv) が持つ。

**辞書に語を足したら、過去の話への波及を注記する。**ルビは話ごとに数え直すので、**新しい話のために足した語が、既に投稿した話にも振られる。**そのぶん、なろう側の本文が古くなる。

- **確かめ方は `--ledger` と同じ仕掛けの `--dry`。**txt を書かずに変換の記録だけ出して、その語で引けば、どの話の何行目に当たったかが分かる（[SKILL.md](../.agent-shared/skills/export-honbun-txt/SKILL.md)「波及検査」）。**なろうと全話を突き合わせる必要はない。**
- 過去の話に当たっていたら、**報告に必ず書く。**話数・行数と、その話の掲載状況（公開済／予約中）まで。予約中なら差し替えが間に合う。
- 実例——第十二話のために `七隈線` を足したら、**第九話の三十四行目にも振られた**（差は九文字）。第九話は予約中だったので差し替えが間に合っている。

**「和美」には振らない。** 読みが一つしかないので辞書に持たない（[登場人物.md](../B_設定/登場人物.md)「税所和美」）。**振るのは苗字の「税所」だけ。**

**「きみ子」にも振らない。** ひらがなと「子」なので読みが割れない。**振るのは苗字の「占部」だけ。**

**下の名前は、読みが割れるかどうかで決める。** 苗字は割れなくても登録するが、**下の名前は原則として持たない。**

- **持たない**——大介、孝一、和美、きみ子、八郎。**どれも他の読みがまず浮かばない。**
- **持つ**——利一（としかず）、伊三郎（いさぶろう）。**当て方が何通りも立つ名。** 難読というより、**読み手が別の読みで通してしまう**のを避けるために振る。

**「大上大介」には振らない。**「大上」は屋号「元祖天神大上屋」のルビが読みを担うので、第一話冒頭の看板でそれが出たあとは「大上さん」にも振らない。「大介」はそもそも辞書に持たない——**読みが一つしかない語だから。**「大上」はオオカミともダイジョウとも読めるが、「大介」はダイスケ以外にまず読まれない。名乗りの口上も素のまま出す。

**造作・建具**

**一般語には振らないのが原則だが、難読で、しかも本編に繰り返し出るものだけ辞書に持つ。** 話ごとに丸括弧を書いて特例の表に足す手間を、そのつどかけずに済ませるため。**増やすのは慎重に。**

**一字の語は、別の読みになる熟語があるかどうかで決める。** 框は上がり框でも床框でも「かまち」のままなので、食い込んでも正しい。**桟は桟橋（さんばし）・桟敷（さじき）で読みが変わるので、入れない**——第十二話に一度きりでもあるので、丸括弧と特例の行のまま残した。

**辞書に入れたので、本文の丸括弧は落とした。** 第一話・第二話・第十二話・第十七話の五箇所。**どの話も丸括弧が初出の位置に来ていたので、出力は一文字も変わらない**（書き出して差分を取って確かめた）。**新しい話では、丸括弧も特例の行も要らない。**

**丸括弧を残したまま辞書に入れてはいけない。** 丸括弧の変換と辞書の変換は初出の勘定を共有しないので、**同じ話で二度振られる**（第一話の百三十七行目、第二話の百二十行目で実際に出た）。**片方に寄せること。**

**振らない語**

福岡、中央区、みやこビル、純喫茶まりも、元祖（単独で出たとき）、大介、孝一、八郎、山、天神南、本家天神大上屋。屋号の初出で `｜元祖《がんそ》` を振っているので、以降の「元祖さん」には要らない。「大介」「孝一」「八郎」は読みが一つしかないので辞書に持たない。「山」は「山さん」の一字で、**苗字か下の名前かも作中で定めていない**（第十六話）。「天神南」は `天神` が通しで済んでいるうえ、駅名として読める。

「ホテル白水」「メゾン平尾」「入江クリーニング」は、辞書の `白水`・`平尾`・`入江` が当たるので個別の行を持たない。

## 傍点

### どこに置くか

**地の文の中で、語や句を浮かせるために使われているカギ括弧。**カギ括弧を外して、その中身に傍点を置く。

```
いま「七」が入っている  →  いま｜七《・》が入っている
```

### 置かないもの

同じカギ括弧でも、次の三つは傍点にしない。**カギ括弧のまま残す。**

1. **発話の引用。**行頭が「で始まる台詞行、および地の文の中の「……」と言った／訊いた／答えた の形。
2. **書かれた文言の引用。**看板、表札、名刺、帳面の記帳行、壁に透けた文字、システムの表示。書いてあるものを写しているのであって、強調ではない。
3. **『家』『番』の二重カギ括弧。**大上が付けた呼び名で、強調ではない。なろうでは『』はそのまま通るので、触らない。

### なろう向けの形

中黒ルビで代用する。**一文字ずつ別々に振る。**まとめて振ると環境フォントで点と字がずれるうえ、途中で改行できなくなる。

```
七        →  ｜七《・》
増やす    →  ｜増《・》｜や《・》｜す《・》
```

### カクヨム向けの形

カクヨムは `《《…》》` が傍点として効くので、そちらで出す。

```
七        →  《《七》》
増やす    →  《《増やす》》
```

### 直書きの二重山括弧

今後 md の本文に `《《…》》` を直接置くことがある。**そこは傍点の指定として扱う。**

- カクヨム向け——そのまま出す。
- **なろう向け——中黒ルビに変換する。**素通しすると `《《》》` が本文にそのまま出るか、ルビとして誤爆する。なろうにこの記法は無い。

`《` `》` `｜` は本編に一箇所も出てこない。地の文で記号として使いたくなったら、その時点でエスケープの規則を決める。

## 変換後の報告

書き出しが済んだら、**ルビを振った箇所と傍点を置いた箇所を表にして出す。**話ごとに、行番号・元の表記・変換後。読みが辞書に無い語や、候補が絞れない語に当たったら、**その場で止めて確認を取る。**勝手に決めて通さない。

## 特例

話ごとの、判断の済んだもの。ここに無い形が出たら確認する。

### 傍点

判断の済んだ対象。これ以外の地の文のカギ括弧は、いまのところ全部「置かないもの」に当たる。

**表は [変換辞書/傍点.tsv](変換辞書/傍点.tsv)**（話／語／文脈）。文脈の列は読むための覚え書きで、変換には使わない。

**紛らわしいので念を押す。**次はどれも傍点にしない。

- 第一話「元祖天神大上屋」「怪異　ご相談ください」「坂口」——看板と表札の文字。
- 第二話「坂口方　員数　七」、第三話「員数　七」、第九話の三行——帳面の記帳行。
- 第五話「システム上は空室」「使用済み」——ホテルの端末と清掃の上げてきた表示。**同じ話の「薄くなっている」は強調なので傍点にする。**
- **強調に二重カギ括弧を使わない。**『』は『家』『番』の呼び名のための括弧で、強調は「」で書く。混ざっていたら本文のほうを直す（第五話でそう直した）。
- 第七話「洋裁」——看板の下の層に透けた文字。
- 第二話「在庫……」——口に出しているので発話。
- 第十八話「合」——**『番』が帳面に書いた文言の引用。**点検記録の結果をそのまま写しているので、強調ではない。カギ括弧のまま残す（第二話・第三話・第九話の記帳行と同じ扱い）。
- 第十六話「弥太郎」——**屋号の引用。**直前の台詞で大上が口に出した語を、地の文で受け直しているだけ。**強調ではないので傍点にしない。カギ括弧のまま残し、ルビは辞書の `弥太郎` が当たる。**
  - **屋号や店名を地の文でカギ括弧に入れた形は、以後もこの扱い。** 傍点を打つと、その名前に含みがあるように読める。

## 踏んではいけない穴

- **全角の記号を正規表現のブラケットに入れない。**`[^「」]` のような書き方をすると、ロケールによってはバイト単位で動き、`一`（E4 B8 80）や `十`（E5 8D 81）を含む行だけ素通しになる。**ルビ・傍点の変換は必ず perl の `:encoding(UTF-8)` で文字単位に読んで処理する。**sed と grep で `《》「」｜` を扱わない。
- **ルビと傍点を入れると、行の文字数は変わるが行数は変わらない。**行数が md と食い違ったら変換が化けている。
- **改行は CRLF、行末の半角スペース二つは落とす。**ルビを足すのは半角スペースを落としたあと。行末の語にルビが付いても末尾に空白を残さない。
