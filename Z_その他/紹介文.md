# 紹介文とキャッチコピー

**両面とも同じ紹介文を出している**（なろう・カクヨム。2026年9月8日に登録した）。**正はここ。** どこかを直したら、両面とも直す。**ノベラボは2026年10月1日にやめた**（それまでは三面に出していた）。

## 紹介文

```
舞台は現代、福岡・天神。
路上に看板が立ち、その脇にパイプ椅子と折り畳み机の簡素な店構えがあった。
店の名は「元祖天神大上屋」。
その店主、大上大介は、新米の拝み屋である。
師匠のもとをわずか三ヶ月で飛び出し、独立したばかりだ。
開業から一ヶ月が経つ頃、初めて看板からの依頼が飛び込んでくる。
依頼人は言う。毎日なにかが増えるのだと。
箸が増え、湯呑みが増え、靴が増え、──家人が増える。
この一件ののち、彼の手元には一冊の帳面が残った。
帳面に怪異を書けば、それは彼の力となる。
怪異は、彼にとって倒す相手ではない。引き取るものだ。
帳面には、怪異が載っていく。
彼がこの稼業を続ける限り、ずっと。
```

## 決めたこと

- **一行目で時代と場所を言い切る。** 屋号の題も、拝み屋も、帳面も、放っておくと江戸に読まれる。**先に現代だと言ってしまえば、あとに出てくる古い語は時代ではなく手触りとして読まれる。**
- **「家人」は残す。** 微妙に和風な質感を出すための語で、列の落ちどころに置いてある。一行目で枠が決まっているので、誤読の引き金にはならない。
- **「あった」は過去形のまま。** 既に構えられていて、そこに在る、という感じを出すため。「看板が立ち」は中止法なので時制を持たず、文末から受ける。ぶつかっていない。
- **帳面は開示する。**（2026年9月8日に方針を変えた。それまでは「抱え込む先は書かない」で、帳面も引き取りも伏せていた。）**伏せることで守れているものが無かった。** 第二話以降の題は記帳の行そのもので、目次は「員数　七」「受　壱」「渡　六」が縦に並んだ列になる。**紹介文だけが伏せていると、目次がただの暗号に見える。** 名指ししておけば、あの列は暗号ではなく看板になる。
  - **守るべきものは減っていない。** 帳面が本当にやっていること、代償、本家、『家』と『番』の正体。**どれも紹介文の射程の外なので、帳面を名指ししても一つも漏れない。**
- **「この一件ののち」で時間を飛ばす。** **帳面は第一話に一度も出てこない**（第二話で千八百円で買う）。買うところを書くと順序の説明が要るので、**手元に在るところから始める。**「残った」は買い物を代償に言い換えた形で、実際とは違うが紹介文としてはこちらが正しい。
- **手口の説明はしない。** 「品名と数を書けば引き取れる」という理屈は第一話と第二話を丸々使って立ち上がるものなので、一行で言うと唐突になる。**規則だけ置いて、機序は置かない。**
- **「引き取る」は対で出す。** 単独で出すと作中の術語なので意味が通らないが、「倒す相手ではない／引き取るものだ」の対にすれば、対比が語を定義してくれる。
- **力に触れるとき「増やす」を使わない。** あれは大上の誤解の名前で、紹介文は作品の外側の声なので、書けば誤解が事実として保証されてしまう（[PROJECT_RULES.md](../PROJECT_RULES.md)「大上が知らないこと」）。「彼の力となる」で止める。
- **「異能」は紹介文に降ろさない。** カクヨムのキャッチコピーだけの語（下記）。
- **収集ものに読まれてよい。** 「帳面に怪異を書けば、それは彼の力となる」は能力収集ものに読める。**そう読まれて構わない、と決めた。** 帳面に一つずつ載って、引き取った力が後から発現する——**構造としては本当に在庫が増えていく話で、商売と勘定は、その増え方をどの物差しで書くかという流儀のほう。**
  - **避けたいのは戦闘の期待であって、収集の期待ではない。** ジャンルをホラーに寄せた理由もそれ（下記）。**紹介文は戦闘を約束していない**——「倒す相手ではない」と名指しで否定している。**収集を見に来た読者は、実際に溜まっていくものを見つける。食い違わない。**
- **「増える」を二度使っているのは意図。** 依頼人の家で増えるもの（箸、湯呑み、靴、家人）が、そのまま彼の帳面で増えるものになる。**被害から在庫へ、同じ語で移す。** 最後の「ずっと」が受けているのはこの対。**帳面を伏せていた頃の版には無かったもので、開示に切り替えて初めて成立した。**

## 完結の注記（両面）

```
※2026年11月13日完結。全七十七本。
```

- **両面とも、紹介文の末尾に一行空けて、AI利用の注記の上に足す。**（2026年11月13日、完結に合わせて。みんみんさんの決め。）
- **冒頭には置かない。** 一行目で時代と場所を言い切る決めを崩さないため。完結は両面とも一覧と作品ページに印が出るので、冒頭で言わなくても伝わる。
- **数は投稿先の目次に合わせて七十七本**（第一話を（１）（２）に割ったのを正とする）。

## AI利用の注記（両面）

```
※本作は、設定と構成を作者が手がけ、本文の執筆に生成AIを利用しています。
```

- **両面とも、紹介文の末尾に一行空けて足す。**（2026年10月9日に、なろうにも足すと決めた。それまではカクヨムだけ。）
  - **カクヨムは2026年9月から。** 専用の欄が無いので、紹介文で申告した。
  - **なろうは、作品設定のAI利用の欄（直接使用）に加えて足す。** 欄は作品情報を開かないと目に入らないが、紹介文なら最初に目に入る。**AIと書いてあれば読まない人は、いまでも読んでいない**（著者の判断）ので、入口は狭まらない。
- **これで紹介文は、注記まで含めて両面同じになる。** 直すときは両面とも、本体とこの一行をそろえて直す。
- **タグ「AI本文利用」も付けた**（2026年9月28日。タグの先頭）。カクヨムの[小説投稿ガイドライン](https://kakuyomu.jp/legal/guideline#generativeAI)「生成AIの利用について」が、使用状況に応じたタグ付けを**推奨**している（義務ではない）。区分は三つ——**AI本文利用**（本文の大半、目安五割以上を生成AIが書いた）、**AI本文一部利用**（五割未満）、**AI補助利用**（アイデア・資料・校正など補助）。**本文は生成AIが書いているので、AI本文利用に当たる。** 応募要項もあわせて確認するよう書いてあるので、コンテストの扱いはそちらで見る。
  - **枠を空けるために「ご当地」を外した**（下記「ジャンルとキーワード」）。

## キャッチコピー（カクヨムだけ）

```
異能の帳面を手にした新米拝み屋の物語
```

- **キャッチコピーはカクヨムだけの欄。** なろうには無い。**一行で引く役なので、紹介文の一行目とは別の仕事をしている**——紹介文は時代と場所を言い切る役、キャッチコピーは稼業を言う役。
- **「異能」はここにしか無い語。** 本編にも、設定にも、紹介文にも一度も出てこない。**外に向けて一行で分からせるための語であって、作中の語ではない。本文や設定に持ち込まないこと。**
- **キャッチコピーが帳面を名指ししたことが、紹介文の方針を動かした。** もとの紹介文は帳面も引き取りも伏せていたが、そこから開示する側へ変えた。

## ジャンルとキーワード

- **ジャンルは両面ともホラーで通す。** 現代退魔ものの主戦場はローファンタジーだが、母数が桁違いで埋もれるうえ、期待されるもの（バトル、成長、強くなること）がこの作品とずれる。**文芸の棚のほうが池が小さく、読者の期待とも合う。** 変えるなら早いほうが痛くない。
- **副題は付けない。** 一覧での引きのために説明口調の題にするのはやらない、と決めた。**そのぶんはキーワードで拾わせる。**
- **「和風」と「超能力」は外した。** 前者は屋号の題と合わさって、江戸の話に読まれる原因になっていた。後者は能力バトルものではないので、別の期待を呼ぶ。
- **「拝み屋」は入れた。** 探している人がそのまま打ち込む語なので、自由入力の側で拾わせる。**残る候補は「博多弁」。**
- **なろうとカクヨムでは数が違う。** なろうは十五、カクヨムは八。**共通は六つ**（現代、怪異、福岡、オカルト、拝み屋、連作短編）。**カクヨムだけ**が「お仕事」（なろうの「職業もの」に当たる）と「AI本文利用」。
- **カクヨムから「ご当地」を外した**（2026年9月28日）。「AI本文利用」の枠を空けるため。**役目が「福岡」と重なっていた**——福岡を舞台にした話を探す人は「福岡」と打つ。**「お仕事」は残した**——稼業の話だと言っているのは八つのうちこれだけで、「拝み屋」に退魔の期待が乗るのを隣で打ち消している。なろうの「ご当地」はそのまま。
- **なろうに企画のキーワード「ＥＳＮ大賞１１」「ドリコム大賞５」を入れ、おすすめの「シリアス」「ダーク」を外した**（2026年10月12日に確かめた）。**どちらの企画も AI 利用を禁じていない。** 十五の枠に収めるため、入れたぶんだけ外した。
- **カクヨムのタグの並び**：AI本文利用、オカルト、現代、怪異、拝み屋、福岡、お仕事、連作短編。**なろうのおすすめキーワードは選択肢が決まっているので数が増える。** カクヨムは自由入力なので、絞ったほうが効く。
